# Проверки в браузере по пунктам

`npm run e2e:files` после своих проверок по очереди (по имени файла) запускает каждый `*.ts` из этой папки. Файл
экспортирует по умолчанию функцию, которая получает `E2EKit` (`scripts/e2e-kit.ts`): страницу `p`, `check`, `tab`,
`openText`, `saveText`, `report`, `shot`. Перед каждым файлом открыта вкладка «Балки и рамы».

Пункт дорожной карты, который ведётся параллельно с другими, кладёт свои проверки сюда отдельным файлом
`item-<номер>-<тема>.ts`, а не дописывает их в `scripts/e2e-files.ts`: так ветки пунктов не конфликтуют при слиянии.
Образец — `item-19-centrodes.ts`.
