# Статика: балки и рамы

Составление, решение и проверка уравнений равновесия плоской рамы с пошаговым решением
в стиле решебника. Перенос прототипа `prototype/statika.html` на TypeScript + Vite + React.

Прототип — источник истины по поведению и ответам; в репозитории он не меняется.

## Команды

```bash
npm install
npm run dev        # приложение (http://localhost:5173)
npm test           # все тесты (Vitest)
npm run typecheck  # проверка типов
npm run build      # сборка в dist/
npm run golden     # переснять эталоны с прототипа (нужен Chromium, см. ниже)
npm run build && npm run compare:ui   # сравнить интерфейс с прототипом в браузере
npm run build && npm run e2e:files    # сохранение, открытие и отчёт в PDF в браузере
npm run build && npm run bundle       # один файл dist/statika.html (всё встроено) и его проверка в браузере
npm run totals     # пересчитать общие итоги (число задач «Задачника», итоги покрытия) после слияния пунктов
```

### Как добавить раздел

1. Папка `src/modules/<имя>/` со своими `model/`, `solver/`, `text/`, `draw/`, `ui/` — общие части брать из `src/shared/`.
2. `index.tsx` возвращает `StatikaModule` (`src/app/module.ts`): идентификатор (он же поле `module` в файле),
   подпись вкладки, хранилище (отмена, повтор, сохранение и открытие файла, уведомления), экран,
   готовые задачи `tasks` и их загрузку `loadTask` (для «Задачника»). Название задачи начинается с источника:
   «Мещерский 46.19: …», «Антонов, задача 4: …» — по нему задача попадает в нужную группу.
3. Добавить раздел в `createModules()` (`src/app/registry.ts`), в блок навигации (`src/app/nav.ts`) и отметить готовым
   в `src/app/roadmap.ts` (`status: 'done'`, `tab` — идентификатор вкладки); пока пункт не готов, его файл не открывается
   с понятным сообщением.
4. Эталоны из задачника — в тесты раздела; браузерные проверки — в `scripts/`.

### Пояснения к ходу решения

`analyze(s, { explain: true })` добавляет к решению абзацы-пояснения (класс `explain`):
какие реакции даёт каждая опора, правило знаков моментов и теорема Вариньона,
как заменяется распределённая нагрузка, почему система определима, **почему в выбранном уравнении
осталось одно неизвестное** (линия действия проходит через точку, сила перпендикулярна оси,
пара не входит в проекции, значение уже найдено), как выбрано проверочное уравнение, что значит знак «−».

Без `explain` текст совпадает с прототипом (кроме исправленных случаев ниже); `explain` только добавляет абзацы — это проверяется тестом.

## Обозначения углов и разбор плеч

- У силы, опорного стержня и наклонного катка можно выбрать обозначение угла (α, β, γ, φ, ψ, θ); значение
  по-прежнему вводится числом. В уравнениях угол пишется буквой (F·sin α·2, для угла больше 90° — sin(180° − α)),
  в подстановке — числа, в первом шаге решения — «Углы: α = 60°». Без обозначения всё как раньше.
- В режиме пояснений под каждым уравнением моментов — разбор слагаемых: какая составляющая силы, где приложена
  (для равнодействующей — в центре тяжести эпюры), почему плечо именно такое (расстояние по горизонтали или
  по вертикали от точки моментов) и откуда знак.

## Составные конструкции (внутренние шарниры)

Шарнир — свойство точки (конфигуратор → «Внутренние шарниры»; доступен в точках, где сходятся хотя бы два участка).

- Шарниры делят раму на жёсткие части (`partsOf` в `src/modules/frames/model/geometry.ts`), части нумеруются I, II, … по обходу.
- В шарнире на вторую часть действуют взаимные силы X, Y, на первую — такие же в обратную сторону
  (в книге — «±»). Опоры и нагрузки, приложенные в самом шарнире, относятся к первой части.
- Распределённая нагрузка, проходящая через шарнир, делится на куски — у каждого своя равнодействующая.
- Уравнения: по три на каждую часть (моменты — прежде всего относительно опор и шарниров части) и уравнения
  для всей конструкции, где внутренние силы взаимно уничтожаются. Определимость — по рангу против 3·(число частей).
- В решении появляется шаг «Расчленяем конструкцию по шарнирам», уравнения помечены номером части (ΣM_D^II),
  в пояснениях — почему силы другой части или внутренние силы не входят в уравнение.
- Без шарниров расчёт и текст прежние (проверяется всеми эталонами прототипа).

Эталоны — Мещерский 3.37, 4.32, 4.33, 4.34, 4.37, 4.38 (`TEXTBOOK_COMPOSITE`, `tests/composite.test.ts`);
для них и для 5000 случайных составных конструкций независимо проверяется равновесие каждой части.
Готовые задачи: «Составная балка с шарниром» (4.32), «Трёхшарнирная рама (арка)» (4.34).

## Скользящая заделка (Яблонский, С.1, С.3, С.4)

Связь, которая не даёт повернуться и сместиться поперёк направляющей, но пускает вдоль неё: реакция R
перпендикулярна направляющей, плюс реактивный момент M.

- **Опора** «Скользящая заделка» (палитра конфигуратора, кнопка «Скольз. заделка»): направляющая горизонтальна,
  вертикальна или наклонна под углом α (`type: 'slide'`, `side`, `angle`). По умолчанию — вдоль участка.
  На чертеже — втулка с двумя линиями и штриховкой.
- **Соединение частей** — свойство точки, как шарнир (`node.slide` — угол направляющей; блок конфигуратора
  «Скользящие заделки между частями»): на вторую часть действуют взаимные сила R_S поперёк направляющей и момент M_S,
  на первую — такие же в обратную сторону. Шарнир и скользящая заделка в одной точке заменяют друг друга.
- В решении шаг «Расчленяем конструкцию по скользящим заделкам» (или «по соединениям частей», если есть и шарниры),
  определимость считается с учётом двух взаимных неизвестных. «Возможные перемещения» принимают такие конструкции:
  освобождая реактивный момент, заделку заменяют ползуном, который может поворачиваться.
- **Проверка** (`tests/slide.test.ts`): пример задания С.3 Яблонского в двух вариантах соединения (`YAB_FRAMES`,
  «Задачник» → Яблонский) сходится с книгой; реакции те же, что дают «Возможные перемещения»; файл туда-обратно.

## Эпюры Q и M (вкладка «Изгиб»)

Своей схемы у раздела нет: он берёт конструкцию и найденные реакции из «Балок и рам» (отмена, файлы и название — общие;
«Изменить схему» переводит на ту вкладку). Готовые задачи: пример Антонова (рис. 8.5), задача 2 Антонова (схема 7),
консоль, а также балки из «Балок и рам».

- **Расчёт** (`bending/model/forces.ts`) — метод сечений для любой конструкции-дерева: у участка есть начало P0 и орт u,
  вклад каждой нагрузки своей части в N, Q, M — многочлен от координаты сечения (сила, пара, распределённая нагрузка
  за участком — точными равнодействующими, на участке — интегралом). Для балки u направлен слева направо; для рам
  с вертикальными участками понадобится только выбрать участки и их «свою» часть — формулы те же.
- **Балка** (`bending/model/beam.ts`): участки между концами, опорами, точками сил и пар, концами распределённой нагрузки
  и шарнирами; на каждом — Q(z), M(z), экстремумы M (где Q = 0).
- **Решение** (`bending/text/solution.ts`): реакции, правило знаков, участки, формулы Q(z) и M(z) в буквах и числах,
  значения на концах и в экстремуме, проверки скачков (Q — на силу, M — на пару; M = 0 на концах и в шарнирах),
  ответ — наибольшие |Q| и |M| и опасное сечение.
- **Чертёж** (`bending/draw/diagrams.ts`): эпюры под расчётной схемой в том же масштабе, со штриховкой, знаками и значениями.
- **Правила и обозначения** (`src/shared/conventions.ts`, панель во вкладке, запоминаются в браузере): сторона эпюры M —
  сжатые волокна (машиностроение, Антонов; по умолчанию) или растянутые (строительная механика); ось вдоль балки z или x;
  обозначения Q, M или Q_y, M_x. Знаки Q и M — как почти во всех учебниках: Q «+», если слева сила вверх;
  M «+» при изгибе выпуклостью вниз.
- **Проверка** (`tests/bending.test.ts`): эталон Антонова (Q = ⅔ql и −4/3·ql, M_max = 8/9·ql²); для готовых задач
  и 3000 случайных балок (в том числе составных) Q и M по левой части совпадают с независимым расчётом по правой части
  (`tests/helpers/cut.ts`: свои направления сил, интегрирование нагрузки по Симпсону), скачки равны силам и парам,
  M = 0 на свободных концах и в шарнирах. Проверено, что порча формулы нагрузки ловится.

## Уравнения Лагранжа второго рода

Вкладка «Уравнения Лагранжа» (Мещерский §48): по обобщённым координатам (1–3), кинетической энергии T(q, q̇, t),
потенциальной энергии Π(q, t) и непотенциальным обобщённым силам Qⱼ^н выводит уравнения движения в буквах.

- **Символьный движок** (`src/shared/sym.ts`): выражение — сумма членов «коэффициент × произведение атомов в степенях»
  (переменные, время, функции, скобки). Подобные приводятся, sin² + cos² = 1 упрощается; суммы без скоростей
  (l + rφ, m₁ + m₂) остаются скобками, поэтому уравнение сокращается на общий множитель, как в задачнике.
  Частные производные и полная производная по времени — по правилу сложной функции.
- **Решение:** ∂T/∂q̇ⱼ, d/dt(∂T/∂q̇ⱼ), ∂T/∂qⱼ, Qⱼ = −∂Π/∂qⱼ + Qⱼ^н, уравнение и его сокращённый вид; ускорения
  (для одной координаты — формулой, иначе система A·q̈ + b = 0); интегрирование Рунге — Кутта 4-го порядка
  с графиками q(t); обобщённый интеграл энергии H = Σ q̇ ∂T/∂q̇ − T + Π (для T, квадратичной по скоростям, H = T + Π) —
  его сохранение проверяет интегрирование; малые колебания около заданного положения: M·δq̈ + K·δq = 0, det(K − ω²M) = 0.
- **Положения равновесия и устойчивость** (Мещерский §52, 47, 31; Яблонский, Д.22; `lagrange/model/equil.ts`):
  в покое ∂W/∂qⱼ = Qⱼ^н(q, 0), где W = Π − T₀ (T₀ — часть T без скоростей: во вращающейся системе так находится
  относительное равновесие). Одна координата — все корни на заданном отрезке (перемена знака, касание; изломы W,
  например |sin(φ/2)|, — отдельно, полюсы отбрасываются); устойчивость — по K = W″ (Лагранж — Дирихле: минимум —
  устойчиво, максимум — нет), при W″ = 0 — по знакам обобщённой силы с обеих сторон и порядку первой ненулевой
  производной; тождественно нулевая сила — безразличное равновесие. Несколько координат — метод Ньютона от
  приближения q*, устойчивость по собственным значениям матрицы жёсткости. T можно не задавать — тогда только статика;
  с T — ещё и частоты малых колебаний около устойчивых положений.
- **Ввод:** скорость — штрихом (x′, φ′), греческие буквы — символом или латиницей (phi, theta), неявное умножение,
  sin²φ, √. Неизвестное обозначение подсвечивается.
- **Проверка** (`tests/lagrange.test.ts`): производные — против численных; Мещерский 48.11 ((l + rφ)φ̈ + rφ̇² + g sin φ = 0),
  48.27, 48.28 (уравнения как в ответах), 48.37–48.38 (уравнения эллиптического маятника и период 2π√(m₁l/((m₁ + m₂)g));
  T в декартовых координатах даёт те же ускорения), 48.35 (ω² = c(m₁ + m₂)/(m₁m₂), центр масс движется равномерно).
  Равновесие (`tests/equil.test.ts`): пример Д.22 Яблонского — шесть положений, как в книге (0 — излом, минимум;
  60° и 300° — максимум; 112,89° и 247,11° — минимум; 180° — максимум); 52.4 — sin³φ = a/l; 48.27 — cos θ = g/(aω²)
  устойчиво; маятник с постоянным моментом; двойной маятник (ω² = (2 ± √2)g/l); на 60 случайных потенциалах корни
  и устойчивость совпадают с независимым перебором по 200 000 точкам.
- **Реакции, отрыв, программное движение** (Мещерский §43, Яблонский Д.20; `lagrange/model/react.ts`): реакция
  связей на тело R = m·a_C − m·g (в проекциях на оси или на направление e(β) и нормаль) — в буквах для одной координаты;
  момент отрыва (смена знака или касание нуля проекции) или достижения положения, дальше — парабола центра масс;
  обобщённые силы Qⱼ по заданным законам qⱼ(t). Подробно — [docs/sections/stability2.md](docs/sections/stability2.md),
  проверка — `tests/react.test.ts`.
- **Параметр по положению равновесия** (пункт 29, `model/inverse.ts`): при каком значении параметра (угловой скорости
  регулятора, жёсткости) заданное положение q* — положение равновесия. Если параметр входит множителем p^k, ответ
  выводится в буквах (p^k = −A/B); иначе — корни на отрезке. Для найденного значения — устойчивость и проверка, не
  обращается ли обобщённая сила в нуль при любом q (безразличное равновесие, 47.19). Готовые задачи 47.13, 47.16–47.19;
  см. [docs/sections/analytic2.md](docs/sections/analytic2.md).
- Не вошло: §47 (общее уравнение динамики) отдельным режимом — его задачи (блоки, катки) решаются здесь же, если
  записать T и Π, или во вкладке «Кинетическая энергия».

## Колебания систем

Вкладка «Колебания систем» (Мещерский §54; Яблонский Д.24, Д.26; `src/modules/vibration/`): малые колебания около
устойчивого равновесия, до шести координат. Линейная система A·q̈ + (B + G)·q̇ + C·q = H sin pt (H cos pt или постоянная
сила с момента t = 0); A, C, B — коэффициенты квадратичных форм T, Π и диссипативной функции Φ, G — гироскопические.

- **Как задать систему** (четыре режима):
  - *по T и Π* — формулами, как в «Уравнениях Лагранжа» (тот же разбор, `shared/sym.ts`), можно точными (cos φ):
    aᵢⱼ = ∂²T/∂q̇ᵢ∂q̇ⱼ, cᵢⱼ = ∂²(Π − T₀)/∂qᵢ∂qⱼ, bᵢⱼ = ∂²Φ/∂q̇ᵢ∂q̇ⱼ в положении q* — в буквах и в числах; проверяется,
    что q* — равновесие; если T линейна по скоростям (вращающаяся система), — гироскопические коэффициенты
    gᵢⱼ = ∂²T/∂q̇ᵢ∂qⱼ − ∂²T/∂q̇ⱼ∂qᵢ (54.20);
  - *цепочка тел* — грузы на пружинах, диски на валу (жёсткость участка задана или c = GπD⁴/(32l)), грузы на натянутой
    нити (c = N/l); пружины к неподвижным точкам, демпферы; концы свободны, закреплены, левый может двигаться по закону
    ξ₀ sin pt (кинематическое возбуждение — сила c₀ξ₀ sin pt + b₀ξ₀p cos pt на первое тело);
  - *грузы на балке* — коэффициенты влияния δᵢⱼ невесомой балки на шарнирах и заделках (в том числе статически
    неопределимой) методом перемещений (`vibration/model/beam.ts`; для сосредоточенных сил совпадает с интегралом
    Мора), дробью от L³/(EJ), если она простая; C = δ⁻¹. Груз с моментом инерции J или со смещённым на e центром масс
    даёт вторую координату — поворот сечения; груз на вершине стойки высотой h, жёстко связанной с балкой (та же EJ,
    стойка нерастяжима), — горизонтальное смещение x и прогиб y (54.36);
  - *гаситель* — масса m₁ на пружине c₁ (или в резонансе, c₁ = m₁p²) под силой H sin pt и гаситель m₂, c₂: по наибольшей
    амплитуде A — c₂ = H/A, m₂ = c₂/p², по массе — c₂ = m₂p².
- **Решение:** уравнения малых колебаний; уравнение частот det(C − k²A) = 0 (для двух координат — биквадратное
  с числами), корни — обобщённая симметричная задача (Холецкий + вращения Якоби, `vibration/model/linalg.ts`);
  нулевые частоты (свободная система, циклическая координата), неустойчивость (k² < 0), кратные частоты; формы главных
  колебаний — коэффициенты распределения (первая ненулевая амплитуда равна 1), для двух координат — формулой; узлы
  цепочки (в том числе узловое сечение вала), центры поворота груза на балке; проверка ортогональности; главные
  координаты (q = Σ A⁽ˢ⁾θₛ, T и Π — суммы квадратов); движение по начальным условиям и под постоянной силой —
  формулы qⱼ(t) через главные координаты; при «пропорциональном» сопротивлении — затухание hₛ каждой главной
  координаты, иначе — численно; вынужденные колебания: X = (C − p²A)⁻¹H с определителями Крамера, с сопротивлением —
  комплексные амплитуды и фазы; резонанс; частоты, при которых амплитуда нагруженной координаты равна нулю (гашение,
  антирезонанс), — собственные частоты системы с этой координатой, закреплённой; парциальные частоты √(cⱼⱼ/aⱼⱼ).
  Сила H sin pt или H cos pt; её амплитуда может задаваться **статическим смещением** δ точки приложения по линии
  действия (поворотом тела под моментом) от постоянной силы той же величины, как в Яблонском Д.26: столбец H — сила
  единичной амплитуды, F₀ = δ/(hᵀC⁻¹h). **Резонанс** без сопротивления — частное решение в главных координатах
  с вековым членом: θₛ = Qₛ/(2Mₛkₛ)·t sin pt (при H cos pt), остальные θᵣ = Qᵣ/(Cᵣ − Mᵣp²)·cos pt.
  **Однородная цепочка** (одинаковые тела, звенья, пружины к неподвижным точкам) — как звено бесконечного фильтра:
  полоса пропускания c₀/m ≤ p² ≤ (c₀ + 4c)/m, cos μ = 1 − (mp² − c₀)/(2c), амплитуды Xₖ = a cos μk + b sin μk в полосе
  и убывающие вне её (54.47–54.50). **Гироскопическая система**: частоты — корни det(C − k²A + ikG) = 0 (многочлен
  от k² по значениям определителя на окружности, корни — методом Дюрана — Кернера), формы — комплексные (модули
  и сдвиги фаз), неустойчивость (k² < 0 или комплексный) и гироскопическая стабилизация (C не положительно
  определена, а частоты вещественны); движение — численно.
- **Чертёж:** схема (цепочка, балка со стойками, гаситель), формы главных колебаний (смещения тел, упругая линия балки,
  для системы по T и Π — столбики; у гироскопической системы формы только в тексте), графики qⱼ(t) (Рунге — Кутта по линейной системе) и амплитуд вынужденных колебаний по частоте
  с отметками kₛ и p.
- **Проверка** (`tests/vibration.test.ts`): 41 готовая задача — Мещерский (38 номеров) 54.1–54.5, 54.8, 54.9,
  54.13–54.18, 54.20, 54.23, 54.27–54.34, 54.36–54.38, 54.40, 54.42–54.52, и Яблонский — пример Д.24 и пример Д.26
  (антирезонанс, первый и второй резонансы) — частоты, отношения амплитуд, коэффициенты законов движения, амплитуды

- **Расхождения с книгой** (в примечаниях к задачам и в тестах):

## Принцип возможных перемещений

Вкладка «Возможные перемещения» находит реакции и неизвестные нагрузки конструкции из «Балок и рам» (Мещерский §46),
не составляя уравнений равновесия для каждого тела; схема общая, правится там же.

- **Метод** (`src/modules/virtual/model/virtual.ts`): у каждой жёсткой части три малых перемещения — сдвиг и поворот.

## Эпюры N, Q, M для рам

## Стержневые системы

Антонов, гл. 3 (рис. 3.7, 3.8, 3.10) и п. 4.5; своя модель (`src/modules/rods/model/rods.ts`) и файл проекта.

- **Система:** узел, в котором сходятся стержни, или абсолютно жёсткий брус на шарнирно-неподвижной опоре и катках.
  Стержни (до 6) — с шарнирами на концах: точка крепления, направление к неподвижному шарниру, длина, площадь c·A,
  E, α, нагрев ΔT, неточность изготовления δ (длиннее «+», короче «−»). Нагрузки: силы, пары и равномерная нагрузка на брус.
- **Расчёт** — методом перемещений (u, v узла; u, v, θ бруса; связи опор исключаются): Δl_i — проекция перемещения точки
  крепления на ось стержня, N_i = (E_iA_i/l_i)(Δl_i − α_iΔT_i l_i − δ_i). Степень статической неопределимости — число
  неизвестных усилий минус ранг уравнений равновесия; стержни на одной прямой (брус между заделками) — одномерная задача.
  Механизм и зависимые опоры распознаются.
- **Решение** в принятом в учебниках виде: неизвестные и степень неопределимости, уравнения равновесия (без реакций —
  моменты относительно шарнира), уравнения совместности деформаций (удлинения «лишних» стержней через удлинения
  базовых, например Δl₂ = 0,6·Δl₁), закон Гука с нагревом и неточностью, усилия, реакции, проверка.
- **Что найти:** усилия, напряжения и проверка прочности (запас по σт); подбор площади — σ_i = a_i/A + b_i, где b_i —
  напряжения от нагрева и неточности (от A не зависят), отсюда A ≥ A_min (и, если надо, A ≤ A_max); допускаемая нагрузка
  по [σ] — множитель λ ко всем нагрузкам; предельное состояние — начало текучести, предельная нагрузка (линейное
  программирование: максимум λ при |N_i| ≤ σт·A_i), [F]п = F_пр/n и сравнение с [F] по допускаемым напряжениям.
- **Схема:** растянутые стержни — синие, сжатые — красные, усилия у стержней; пунктиром — положение после деформации
  (перемещения увеличены).
- **Эталоны** (`tests/rods.test.ts`): пример п. 4.5 — N₁ = N₃ = P/5, N₂ = 4P/5, [P] = (5/4)[σ]A, P_пр = 2σт·A, отношение 8/5;
  брус с зазором (рис. 3.10) — P·l₁/(EA) + P·l₂/(2EA) = Δ; брус на шарнире и двух стержнях — N₁ = 0,6F, N₂ = 1,2F;
  нагретый стержень между заделками — σ = −EαΔT; предельная нагрузка бруса на шарнире — Σσт·A_i·h_i/M;
  подбор и допускаемая нагрузка дают |σ|max = [σ].
- **Расхождения с пособием:** в п. 4.5 сказано, что предельная нагрузка «почти в два раза» больше допускаемой —
  по формулам пособия отношение 8/5 = 1,6. В п. 3.5 про систему рис. 3.7 сказано и «один раз статически
  неопределима», и «статически определима», и что нужны «два дополнительных уравнения» — по рисунку система один раз
  неопределима (три усилия, два уравнения равновесия), нужно одно уравнение совместности.

## Усталостная прочность

Антонов, гл. 11; модель `src/modules/fatigue/model/fatigue.ts`, файл проекта.

- **Цикл** (п. 11.2) нормальных и (или) касательных напряжений задаётся σ_max и σ_min или σ_m и σ_a:

  1/n² = 1/n_σ² + 1/n_τ²; сравнение с [n] (1,4…1,7); первое приближение п. 11.5 1/n = σ_a/σ₋₁ + σ_m/σ_т (если задан
  σ_т). Предупреждения: сжимающее среднее напряжение, K_D < 1. График цикла по времени и диаграмма предельных
  амплитуд (прямые образца и детали, рабочая точка, луч до предельного цикла).
- **Обозначения пособия.** В п. 11.5 K = K_F·K_d·β/K_σ < 1 и σ̄₋₁ = σ₋₁·K, а в пп. 11.6–11.7 K ≥ 1 умножает
  амплитуду — это обратная величина; в разделе везде K_D ≥ 1 (так формула запаса даёт верный результат с обоими
  способами вычисления K_D). Ещё два места: прямая предельных циклов A₀B₀ и ψ_σ = σ₋₁/σ_в построены по пределу
  прочности, а «первое приближение» п. 11.5 — по пределу текучести σ_т; оценка σ₋₁ ≈ (0,4…0,5)σ_в в п. 11.3 и
  (0,55…0,7)σ_в в п. 11.7.
- **Примеры** — условные числа (в пособии к главе 11 задач нет); проверка по формулам — `tests/fatigue.test.ts`.

## Кинематика точки

Мещерский §10–12; Яблонский К.1, К.2; модель `src/modules/pointkin/model/kin.ts`, файл проекта.

- **Способы задания:** координатный x(t), y(t), z(t); естественный — путь s(t) по траектории известного радиуса
  кривизны ρ; полярный r(t), φ(t); цилиндрический r(t), φ(t), z(t); сферический r(t), долгота φ(t), широта θ(t)
  (угол с плоскостью xy, как в Мещерском 10.22: x = r cos θ cos φ, y = r cos θ sin φ, z = r sin θ). Формулы
  с символьными производными (как в «Динамике точки»).
- **Решение:** производные формулами, скорость и ускорение (проекции, модули, углы с осями), касательное и нормальное
  ускорения, радиус кривизны; в полярных координатах — v_r, v_φ, a_r, a_φ; в цилиндрических — и v_z, a_z; в
  сферических — v_r = ṙ, v_φ = rφ̇ cos θ, v_θ = rθ̇, a_r = r̈ − rθ̇² − rφ̇² cos²θ, a_φ = (rφ̈ + 2ṙφ̇) cos θ − 2rφ̇θ̇ sin θ,
  a_θ = rθ̈ + 2ṙθ̇ + rφ̇² sin θ cos θ. Траектория в одном масштабе с векторами скорости и ускорения; для
  естественного способа — графики s(t), v(t).
- **Уравнение траектории** (`model/traj.ts`; §10, Яблонский К.1): исключение t — ищется многочлен P(x, y)
  наименьшей степени (до четвёртой), равный нулю во всех точках траектории (значения одночленов xⁱyʲ в 240 моментах
  времени, нуль-пространство матрицы одностороннего метода Якоби, проверка в других точках); коэффициенты
  приводятся к целым, если это возможно; явный вид y = f(x) или x = g(y), если переменная входит линейно; вид кривой
  (прямая, парабола, эллипс, окружность, гипербола — с центром, полуосями, радиусом). Пространственная траектория —
  уравнения проекций на координатные плоскости (цилиндры, на пересечении которых она лежит). Начальная точка и
  пределы координат на отрезке времени (какую часть кривой проходит точка). У циклоиды, спирали, винтовой линии
  (в проекции с z) алгебраического уравнения нет — так и сказано.
- **Законы движения по времени** (пункт 20; `model/ext.ts`, `model/cam.ts`, интегратор `src/shared/integ.ts`;
  подробно — [docs/sections/kinlaws.md](docs/sections/kinlaws.md)): режимы «путь и закон движения по траектории s(t)»
  (расстояние, путь с остановками, положения через равные промежутки; 10.1, 10.4, 10.7, 10.20), «закон движения по
  заданному ускорению» (12.7), «гармонические колебания» (центр, амплитуда, частота, фаза; 10.8, 10.9, 21.1), «бросок
  под углом» (высота, дальность, два угла попадания, парабола безопасности; 10.15–10.18), «кулачки» (контур ↔ закон
  движения толкателя, круговой кулак; 14.15–14.19) и тороидальные координаты (12.37–12.39).
- **Равнопеременное движение** (`model/uniform.ts`; 12.1–12.10, Яблонский К.2): из v₀, v, a, t, s известны любые
  три — тот же решатель, что у равнопеременного вращения; скорости в м/с или км/ч; на закруглении радиуса ρ —
  нормальное и полное ускорения в начале, в конце и в заданный момент t′; закон s(t) = v₀t + (a/2)t² (коэффициенты
  c₁, c₂ в К.2). Графики s(t), v(t).
- **Эталоны:** 10.2, 10.6, 10.11, 10.20–10.21, 10.22 (уравнения траекторий), 11.15, 11.17, 12.1, 12.2, 12.5, 12.8,

## Плоский механизм

Мещерский §16, 18, 22–23 (кулисы), 38 (кинетическая энергия механизмов), 46 (равновесие механизмов); модели
`src/modules/mechanism/model/mech.ts` (кинематика), `forces.ts` (силы и массы), `solve.ts` (параметр положения, теорема
об энергии, график), файл проекта.

- **Положение:** точки задаются построениями — координатами, от точки по длине и углу (угол — от оси x или от
  направления на другую точку), на расстояниях от двух точек (пересечение окружностей, сторона выбирается), на прямой
  на расстоянии от точки, на отрезке (доля длины), пересечением двух прямых (каждая — через две точки или через точку
  под углом). Числа — формулы (15/cos(π/6), 30sqrt(3)); углы — в градусах. Точка вне звеньев — вспомогательная для
  построения (неподвижная).
- **Звенья и связи:** звено — жёсткое тело из отмеченных точек; связи — неподвижный шарнир, ползун на прямой
  направляющей, колесо катится по неподвижной прямой, зацепление (качение) двух колёс, в том числе с неподвижным и
  внутреннее, **кулисный камень** (точка скользит вдоль прямой, жёстко связанной с другим звеном; камнем может быть и
  неподвижная ось качающегося цилиндра), **поступательное движение звена** (ω = 0). Ведущие — ω и ε звена, скорость и
  ускорение точки вдоль направления или их векторы.
- **Решение:** скорости и ускорения — из линейных систем (v_B = v_A + ω × AB, a_B = a_A + ε × AB − ω²AB плюс связи);
  для кулисы (v_A − v_G)·n = ω(r·u), (a_A − a_G)·n − ε(r·u) = 2ωv_r − ω²(r·n). Подвижность механизма — по рангу системы
  без ведущих; при нехватке или избытке ведущих — сообщение. В тексте — по-учебному: МЦС каждого звена и v = ω·PM;
  кулисный камень как сложное движение точки (v = v_e + v_r, a = a_e + a_r + a_c, кориолисово a_c = 2ωv_r); ускорения
  методом полюса (aⁿ = ω²·AB, aᵗ = ε·AB) и мгновенные центры ускорений; в ответе — радиус кривизны траектории
  ρ = v³/|v × a|. Ускорения можно отключить (задачи статики). Чертёж в масштабе: векторы скоростей и МЦС или ускорений
  и МЦУ, прорези кулис, нагрузки.
- **Силы (механизм с одной степенью свободы):** силы в точках (угол — от оси x или от направления отрезка звена),
  пары на звеньях, моменты сопротивления в шарнирах, вес масс. Одна сила или пара может быть неизвестной — она
  находится из принципа возможных перемещений Σ F·v + Σ M·ω = 0 (возможные скорости — найденные скорости; моменты
  сопротивления в равновесии не участвуют). Без неизвестной — мощность сил и приведённый момент M_пр = ΣN/ω.
- **Массы:** точечные, однородные стержни (J = ml²/12), тела с центром масс (диск, обод или заданный J_C);
  T = Σ(m v_C²/2 + J_C ω²/2) по теореме Кёнига, приведённый момент инерции J_пр = 2T/ω² (для ведущей точки —
  приведённая масса).
- **Параметр положения φ** (градусы) можно писать в любом числовом поле (угол кривошипа «φ», «90−φ»). По нему —
  **график** любой величины (координаты, скорости, ускорения точек, ω и ε звеньев, v_r и a_r камня, T, J_пр, M_пр,
  неизвестная сила) с наибольшим и наименьшим значениями (уточняются золотым сечением) и **теорема об изменении

## Тело с неподвижной точкой

Мещерский §19, 20, 25; Яблонский К.5, К.6, К.8. Своя модель (`src/modules/fixedpoint/model/`) и файл проекта. Четыре режима.

- **Сложение вращений: схема в плоскости осей** (`scheme.ts`). Плоскость чертежа — плоскость осей, как на рисунках
  книги: x — вправо, y — вверх, z — на нас. Звено вращается относительно «родителя» (стойки, водила, другого звена)
  вокруг оси в этой плоскости; ω звена — относительная угловая скорость вдоль направления оси (правило правого винта).
  Точки задаются координатами, полярно от начала, от оси звена (вдоль и поперёк) или расстояниями до осей двух звеньев
  (радиусами колёс со знаком). Касание — качение без скольжения или зацепление: скорости точек двух звеньев в точке
  касания равны; для точки в плоскости вклад каждого вращения — ω·h, h — расстояние до оси со знаком. Задаются
  относительные ω звеньев (с⁻¹, об/мин или период), скорости точек (проекция на z) с производными (ε, dv/dt) или модуль
  ускорения точки (19.9: равномерное движение с одной степенью свободы, масштаб по √a). Неизвестные ω и ε находятся из
  линейной системы (недостаток и противоречие условий — сообщениями). Абсолютные Ω = Ω_родителя + ω·e и
  ε = ε_родителя + ε_отн·e + Ω_родителя × ω·e; характер движения — вокруг неподвижной оси, неподвижной точки
  (пересечение осей цепочки), плоское (параллельные оси); мгновенная ось; аксоиды при двух равномерных вращениях.
  Скорости и ускорения точек — сложением движений по уровням цепочки (переносное, относительное, кориолисово), для
  звеньев с неподвижной точкой — с разложением на вращательное ε × r и осестремительное ω × (ω × r) (формула Ривальса);
  точки могут лежать вне плоскости (z). Чертёж: оси, колёса и конусы по точкам касания, неподвижные поверхности,
  мгновенные оси, скорости точек ⊙/⊗.
- **Углы Эйлера** (`euler.ts`). Последовательности поворотов: z–x–z (классическая), z–y–z (как в ответах 20.3–20.4),
  самолётные (20.5), корабельные А. Н. Крылова (20.7), карданов подвес в двух установках (20.1, 20.2) и своя. Законы
  углов — формулы от t; символьно — таблица направляющих косинусов и кинематические формулы Эйлера (проекции ω на
  неподвижные и связанные оси), численно в момент t₁ — ω, ε, ω(t) в неподвижных осях (годограф), точка M тела:
  v = ω × r, a = ε × r + ω × (ω × r). Регулярная прецессия — аксоиды.

  при Ω = 0; скорости точек и расстояния до оси.

## Гироскоп

Мещерский §40; своя модель (`src/modules/gyro/model/gyro.ts`) и файл проекта. Приближённая теория: H = Jω по оси
ротора; J — задан, по массе (весу) и радиусу инерции, диск или масса по ободу; единицы — техническая система (кГ,
кГ·м·с², как в книге) или СИ.

- **Вынужденная прецессия.** Собственное вращение: ω (с⁻¹, об/мин), колесо катится (ω = v/a) или бегун катится по
  основанию (ω = ω₁d/r). Поворот оси: ω₁ (с⁻¹, об/мин, °/с), по закруглению v/R, качка — наибольшая 2πθ₀/T.
  Гироскопический момент M_г = Jωω₁ sin β (правило Жуковского); опоры на оси ротора или на оси прецессии — пара сил
  ΔN = M_г/l, полные давления со статическими (вес делится между опорами — на какой опоре давление растёт, по
  направлениям ω и ω₁) или отношение к статическим боковым давлениям; бегун на шарнире — добавочное давление на
  основание ΔN = M_г/d = Jω₁² sin β/r.
- **Прецессия под действием момента:** вес ротора с плечом, сила с плечом или момент; ω_п = M₀/H, период T = 2π/ω_п.
- **Равновесие оси:** гиротахометр — пружины (α = Jωω₁/(n c a²)); маятниковый гироскоп на вращающемся основании
  (Земле): Jω·Ω_о·sin(γ − α) = H_ст·sin α.

## Принцип Даламбера

- **Тело на оси:** части — как в «Геометрии масс» (точки, стержни, диски, цилиндры, шары, брусья под любым углом,
  вырезы, массы или веса); ось вращения z, подпятник A и подшипник B в заданных точках оси; ω и ε в рассматриваемый
  момент; вал вертикальный (сила тяжести −z), горизонтальный (−y) или без силы тяжести.
- **Вращение под действием пары** (Яблонский, Д.17): вместо ω и ε задаются момент пары M, момент времени τ и ω₀;
  ε = M/J_z (с моментом силы тяжести относительно оси, если он есть), ω = ω₀ + ετ. Горизонтальный вал с центром масс
  вне оси не принимается: момент силы тяжести меняется при повороте, и ε не постоянно.
- **Решение:** масса, центр масс, центробежные моменты J_xz, J_yz; силы инерции, приведённые к центру O
  (Φ = M(ω²x_C + εy_C, ω²y_C − εx_C), M^Φ = (εJ_xz − ω²J_yz, εJ_yz + ω²J_xz, −εJ_z)); шесть уравнений кинетостатики;
  реакции — статические, динамические и полные, давления на опоры (обратны реакциям), вращающий момент для заданного ε.
- **Силы инерции в машинах** (пункт 23): режим вкладки — каталог из 13 задач §41: стержень на упоре и угле по углу φ

  паром, полиспаст, клин между пластинами, стабилизатор качки, продольная сила во вращающемся стержне, пластине, диске.
  Подробно — [docs/sections/kinetostatics.md](docs/sections/kinetostatics.md); проверка — `tests/machines41.test.ts`.
  Расхождение: 41.20 — 109,96 т по расчёту, 109,7 т в книге (0,2 %).

  вместо времени τ: ω² = ω₀² + 2εφ.
- **Натяжения нитей** — во вкладке «Кинетическая энергия»: систему отсекают по нити, и для отсечённой части

## Удар

Мещерский §44; Яблонский Д.13; своя модель (`src/modules/impact/model/impact.ts`) и файл проекта. Два тела в плоскости
(оси: x вправо, y вверх; ω > 0 — против часовой): свободное (материальная точка, шар, диск, кольцо, стержень,
пластина, радиус или момент инерции), на неподвижной оси O или неподвижная преграда. Точка удара P и нормаль n (от
тела 1 к телу 2); контакт гладкий или абсолютно шероховатый (без проскальзывания); коэффициент восстановления k;
по желанию тело 1 остаётся в теле 2 (снаряд в маятнике, шар в призме).

- **Удар:** теоремы об изменении количества движения и кинетического момента при ударе — m(u_C − v_C) = S,
  J_C(ω′ − ω) = (P − C) × S или J_O(ω′ − ω) = (P − O) × S; условие Ньютона (u₂ − u₁)·n = −k(v₂ − v₁)·n и, при
  шероховатом контакте, (u₂ − u₁)·t = 0. Удар без проскальзывания — только неупругий (k = 0): при k > 0 эти условия
  вместе могут давать прирост энергии, и модель сообщает об ошибке. Ударный импульс, скорости после удара, импульсы
  осей S_O = m(u_C − v_C) − S, центр удара J_O/(m·OC), потеря энергии и теорема Карно (ΔT = T* при k = 0,
  ΔT = (1 − k)/(1 + k)·T* при гладком ударе).
- **До удара:** скорости заданы; падение с высоты h; груз на нити, отклонённый на α₀; тело на оси, отпущенное
  в положении, повёрнутом на φ₀ (ω — из интеграла энергии).
- **После удара:** подъём (и полный путь шарика при повторных отскоках от плиты), отклонение нити, скольжение с

  среднее сопротивление грунта при забивке сваи.
- **Обратные задачи:** скорость тела 1 по углу отклонения тела после удара (баллистический маятник) или наименьшая

- **Эталоны:** 44.1–44.7, 44.10, 44.12, 44.14, 44.16–44.20, 44.22–44.26 и пример Д.13 Яблонского (удар цилиндра о

## Удар и колебания

Мещерский §32, §53; Антонов, гл. 10; своя модель (`src/modules/oscillation/model/osc.ts`, `elastic.ts`) и файл проекта.

- **Груз на упругом элементе** движется горизонтально, вертикально или по гладкой наклонной плоскости; x отсчитывается
  от положения статического равновесия (δ_ст = (P sin α + Q)/c). Единицы — согласованные, выбираются: длина (м, см, мм),
  сила (Н, кН, кГ, Г, т); g задаётся (в части задач Мещерского g = 9,8 м/с²).
- **Жёсткость:** задана; по статической деформации; по измеренному периоду (в том числе с сопротивлением — тогда
  k² = (2π/T₁)² + n²); собрана из элементов. Элементы — пружина (в том числе под углом к оси, c·cos²α, и на рычаге,
  c·(a/b)²), стержень (EA/l) и балка шести схем (c = 1/δ₁₁). Внутри ступени элементы параллельны, ступени — последовательны.
  Трос работает только на растяжение: момент ослабления отмечается. Масса одиночного элемента приводится к грузу
  по Рэлею: β = 1/3 (пружина, стержень), 17/35, 33/140, 13/35 (балки).
- **Сопротивление:** вязкое (b, n, по уменьшению амплитуды в q раз за N колебаний, по периоду T₁) — все три случая
  n < k, n = k, n > k; сухое трение — по полуразмахам со смещённым центром ±fN/c и областью застоя |x| ≤ f₀N/c.
- **Возмущение:** H sin(pt + δ), две гармоники, неуравновешенный ротор (H = m₀ep²), движение точки крепления (H = ca),
  движение основания (виброграф, сейсмограф — x относительно основания), сила a·t, F₀e^{−βt}, постоянная сила время τ,
  нарастание до F₀, кулачок (подробно — [docs/sections/oscillation.md](docs/sections/oscillation.md)). Частное решение,
  резонанс (x_p = −(h/2k)·t cos kt), коэффициент динамичности, сдвиг фазы, частота и величина наибольшей амплитуды,
  сила, передаваемая на основание.
- **Начальные условия:** смещение от равновесия; начальная деформация элемента; равновесие под другой нагрузкой
  (груз сняли или добавили); падение с высоты h — удар: K_д = λ_max/δ_ст, проверка формулой
  1 + √(1 + 2h/(δ_ст(1 + βm_эл/M))), напряжения σ_max = K_д·σ_ст и проверка по [σ] для одиночного стержня или балки;
  момент отрыва груза от элемента.
- **Обратные задачи** (флажок «Найти неизвестное»): параметр — c, l, E, J, A, g, b, вес, амплитуда или частота возмущения,
  h — по измеренной T₀, T₁, k, амплитуде, сдвигу фазы, наибольшей амплитуде; все корни (до и после резонанса), выбор

## Геометрия масс

- **Части:** точечная масса, тонкий стержень, тонкое кольцо (обод), диск или сплошной цилиндр, полый цилиндр

## Сходящиеся силы

Мещерский §1–2, 6–7; своя модель (`src/modules/converging/model/forces.ts`) и файл проекта. Две задачи:

- **Равновесие узла.** Силы в одной точке: известные (модуль и направление) и неизвестные по модулю — нить
  (только растяжение), стержень («+» — растяжение), гладкая опора (только давит). Направление — углом к оси x
  на плоскости или вектором к другому концу нити или стержня в пространстве. Решение — проекции на оси

## Пространственное тело

Твёрдое тело в пространстве (Мещерский §8), своя модель (`src/modules/spacebody/model/body.ts`) и файл проекта.

- **Ввод:** точки (x, y, z); опоры — сферический шарнир и подпятник (X, Y, Z), подшипник или петля с осью (две реакции
  поперёк оси), стержень или нить к неподвижной точке (усилие вдоль, «+» — сжатие), гладкая опора (реакция по нормали n);
  силы — составляющими или модулем вдоль направления к точке, с флажком «модуль неизвестен». **Связанные силы:**
  модуль силы можно задать долей другой, T = k·t (натяжения ветвей ремня, Яблонский С.7): если t известна, T тоже
  известна; если t неизвестна, обе силы входят в уравнения одной неизвестной t.
- **Решение:** уравнения-кандидаты — моменты относительно осей, параллельных координатным и проходящих через опоры,
  и три проекции; сначала уравнения с одним неизвестным, остальное совместно; проверка неиспользованной проекцией.
  Статусы: определимо, неопределимо (ранг 6, неизвестных больше), не закреплено (ранг меньше), равновесие невозможно
  (связи допускают движение, и нагрузка его вызывает).
- **Чертёж** — аксонометрия (x к наблюдателю, y вправо, z вверх) с опорами, силами и реакциями.
- **Эталоны:** Мещерский 8.24, 8.25, 8.26 — все реакции совпадают с книгой; главный вектор и главный момент
  проверяются независимым расчётом. Готовый пример — вал со шкивом и зубчатым колесом (натяжения ремня T = 2t).

## Трение и односторонние связи

Встроено в «Балки и рамы»: опора «Трение» (шероховатая поверхность) и флажок «Односторонняя связь» у катка.

- **Связи.** Опора с трением даёт нормальную реакцию N ≥ 0 и силу трения |Fтр| ≤ f·N вдоль поверхности
  (положительное направление — нормаль, повёрнутая на −90°); при k > 0 — момент сопротивления качению |Mк| ≤ k·N.
  Односторонний каток: R ≥ 0 — опора может оторваться (опрокидывание).
- **Расчёт** (`solver/friction.ts`, симплекс-метод — `src/shared/lp.ts`). Если искомая нагрузка одна — её наименьшее
  и наибольшее значения, при которых существуют реакции, удовлетворяющие уравнениям равновесия и неравенствам.
  Для каждой границы — предельное состояние: где трение достигло f·N (и куда готова скользить точка), где связь
  отрывается (вокруг какой точки опрокидывание), где начинается качение. Без искомой нагрузки — возможно ли
  равновесие и наименьший коэффициент трения, при котором оно возможно.
- **Эталоны:** Мещерский 3.23 (кран, Q ≤ 5,18), 3.25 (лебёдка, P ≥ 6), 4.79 (каток, P = 5,72), 4.66 (лестница,
  tg α ≥ (P + 2p)/(2f(P + p))), 4.67 (лестница, трение о стену и пол, BP = AB/2); брус на наклонной плоскости —
  G(sin α ∓ f cos α). В предельных состояниях равновесие проверяется независимым расчётом сил, неравенства — отдельно,
  в том числе на 1500 случайных конструкциях. Готовые задачи: «Брус на наклонной плоскости», «Кран на рельсах».

## Контакт тел

Встроено в «Балки и рамы» (конфигуратор → «Отдельные тела и связи между ними»; эталоны — Мещерский §2–4, Яблонский
С.5, С.9). Задачи на контакт тел — `src/modules/frames/model/contacts.ts`, тесты — `tests/contact.test.ts`.

- **Тела.** Кроме основной рамы можно поставить отдельное тело: его начальная точка смещена от точки другого тела
  на (Δx, Δy), из неё участки строят тело как обычно (`Node.place`). Тело без участков — **тело-точка** (материальная
  точка): для него два уравнения проекций. Тела-точки — бруски, клинья, цилиндры, у которых все силы сходятся
  в центре, неподвижные блоки и точки крепления нитей (с шарнирно-неподвижной опорой). Тело со смещением 0 сразу
  касается выбранной точки.
- **Связи между телами** (`Structure.links`): **касание** двух совпадающих точек — давление N по общей нормали
  (угол нормали — направление давления на тело второй точки), связь односторонняя (N ≥ 0); при f > 0 ещё сила трения
  вдоль касательной, |Fтр| ≤ f·N. У тела-точки положение условно, поэтому его касание может быть в стороне — тогда
  для всей системы берутся только проекции. **Нить** от точки к точке, в том числе через блоки (точки других тел;
  размеры блоков и трение на них не учитываются): одно натяжение T ≥ 0 по всей нити. **Шарнир между телами** в
  совпадающих точках — силы X, Y; им замыкаются контуры (Яблонский С.9).
- **Расчёт.** Уравнения — по три на каждое тело (по два для тела-точки) и для всей системы; силы связей входят
  в уравнения тел с противоположными знаками. Если определимо — обычное решение и проверка знаков: давление или
  натяжение < 0 — «равновесие невозможно: тела разойдутся, нить провиснет». Если неизвестных больше из-за
  односторонних связей — **перебор случаев**, как в книге: какие связи работают (сила остальных равна нулю),
  подходит случай, где все давления и натяжения не отрицательны. С трением между телами (или при искомой
  нагрузке и лишних односторонних связях) — расчёт с неравенствами, как у опор с трением: границы искомой нагрузки
  и предельные состояния (какое тело по какому скользит, где тела расходятся, где нить провисает); без искомой
  нагрузки — возможно ли равновесие и одно из распределений сил — с наименьшим натяжением нитей.
- **Чертёж:** касание — линия касательной со штриховкой со стороны давящего тела (с трением — частая), нить —
  тонкая линия, блок — кружок, тело-точка — точка, шарнир между телами — кружок; на расчётной схеме — давление,
  трение и натяжение.
- **Ограничения.** Положение равновесия (угол, размер) и трение в шарнирах — см. «Положение равновесия и трение
  в шарнирах»; трения в опорах качения нет. Вкладки «Изгиб», «Рамы: эпюры N, Q, M» и «Возможные перемещения» схемы
  из нескольких тел не принимают.
- **Эталоны** (17 задач): Мещерский 2.42, 2.45, 2.46, 2.65–2.68, 3.35, 4.54, 4.55, 4.57, 4.58, 4.59, 4.76;
  Яблонский С.5 (оба примера) и С.9. Равновесие каждого тела проверяется независимым расчётом (свои координаты
  и направления сил), неравенства — отдельно, в том числе на 400 случайных парах балок.

  сцепления и давление (9,4 и 94) до расчёта реакций; остальные величины совпадают.

## Положение равновесия и трение в шарнирах

Встроено в «Балки и рамы» (пункт 17; конфигуратор → «Положение равновесия», карточка шарнирной опоры → «Трение
в шарнире»). Подробно — [docs/sections/position.md](docs/sections/position.md); код — `model/search.ts`,
`solver/search.ts`, `text/search.ts`, задачи — `model/positions.ts`, тесты — `tests/positions.test.ts`.

- **Поиск положения.** Неизвестен угол или размер, а не нагрузка: задаются параметр (обозначение, единица,
  промежуток) и поля схемы формулами от него — длины и углы участков, смещения тел, углы опор и касаний,
  коэффициенты трения, нагрузки. Тригонометрия в формулах — в градусах.
- **Без трения** уравнений равновесия на одно больше, чем неизвестных реакций; положения равновесия — корни
  определителя D(p) расширенной матрицы системы на промежутке. Каждый корень проверяется полным решением
  (давления и натяжения не отрицательны), для координаты движения — устойчивость по знаку dQ/dp обобщённой силы.
  Корни — кнопками в конфигураторе; решение и чертёж — в выбранном положении.
- **С трением и односторонними связями** — промежутки, где равновесие возможно (проверка линейным
  программированием на сетке, границы — делением пополам), и предельное равновесие на границах: угол откоса,
  самоторможение, опрокидывание.
- **Трение в шарнире:** момент M_тр = ρ·√(X² + Y²) против вращения, ρ = f·r или r·f/√(1 + f²) (круг трения);
  нелинейная система — методом Ньютона. Только у шарнирно-неподвижной опоры; не сочетается с поиском и со
  связями-неравенствами.
- **Эталоны** (21 задача): Мещерский 2.48–2.50, 2.54, 2.60, 2.61, 2.64, 2.70, 3.28, 3.29, 4.3, 4.6, 4.52, 4.53,
  4.56, 4.60, 4.61, 4.70, 4.72, 4.73, 4.77 — корни, границы, устойчивость и реакции сверены с формулами книги.
- **Расхождения с книгой:** 2.48 и 4.52 — округление угла (84°45′ и 82°50′ в книге, по формуле 84°44′ и 82°49′);
  2.64 — книга округляет tg α до 0,38, T_BC по расчёту 6,44, в книге 6,5; 2.70 — в ответе книги знак неравенства
  обратный, самоторможение при θ ≥ 74,02° по её формуле, а приложение находит θ ≥ arcctg f = 73,30° (заклинивание);
  3.28 — 19°6′ против 19°5′; 4.56 — у книги другой отсчёт угла (θ = 180° − φ), давление N по её формуле со знаком «−».

## Фермы

Плоская ферма: узлы с координатами, стержни с шарнирами на концах, опоры (шарнир — X и Y, каток — одна реакция
под заданным углом) и силы в узлах. Своя модель (`src/modules/truss/model/truss.ts`) и файл проекта (`module: "truss"`).

- **Расчёт** — уравнения равновесия всех узлов (2n уравнений, m + r неизвестных) методом Гаусса. Определимость:
  m + r = 2n и ранг 2n; иначе — неопределима (больше неизвестных) или изменяема (меньше, либо связи мгновенно
  изменяемы, например три шарнира на одной прямой). Правило знаков: «+» — растяжение.
- **Решение по шагам:** определимость; реакции из равновесия всей фермы (момент относительно шарнира, затем проекции);
  нулевые стержни по двум признакам (с повторным применением); вырезание узлов в порядке, где не больше двух
  неизвестных (если узлов с двумя неизвестными не осталось — остальные усилия из совместного решения);
  проверка выбранного стержня методом Риттера — сечение через три стержня ищется само, точка Риттера Kр
  (или проекция на ось, перпендикулярную параллельным стержням); ответ с «растянут/сжат/не нагружен».
- **Чертёж:** номера стержней и усилия, растянутые — синим, сжатые — красным, нулевые — пунктиром; рассечённые стержни
  и точка Kр.
- **Эталоны** — Мещерский §5: 5.7, 5.11, 5.12, 5.13, 5.14 (перекрещивающиеся стержни без шарнира), 5.15; реакции
  и усилия во всех стержнях совпадают с таблицами книги. Независимо проверяется равновесие каждого узла;
  метод Риттера и признаки нулевых стержней сверяются с общим решением.

## Наклонные участки

Участок рамы может идти под любым углом (раздел «Балки и рамы», эталоны — Мещерский §4).

- **Ввод.** В списке участков и при добавлении — стрелки ↗ ↖ ↙ ↘ и острый угол α к горизонту; новый участок
  можно задать и проекциями («4 м по горизонтали, 3 м по вертикали»): тогда длина √(Δx² + Δy²) хранится точно,
  без округления до миллиметра. Угол, кратный 90°, превращает участок в обычный горизонтальный или вертикальный.
- **Данные.** У наклонного участка `dir: "a"` и `ang` — угол к оси x от начала к концу, 0…360°, против часовой стрелки.
  Рамы только из горизонтальных и вертикальных участков считаются и рисуются как раньше (координаты с точностью
  до миллиметра, эталоны прототипа не изменились); с наклонными участками координаты не огрубляются.
- **Распределённая нагрузка** на наклонной прямой: вниз, вверх, вправо, влево или перпендикулярно участку
  («вверх» — в сторону, где выше). Интенсивность q отнесена к длине участка по его оси: Q = q·l. Нагрузку на единицу
  горизонтальной проекции (снег) нужно пересчитать: q·cos α — об этом сказано в пояснениях.
- **Опоры.** Гладкая опора посередине наклонной балки (столб, упор, край стены) — каток с наклонной поверхностью;
  кнопка «⊥ участку» ставит угол реакции перпендикулярно участку в нужную сторону.
- **Чертёж.** Размер вдоль участка (со стороны, свободной от эпюры нагрузки) и угол к горизонту в начале прямого отрезка.
  Моменты наклонных сил в решении, как и раньше, раскладываются на составляющие (теорема Вариньона).
- **Проверка.** Восемь задач Мещерского (4.7, 4.8, 4.12, 4.13, 4.14, 4.15, 4.19, 4.21 — `TEXTBOOK_INCLINED`),
  1500 случайных рам с наклонными участками и нормальной нагрузкой — независимым расчётом равновесия
  (свои координаты и нормали в `tests/helpers/equilibrium.ts`). Готовые задачи: «Лестница у гладкой стены»,
  «Стропила: ветер перпендикулярно скату». Вкладка «Изгиб» рамы с наклонными участками не принимает — для них вкладка «Рамы: эпюры N, Q, M».

## Отличия от прототипа

Исправлены ошибки, влиявшие на расчёт (`tests/fixes.test.ts`):

1. **Определимость — по рангу.** Раньше при n > 3 статус «неопределима» ставился до проверки ранга.
   Теперь: ранг 3 и n > 3 — неопределима, степень n − 3; ранг < 3 — геометрически изменяема
   (например, четыре вертикальных катка).
2. **Знакопеременная распределённая нагрузка** (q₁ и q₂ разных знаков) заменяется двумя силами Q′ и Q″ —
   по одной на каждый треугольник эпюры по обе стороны от нуля. Раньше была одна сила: при q₁ = −q₂
   она равна нулю, и пара сил терялась; в остальных случаях точка приложения уходила за участок.
   На расчётной схеме рисуются обе силы.

Исправлена ошибка этапа 4: при **открытии файла** терялись внутренние шарниры (составная конструкция
считалась как сплошная). Проверяется в `tests/store.test.ts` и в браузере.

Исправлена ошибка редактора: **«Убрать участок»** теперь работает (баг №7: `geomOK` проверялся,
пока удаляемый узел ещё был в списке узлов, и проверка проваливалась всегда).

В режиме пояснений добавлено: проекции каждой наклонной силы через угол с той осью, от которой пользователь
отсчитывал угол (угол больше 90° приводится к острому), и простое объяснение, что значит «по нормали».
