# Статика: балки и рамы

Составление, решение и проверка уравнений равновесия плоской рамы с пошаговым решением
в стиле решебника. Перенос прототипа `prototype/statika.html` на TypeScript + Vite + React.

Прототип — источник истины по поведению и ответам; в репозитории он не меняется.

## Команды

```bash
npm install
npm run dev        # приложение (http://localhost:5173)
npm test           # все тесты (Vitest)
npm run typecheck  # проверка типов
npm run build      # сборка в dist/
npm run golden     # переснять эталоны с прототипа (нужен Chromium, см. ниже)
npm run build && npm run compare:ui   # сравнить интерфейс с прототипом в браузере
npm run build && npm run e2e:files    # сохранение, открытие и отчёт в PDF в браузере
```

### Как добавить раздел

1. Папка `src/modules/<имя>/` со своими `model/`, `solver/`, `text/`, `draw/`, `ui/` — общие части брать из `src/shared/`.
2. `index.tsx` возвращает `StatikaModule` (`src/app/module.ts`): идентификатор (он же поле `module` в файле),
   подпись вкладки, хранилище (отмена, повтор, сохранение и открытие файла, уведомления), экран,
   готовые задачи `tasks` и их загрузку `loadTask` (для «Задачника»). Название задачи начинается с источника:
   «Мещерский 46.19: …», «Антонов, задача 4: …» — по нему задача попадает в нужную группу.
3. Добавить раздел в `createModules()` (`src/app/registry.ts`), в блок навигации (`src/app/nav.ts`) и отметить готовым
   в `src/app/roadmap.ts` (`status: 'done'`, `tab` — идентификатор вкладки); пока пункт не готов, его файл не открывается
   с понятным сообщением.
4. Эталоны из задачника — в тесты раздела; браузерные проверки — в `scripts/`.

### Пояснения к ходу решения

`analyze(s, { explain: true })` добавляет к решению абзацы-пояснения (класс `explain`):
какие реакции даёт каждая опора, правило знаков моментов и теорема Вариньона,
как заменяется распределённая нагрузка, почему система определима, **почему в выбранном уравнении
осталось одно неизвестное** (линия действия проходит через точку, сила перпендикулярна оси,
пара не входит в проекции, значение уже найдено), как выбрано проверочное уравнение, что значит знак «−».

Без `explain` текст совпадает с прототипом (кроме исправленных случаев ниже); `explain` только добавляет абзацы — это проверяется тестом.

## Обозначения углов и разбор плеч

- У силы, опорного стержня и наклонного катка можно выбрать обозначение угла (α, β, γ, φ, ψ, θ); значение
  по-прежнему вводится числом. В уравнениях угол пишется буквой (F·sin α·2, для угла больше 90° — sin(180° − α)),
  в подстановке — числа, в первом шаге решения — «Углы: α = 60°». Без обозначения всё как раньше.
- В режиме пояснений под каждым уравнением моментов — разбор слагаемых: какая составляющая силы, где приложена
  (для равнодействующей — в центре тяжести эпюры), почему плечо именно такое (расстояние по горизонтали или
  по вертикали от точки моментов) и откуда знак.

## Составные конструкции (внутренние шарниры)

Шарнир — свойство точки (конфигуратор → «Внутренние шарниры»; доступен в точках, где сходятся хотя бы два участка).

- Шарниры делят раму на жёсткие части (`partsOf` в `src/modules/frames/model/geometry.ts`), части нумеруются I, II, … по обходу.
- В шарнире на вторую часть действуют взаимные силы X, Y, на первую — такие же в обратную сторону
  (в книге — «±»). Опоры и нагрузки, приложенные в самом шарнире, относятся к первой части.
- Распределённая нагрузка, проходящая через шарнир, делится на куски — у каждого своя равнодействующая.
- Уравнения: по три на каждую часть (моменты — прежде всего относительно опор и шарниров части) и уравнения
  для всей конструкции, где внутренние силы взаимно уничтожаются. Определимость — по рангу против 3·(число частей).
- В решении появляется шаг «Расчленяем конструкцию по шарнирам», уравнения помечены номером части (ΣM_D^II),
  в пояснениях — почему силы другой части или внутренние силы не входят в уравнение.
- Без шарниров расчёт и текст прежние (проверяется всеми эталонами прототипа).

Эталоны — Мещерский 3.37, 4.32, 4.33, 4.34, 4.37, 4.38 (`TEXTBOOK_COMPOSITE`, `tests/composite.test.ts`);
для них и для 5000 случайных составных конструкций независимо проверяется равновесие каждой части.
Готовые задачи: «Составная балка с шарниром» (4.32), «Трёхшарнирная рама (арка)» (4.34).

## Скользящая заделка (Яблонский, С.1, С.3, С.4)

Связь, которая не даёт повернуться и сместиться поперёк направляющей, но пускает вдоль неё: реакция R
перпендикулярна направляющей, плюс реактивный момент M.

- **Опора** «Скользящая заделка» (палитра конфигуратора, кнопка «Скольз. заделка»): направляющая горизонтальна,
  вертикальна или наклонна под углом α (`type: 'slide'`, `side`, `angle`). По умолчанию — вдоль участка.
  На чертеже — втулка с двумя линиями и штриховкой.
- **Соединение частей** — свойство точки, как шарнир (`node.slide` — угол направляющей; блок конфигуратора
  «Скользящие заделки между частями»): на вторую часть действуют взаимные сила R_S поперёк направляющей и момент M_S,
  на первую — такие же в обратную сторону. Шарнир и скользящая заделка в одной точке заменяют друг друга.
- В решении шаг «Расчленяем конструкцию по скользящим заделкам» (или «по соединениям частей», если есть и шарниры),
  определимость считается с учётом двух взаимных неизвестных. «Возможные перемещения» принимают такие конструкции:
  освобождая реактивный момент, заделку заменяют ползуном, который может поворачиваться.
- **Проверка** (`tests/slide.test.ts`): пример задания С.3 Яблонского в двух вариантах соединения (`YAB_FRAMES`,
  «Задачник» → Яблонский) сходится с книгой; реакции те же, что дают «Возможные перемещения»; файл туда-обратно.

## Эпюры Q и M (вкладка «Изгиб»)

Своей схемы у раздела нет: он берёт конструкцию и найденные реакции из «Балок и рам» (отмена, файлы и название — общие;
«Изменить схему» переводит на ту вкладку). Готовые задачи: пример Антонова (рис. 8.5), задача 2 Антонова (схема 7),
консоль, а также балки из «Балок и рам».

- **Расчёт** (`bending/model/forces.ts`) — метод сечений для любой конструкции-дерева: у участка есть начало P0 и орт u,
  вклад каждой нагрузки своей части в N, Q, M — многочлен от координаты сечения (сила, пара, распределённая нагрузка
  за участком — точными равнодействующими, на участке — интегралом). Для балки u направлен слева направо; для рам
  с вертикальными участками понадобится только выбрать участки и их «свою» часть — формулы те же.
- **Балка** (`bending/model/beam.ts`): участки между концами, опорами, точками сил и пар, концами распределённой нагрузки
  и шарнирами; на каждом — Q(z), M(z), экстремумы M (где Q = 0).
- **Решение** (`bending/text/solution.ts`): реакции, правило знаков, участки, формулы Q(z) и M(z) в буквах и числах,
  значения на концах и в экстремуме, проверки скачков (Q — на силу, M — на пару; M = 0 на концах и в шарнирах),
  ответ — наибольшие |Q| и |M| и опасное сечение.
- **Чертёж** (`bending/draw/diagrams.ts`): эпюры под расчётной схемой в том же масштабе, со штриховкой, знаками и значениями.
- **Правила и обозначения** (`src/shared/conventions.ts`, панель во вкладке, запоминаются в браузере): сторона эпюры M —
  сжатые волокна (машиностроение, Антонов; по умолчанию) или растянутые (строительная механика); ось вдоль балки z или x;
  обозначения Q, M или Q_y, M_x. Знаки Q и M — как почти во всех учебниках: Q «+», если слева сила вверх;
  M «+» при изгибе выпуклостью вниз.
- **Проверка** (`tests/bending.test.ts`): эталон Антонова (Q = ⅔ql и −4/3·ql, M_max = 8/9·ql²); для готовых задач
  и 3000 случайных балок (в том числе составных) Q и M по левой части совпадают с независимым расчётом по правой части
  (`tests/helpers/cut.ts`: свои направления сил, интегрирование нагрузки по Симпсону), скачки равны силам и парам,
  M = 0 на свободных концах и в шарнирах. Проверено, что порча формулы нагрузки ловится.

## Уравнения Лагранжа второго рода

Вкладка «Уравнения Лагранжа» (Мещерский §48): по обобщённым координатам (1–3), кинетической энергии T(q, q̇, t),
потенциальной энергии Π(q, t) и непотенциальным обобщённым силам Qⱼ^н выводит уравнения движения в буквах.

- **Символьный движок** (`src/shared/sym.ts`): выражение — сумма членов «коэффициент × произведение атомов в степенях»
  (переменные, время, функции, скобки). Подобные приводятся, sin² + cos² = 1 упрощается; суммы без скоростей
  (l + rφ, m₁ + m₂) остаются скобками, поэтому уравнение сокращается на общий множитель, как в задачнике.
  Частные производные и полная производная по времени — по правилу сложной функции.
- **Решение:** ∂T/∂q̇ⱼ, d/dt(∂T/∂q̇ⱼ), ∂T/∂qⱼ, Qⱼ = −∂Π/∂qⱼ + Qⱼ^н, уравнение и его сокращённый вид; ускорения
  (для одной координаты — формулой, иначе система A·q̈ + b = 0); интегрирование Рунге — Кутта 4-го порядка
  с графиками q(t); обобщённый интеграл энергии H = Σ q̇ ∂T/∂q̇ − T + Π (для T, квадратичной по скоростям, H = T + Π) —
  его сохранение проверяет интегрирование; малые колебания около заданного положения: M·δq̈ + K·δq = 0, det(K − ω²M) = 0.
- **Ввод:** скорость — штрихом (x′, φ′), греческие буквы — символом или латиницей (phi, theta), неявное умножение,
  sin²φ, √. Неизвестное обозначение подсвечивается.
- **Проверка** (`tests/lagrange.test.ts`): производные — против численных; Мещерский 48.11 ((l + rφ)φ̈ + rφ̇² + g sin φ = 0),
  48.27, 48.28 (уравнения как в ответах), 48.37–48.38 (уравнения эллиптического маятника и период 2π√(m₁l/((m₁ + m₂)g));
  T в декартовых координатах даёт те же ускорения), 48.35 (ω² = c(m₁ + m₂)/(m₁m₂), центр масс движется равномерно).

## Принцип возможных перемещений

Вкладка «Возможные перемещения» находит реакции и неизвестные нагрузки конструкции из «Балок и рам» (Мещерский §46),
не составляя уравнений равновесия для каждого тела; схема общая, правится там же.

- **Метод** (`src/modules/virtual/model/virtual.ts`): у каждой жёсткой части три малых перемещения — сдвиг и поворот.
  Для искомой неизвестной её связь отбрасывается: перемещение в ней равно δs (или повороту δφ), остальные связи
  и шарниры перемещения не допускают. Получается механизм с одной степенью свободы; центр поворота каждой части
  (мгновенный центр) и перемещения точек приложения нагрузок находятся из этих условий. Сумма работ равна нулю —
  отсюда значение. Если связей меньше, чем нужно для неподвижности (рычаг с неизвестной силой), берётся одно из
  возможных перемещений — ответ от выбора не зависит.
- **Решение** — для каждой неизвестной: какая связь отброшена, как движется каждая часть (поворот вокруг какой точки
  и на какой угол или поступательно), работы нагрузок, уравнение работ, сравнение с уравнениями равновесия.
  Чертёж — положение после возможного перемещения и центры поворота.
- **Проверка** (`tests/virtual.test.ts`): Мещерский 46.19 (R_A = 1, R_B = 10,5, R_D = −0,5), 46.20 (M = 2a),
  46.21–46.22 (R_E = 0,5P, m_E = 0), 46.25 (Y_A = P1 − P2·h/l), 46.26–46.27 (R = P1 + P2/2, m_A = (P1 + P2/2)h);
  во всех готовых задачах «Балок и рам» значения совпадают с уравнениями равновесия.
- **Расхождение с задачником:** в 46.21 опора A — каток (с неподвижным шарниром балка была бы неопределимой).

## Эпюры N, Q, M для рам

Вкладка «Рамы: эпюры N, Q, M» строит эпюры для любой статически определимой рамы из «Балок и рам»: со стойками,
наклонными стержнями, ветвлениями и внутренними шарнирами (схема общая, правится там же, отмена и файлы общие).

- **Метод** (`src/modules/framediag/model/frame.ts`): каждый участок рамы — свой участок эпюр. Сечение делит раму-дерево
  на две части; берётся та, где меньше сил (по возможности без реакций), z отсчитывается от её конца. Слагаемые —
  те же функции метода сечений, что у «Изгиба» (`bending/model/forces.ts`): силы, пары и распределённые нагрузки,
  в том числе нормальные к наклонному стержню; сила под углом к оси — через cos φ и sin φ.
- **Правила знаков.** У Антонова рам нет, поэтому приняты общепринятые: N > 0 — растяжение; Q > 0, если сила вращает
  отсечённую часть относительно сечения по часовой стрелке (от выбора части не зависит); у M знак зависит от обхода,
  поэтому для каждого участка в решении сказано, какие волокна растянуты при M > 0, а эпюра M строится на сжатых или
  растянутых волокнах (настройка общая с «Изгибом») без знаков. N и Q откладываются со знаками: «+» вверх
  у горизонтальных и наклонных стержней, влево у вертикальных.
- **Проверка в решении:** равновесие каждого жёсткого узла (ΣM, ΣX, ΣY от концов участков, сил и пар в узле), M = 0
  в шарнирах и на свободных концах.
- **Проверка** (`tests/framediag.test.ts`): Г-образная рама вручную (M = 30 и 34 в узле C, 50 в заделке); равновесие
  всех узлов во всех готовых задачах, где участки независимо выбирают разные отсечённые части; для балок N, Q, M
  совпадают с «Изгибом»; рама с наклонным ригелем и трапециевидной нормальной нагрузкой — dM/dz = Q.

## Стержневые системы

Антонов, гл. 3 (рис. 3.7, 3.8, 3.10) и п. 4.5; своя модель (`src/modules/rods/model/rods.ts`) и файл проекта.

- **Система:** узел, в котором сходятся стержни, или абсолютно жёсткий брус на шарнирно-неподвижной опоре и катках.
  Стержни (до 6) — с шарнирами на концах: точка крепления, направление к неподвижному шарниру, длина, площадь c·A,
  E, α, нагрев ΔT, неточность изготовления δ (длиннее «+», короче «−»). Нагрузки: силы, пары и равномерная нагрузка на брус.
- **Расчёт** — методом перемещений (u, v узла; u, v, θ бруса; связи опор исключаются): Δl_i — проекция перемещения точки
  крепления на ось стержня, N_i = (E_iA_i/l_i)(Δl_i − α_iΔT_i l_i − δ_i). Степень статической неопределимости — число
  неизвестных усилий минус ранг уравнений равновесия; стержни на одной прямой (брус между заделками) — одномерная задача.
  Механизм и зависимые опоры распознаются.
- **Решение** в принятом в учебниках виде: неизвестные и степень неопределимости, уравнения равновесия (без реакций —
  моменты относительно шарнира), уравнения совместности деформаций (удлинения «лишних» стержней через удлинения
  базовых, например Δl₂ = 0,6·Δl₁), закон Гука с нагревом и неточностью, усилия, реакции, проверка.
- **Что найти:** усилия, напряжения и проверка прочности (запас по σт); подбор площади — σ_i = a_i/A + b_i, где b_i —
  напряжения от нагрева и неточности (от A не зависят), отсюда A ≥ A_min (и, если надо, A ≤ A_max); допускаемая нагрузка
  по [σ] — множитель λ ко всем нагрузкам; предельное состояние — начало текучести, предельная нагрузка (линейное
  программирование: максимум λ при |N_i| ≤ σт·A_i), [F]п = F_пр/n и сравнение с [F] по допускаемым напряжениям.
- **Схема:** растянутые стержни — синие, сжатые — красные, усилия у стержней; пунктиром — положение после деформации
  (перемещения увеличены).
- **Эталоны** (`tests/rods.test.ts`): пример п. 4.5 — N₁ = N₃ = P/5, N₂ = 4P/5, [P] = (5/4)[σ]A, P_пр = 2σт·A, отношение 8/5;
  брус с зазором (рис. 3.10) — P·l₁/(EA) + P·l₂/(2EA) = Δ; брус на шарнире и двух стержнях — N₁ = 0,6F, N₂ = 1,2F;
  нагретый стержень между заделками — σ = −EαΔT; предельная нагрузка бруса на шарнире — Σσт·A_i·h_i/M;
  подбор и допускаемая нагрузка дают |σ|max = [σ].
- **Расхождения с пособием:** в п. 4.5 сказано, что предельная нагрузка «почти в два раза» больше допускаемой —
  по формулам пособия отношение 8/5 = 1,6. В п. 3.5 про систему рис. 3.7 сказано и «один раз статически
  неопределима», и «статически определима», и что нужны «два дополнительных уравнения» — по рисунку система один раз
  неопределима (три усилия, два уравнения равновесия), нужно одно уравнение совместности.

## Вращение тела и передачи

Мещерский §13–14; модель `src/modules/gears/model/gears.ts`, файл проекта.

- **Ведущее звено:** закон поворота колеса 1 φ₁(t) или закон движения нити (рейки), сходящей с колеса 1 без
  проскальзывания (ω₁ = ẋ/r₁). Производные — символьные.
- **Цепочка колёс:** каждое колесо связано с предыдущим — на одном валу, внешнее или внутреннее зацепление, открытый
  или перекрёстный ремень, коническая пара. Отношение в паре — по числам зубьев (если заданы у обоих), иначе по
  радиусам; внешнее зацепление и перекрёстный ремень меняют знак ω, у конической пары направление — по чертежу.
- **Решение:** ω, ε, обороты в минуту и число оборотов каждого колеса, передаточное отношение i₁ₖ; точка выбранного
  колеса на расстоянии ρ от оси — v, a_τ, a_n, a и угол μ с радиусом. Обратные задачи: момент, когда колесо наберёт
  заданную угловую скорость, или неизвестный радиус (число зубьев) колеса по заданной ω (14.1; размер паразитного
  колеса не влияет на ω — об этом сообщение). Схема передачи в масштабе со стрелками направления вращения и график ω(t).
- **Равнопеременное вращение:** из ω₀, ω, ε, t, φ известны любые три (обороты в минуту и обороты — по выбору);
  при двух корнях берётся момент, когда значение достигается впервые. Все 10 сочетаний проверены друг другом.
- **Эллиптические колёса:** колесо 1 — эллипс на фокусе или на центре, ω₁ = const; ω₂ = ω₁r₁/(A − r₁), ε₂, крайние
  значения ω₂, сопряжённое колесо 2 на чертеже и график ω₂(φ). При оси в фокусе и A = 2a колесо 2 — тот же эллипс
  (проверено: за оборот колеса 1 оно делает ровно оборот). Два одинаковых эллипса на центрах точно не сопрягаются
  (колесо 2 за оборот колеса 1 поворачивается лишь на ≈ 0,8 оборота), поэтому в 14.8 речь об «овалах»: крайние
  значения ω₂ от формы овала не зависят и совпадают с книгой, а закон между ними приведён для эллипса — это сказано
  в решении.
- **Фрикционная передача с переменным плечом:** ω₂ = ω₁r/d(t), ε₂ — символьная производная; момент, когда d примет
  заданное значение; точка диска 2.

## Плоский механизм

Мещерский §16, 18, 22–23 (кулисы), 38 (кинетическая энергия механизмов), 46 (равновесие механизмов); модели
`src/modules/mechanism/model/mech.ts` (кинематика), `forces.ts` (силы и массы), `solve.ts` (параметр положения, теорема
об энергии, график), файл проекта.

- **Положение:** точки задаются построениями — координатами, от точки по длине и углу (угол — от оси x или от
  направления на другую точку), на расстояниях от двух точек (пересечение окружностей, сторона выбирается), на прямой
  на расстоянии от точки, на отрезке (доля длины), пересечением двух прямых (каждая — через две точки или через точку
  под углом). Числа — формулы (15/cos(π/6), 30sqrt(3)); углы — в градусах. Точка вне звеньев — вспомогательная для
  построения (неподвижная).
- **Звенья и связи:** звено — жёсткое тело из отмеченных точек; связи — неподвижный шарнир, ползун на прямой
  направляющей, колесо катится по неподвижной прямой, зацепление (качение) двух колёс, в том числе с неподвижным и
  внутреннее, **кулисный камень** (точка скользит вдоль прямой, жёстко связанной с другим звеном; камнем может быть и
  неподвижная ось качающегося цилиндра), **поступательное движение звена** (ω = 0). Ведущие — ω и ε звена, скорость и
  ускорение точки вдоль направления или их векторы.
- **Решение:** скорости и ускорения — из линейных систем (v_B = v_A + ω × AB, a_B = a_A + ε × AB − ω²AB плюс связи);
  для кулисы (v_A − v_G)·n = ω(r·u), (a_A − a_G)·n − ε(r·u) = 2ωv_r − ω²(r·n). Подвижность механизма — по рангу системы
  без ведущих; при нехватке или избытке ведущих — сообщение. В тексте — по-учебному: МЦС каждого звена и v = ω·PM;
  кулисный камень как сложное движение точки (v = v_e + v_r, a = a_e + a_r + a_c, кориолисово a_c = 2ωv_r); ускорения
  методом полюса (aⁿ = ω²·AB, aᵗ = ε·AB) и мгновенные центры ускорений; в ответе — радиус кривизны траектории
  ρ = v³/|v × a|. Ускорения можно отключить (задачи статики). Чертёж в масштабе: векторы скоростей и МЦС или ускорений
  и МЦУ, прорези кулис, нагрузки.
- **Силы (механизм с одной степенью свободы):** силы в точках (угол — от оси x или от направления отрезка звена),
  пары на звеньях, моменты сопротивления в шарнирах, вес масс. Одна сила или пара может быть неизвестной — она
  находится из принципа возможных перемещений Σ F·v + Σ M·ω = 0 (возможные скорости — найденные скорости; моменты
  сопротивления в равновесии не участвуют). Без неизвестной — мощность сил и приведённый момент M_пр = ΣN/ω.
- **Массы:** точечные, однородные стержни (J = ml²/12), тела с центром масс (диск, обод или заданный J_C);
  T = Σ(m v_C²/2 + J_C ω²/2) по теореме Кёнига, приведённый момент инерции J_пр = 2T/ω² (для ведущей точки —
  приведённая масса).
- **Параметр положения φ** (градусы) можно писать в любом числовом поле (угол кривошипа «φ», «90−φ»). По нему —
  **график** любой величины (координаты, скорости, ускорения точек, ω и ε звеньев, v_r и a_r камня, T, J_пр, M_пр,
  неизвестная сила) с наибольшим и наименьшим значениями (уточняются золотым сечением) и **теорема об изменении
  кинетической энергии** на перемещении φ₀ → φ: J_пр(φ)ω²/2 − J_пр(φ₀)ω₀²/2 = ∫M_пр dφ. Работа считается по формуле
  Симпсона; обобщённая скорость φ̇ — по численной производной положения по φ (на краях промежутка — односторонней:
  за краем построение может перейти на другую ветвь), с проверкой, что скорости точек ей пропорциональны; моменты
  сопротивления берутся против направления движения.
- **Эталоны:** 16.8, 16.11, 16.15, 16.21, 16.24, 16.27, 16.28, 16.36, 18.9, 18.12–18.14, 18.17, 18.19, 18.20, 18.22,
  18.23, 22.21, 23.22–23.23, 23.24–23.25, 46.8, 46.10, 46.13, 46.14, 38.1, 38.3, 38.5–38.7, 38.49, 38.50 — совпадают с
  книгой (для ответов в общем виде — на числовом примере). Независимые проверки: скорость и ускорение ползуна
  кривошипно-шатунного механизма равны численным производным x_B(t) (в том числе при ε ≠ 0); |v| = |ω|·PM;
  планетарные передачи (15.3, 15.4); катушка (16.30); ускорения в механизмах с кулисами равны численным производным
  скоростей по времени (проверка кориолисова члена); равновесие — нулевая мощность при найденной силе; T — через
  скорости концов звеньев; работа веса в теореме об энергии равна −Σmg·Δy по положениям (ход вперёд и назад);
  момент сопротивления тормозит в обе стороны.
- **Расхождения с книгой** (в примечаниях к задачам): 16.27 — в положениях II, IV 58,84 см/с, в книге 58,88;
  18.20 (кривошип ⊥ шатуну) — 6,19 см/с² и ρ = 582 см, в книге 6,12 и 589 (книга округлила AO₁ до 58,8 см, а разность

## Вращение тела

## Удар и колебания

Мещерский §32, §53; Антонов, гл. 10; своя модель (`src/modules/oscillation/model/osc.ts`, `elastic.ts`) и файл проекта.

- **Груз на упругом элементе** движется горизонтально, вертикально или по гладкой наклонной плоскости; x отсчитывается
  от положения статического равновесия (δ_ст = (P sin α + Q)/c). Единицы — согласованные, выбираются: длина (м, см, мм),
  сила (Н, кН, кГ, Г, т); g задаётся (в части задач Мещерского g = 9,8 м/с²).
- **Жёсткость:** задана; по статической деформации; по измеренному периоду (в том числе с сопротивлением — тогда
  k² = (2π/T₁)² + n²); собрана из элементов. Элементы — пружина (в том числе под углом к оси, c·cos²α, и на рычаге,
  c·(a/b)²), стержень (EA/l) и балка шести схем (c = 1/δ₁₁). Внутри ступени элементы параллельны, ступени — последовательны.
  Трос работает только на растяжение: момент ослабления отмечается. Масса одиночного элемента приводится к грузу
  по Рэлею: β = 1/3 (пружина, стержень), 17/35, 33/140, 13/35 (балки).
- **Сопротивление:** вязкое (b, n, по уменьшению амплитуды в q раз за N колебаний, по периоду T₁) — все три случая
  n < k, n = k, n > k; сухое трение — по полуразмахам со смещённым центром ±fN/c и областью застоя |x| ≤ f₀N/c.
- **Возмущение:** H sin(pt + δ), неуравновешенный ротор (H = m₀ep²), движение точки крепления (H = ca). Частное решение,
  резонанс (x_p = −(h/2k)·t cos kt), коэффициент динамичности, сдвиг фазы, частота и величина наибольшей амплитуды,
  сила, передаваемая на основание.
- **Начальные условия:** смещение от равновесия; начальная деформация элемента; равновесие под другой нагрузкой
  (груз сняли или добавили); падение с высоты h — удар: K_д = λ_max/δ_ст, проверка формулой
  1 + √(1 + 2h/(δ_ст(1 + βm_эл/M))), напряжения σ_max = K_д·σ_ст и проверка по [σ] для одиночного стержня или балки;
  момент отрыва груза от элемента.
- Решение — аналитическое, с постоянными из начальных условий; формула проверяется численным интегрированием
  уравнения (расхождение показывается). График x(t): наибольшее отклонение, момент t, огибающая, область застоя,
  положение недеформированного элемента.
- **Эталоны:** 32.1–32.6, 32.13, 32.14, 32.30, 32.35, 32.55–32.57, 32.60, 32.63–32.67, 32.73, 32.81, 32.84,
  32.86, 32.87, 32.90, 32.97, 32.99, 53.31–53.33 и примеры по рис. 10.3, 10.4, 10.8 Антонова.
- **Расхождения с книгой** (записаны в примечаниях к задачам и в тестах): 32.56 — книга берёт k ≈ 10 с⁻¹ (точно 9,905);
  32.64 — в ответе частота 19,2 вместо 19,7 с⁻¹ (из 32.63) и коэффициент −0,252 вместо −0,247; 32.97 — «arctg 1,26 = 51°40′»,
  на деле arctg 1,26 = 51°34′; 32.67 — корни и коэффициенты округлены; 53.31–53.32 — с учётом массы балки книга даёт

## Кинетическая энергия

Мещерский §38; Антонов п. 9.6–9.9; своя модель (`src/modules/energy/model/energy.ts`) и файл проекта.
Система с одной степенью свободы.

- **Тела:** груз (поступательно, по вертикали или по наклонной плоскости), блок или барабан на неподвижной оси
  (в том числе ступенчатый, радиусы R и r), каток (катится без скольжения; нить — через ось или на ступени радиуса R
  над или под осью). Тело 1 — ведущее: его перемещение s и скорость v (если это блок — угол φ и ω). Каждое следующее
  тело связано нитью или ремнём с одним из предыдущих: «сходит с» и «крепится к» — точки нити на телах.
  Момент инерции — сплошной диск, масса на ободе, радиус инерции или задан числом. Массы или веса (m = P/g).
- **Силы:** тяжесть, трение скольжения f (груз), сопротивление качению δ (каток), постоянная сила F,
  момент M = M₀ + M₁φ + M₂φ², пружина (c, начальная деформация λ₀).
- **Решение:** скорости тел через v, кинетическая энергия и приведённая масса m_пр, работа каждой силы,
  T − T₀ = ΣA, ускорение a = Q/m_пр. Можно искать скорость после перемещения, перемещение до заданной скорости
  (в том числе до остановки) или начальную скорость. Если из покоя система пошла бы в другую сторону или
  остановится раньше — об этом сказано.
- **Эталоны:** 38.13, 38.23, 38.24, 38.25, 38.37, 38.39, 38.41, 38.42 (без массы троса), 38.43–38.46 — совпадают
  с книгой; задачи с переменными силами (пружина, M = aφ, aφ²) дополнительно проверены интегрированием уравнения
  движения. **38.23, 38.24:** в начальный момент M = aφ = 0, и из покоя груз пошёл бы вниз, а не вверх; ответ книги —
  формальный результат теоремы, приложение его выдаёт с предупреждением.

## Геометрия масс

- **Части:** точечная масса, тонкий стержень, тонкое кольцо (обод), диск или сплошной цилиндр, полый цилиндр

## Сходящиеся силы

Мещерский §1–2, 6–7; своя модель (`src/modules/converging/model/forces.ts`) и файл проекта. Две задачи:

- **Равновесие узла.** Силы в одной точке: известные (модуль и направление) и неизвестные по модулю — нить
  (только растяжение), стержень («+» — растяжение), гладкая опора (только давит). Направление — углом к оси x
  на плоскости или вектором к другому концу нити или стержня в пространстве. Решение — проекции на оси
  (два уравнения на плоскости, три в пространстве), для трёх сил на плоскости — проверка по теореме Лами;
  сжатая нить или «тянущая» опора отмечаются как невозможное равновесие; лишние неизвестные — статическая
  неопределимость.
- **Приведение системы сил.** Силы в точках и пары → главный вектор R и главный момент M_O с подстановкой
  чисел, инвариант R·M_O и простейший вид: равновесие, пара, равнодействующая (с линией действия) или
  динамический винт (M* = R·M_O/R, центральная ось и её пересечение с плоскостью Oxy).
- **Эталоны:** 2.7, 2.10, 2.12, 2.18, 2.22, 6.5, 6.15, 7.6, 7.12 — совпадают с книгой. В 7.12 книга приводит реакцию
  грунта, противоположную нагрузкам: ось динамы та же, модуль M* = 6 тот же; приложение показывает знак
  (M* = −6 — левый винт; при обращении всех сил R·M_O не меняется, поэтому и вид винта тот же).

## Пространственное тело

Твёрдое тело в пространстве (Мещерский §8), своя модель (`src/modules/spacebody/model/body.ts`) и файл проекта.

- **Ввод:** точки (x, y, z); опоры — сферический шарнир и подпятник (X, Y, Z), подшипник или петля с осью (две реакции
  поперёк оси), стержень или нить к неподвижной точке (усилие вдоль, «+» — сжатие), гладкая опора (реакция по нормали n);
  силы — составляющими или модулем вдоль направления к точке, с флажком «модуль неизвестен».
- **Решение:** уравнения-кандидаты — моменты относительно осей, параллельных координатным и проходящих через опоры,
  и три проекции; сначала уравнения с одним неизвестным, остальное совместно; проверка неиспользованной проекцией.
  Статусы: определимо, неопределимо (ранг 6, неизвестных больше), не закреплено (ранг меньше), равновесие невозможно
  (связи допускают движение, и нагрузка его вызывает).

  проверяются независимым расчётом. Готовый пример — вал со шкивом и зубчатым колесом.

## Трение и односторонние связи

Встроено в «Балки и рамы»: опора «Трение» (шероховатая поверхность) и флажок «Односторонняя связь» у катка.

- **Связи.** Опора с трением даёт нормальную реакцию N ≥ 0 и силу трения |Fтр| ≤ f·N вдоль поверхности
  (положительное направление — нормаль, повёрнутая на −90°); при k > 0 — момент сопротивления качению |Mк| ≤ k·N.
  Односторонний каток: R ≥ 0 — опора может оторваться (опрокидывание).
- **Расчёт** (`solver/friction.ts`, симплекс-метод — `src/shared/lp.ts`). Если искомая нагрузка одна — её наименьшее
  и наибольшее значения, при которых существуют реакции, удовлетворяющие уравнениям равновесия и неравенствам.
  Для каждой границы — предельное состояние: где трение достигло f·N (и куда готова скользить точка), где связь
  отрывается (вокруг какой точки опрокидывание), где начинается качение. Без искомой нагрузки — возможно ли
  равновесие и наименьший коэффициент трения, при котором оно возможно.
- **Эталоны:** Мещерский 3.23 (кран, Q ≤ 5,18), 3.25 (лебёдка, P ≥ 6), 4.79 (каток, P = 5,72), 4.66 (лестница,
  tg α ≥ (P + 2p)/(2f(P + p))), 4.67 (лестница, трение о стену и пол, BP = AB/2); брус на наклонной плоскости —
  G(sin α ∓ f cos α). В предельных состояниях равновесие проверяется независимым расчётом сил, неравенства — отдельно,
  в том числе на 1500 случайных конструкциях. Готовые задачи: «Брус на наклонной плоскости», «Кран на рельсах».

## Фермы

Плоская ферма: узлы с координатами, стержни с шарнирами на концах, опоры (шарнир — X и Y, каток — одна реакция
под заданным углом) и силы в узлах. Своя модель (`src/modules/truss/model/truss.ts`) и файл проекта (`module: "truss"`).

- **Расчёт** — уравнения равновесия всех узлов (2n уравнений, m + r неизвестных) методом Гаусса. Определимость:
  m + r = 2n и ранг 2n; иначе — неопределима (больше неизвестных) или изменяема (меньше, либо связи мгновенно
  изменяемы, например три шарнира на одной прямой). Правило знаков: «+» — растяжение.
- **Решение по шагам:** определимость; реакции из равновесия всей фермы (момент относительно шарнира, затем проекции);
  нулевые стержни по двум признакам (с повторным применением); вырезание узлов в порядке, где не больше двух
  неизвестных (если узлов с двумя неизвестными не осталось — остальные усилия из совместного решения);
  проверка выбранного стержня методом Риттера — сечение через три стержня ищется само, точка Риттера Kр
  (или проекция на ось, перпендикулярную параллельным стержням); ответ с «растянут/сжат/не нагружен».
- **Чертёж:** номера стержней и усилия, растянутые — синим, сжатые — красным, нулевые — пунктиром; рассечённые стержни
  и точка Kр.
- **Эталоны** — Мещерский §5: 5.7, 5.11, 5.12, 5.13, 5.14 (перекрещивающиеся стержни без шарнира), 5.15; реакции
  и усилия во всех стержнях совпадают с таблицами книги. Независимо проверяется равновесие каждого узла;
  метод Риттера и признаки нулевых стержней сверяются с общим решением.

## Наклонные участки

Участок рамы может идти под любым углом (раздел «Балки и рамы», эталоны — Мещерский §4).

- **Ввод.** В списке участков и при добавлении — стрелки ↗ ↖ ↙ ↘ и острый угол α к горизонту; новый участок
  можно задать и проекциями («4 м по горизонтали, 3 м по вертикали»): тогда длина √(Δx² + Δy²) хранится точно,
  без округления до миллиметра. Угол, кратный 90°, превращает участок в обычный горизонтальный или вертикальный.
- **Данные.** У наклонного участка `dir: "a"` и `ang` — угол к оси x от начала к концу, 0…360°, против часовой стрелки.
  Рамы только из горизонтальных и вертикальных участков считаются и рисуются как раньше (координаты с точностью
  до миллиметра, эталоны прототипа не изменились); с наклонными участками координаты не огрубляются.
- **Распределённая нагрузка** на наклонной прямой: вниз, вверх, вправо, влево или перпендикулярно участку
  («вверх» — в сторону, где выше). Интенсивность q отнесена к длине участка по его оси: Q = q·l. Нагрузку на единицу
  горизонтальной проекции (снег) нужно пересчитать: q·cos α — об этом сказано в пояснениях.
- **Опоры.** Гладкая опора посередине наклонной балки (столб, упор, край стены) — каток с наклонной поверхностью;
  кнопка «⊥ участку» ставит угол реакции перпендикулярно участку в нужную сторону.
- **Чертёж.** Размер вдоль участка (со стороны, свободной от эпюры нагрузки) и угол к горизонту в начале прямого отрезка.
  Моменты наклонных сил в решении, как и раньше, раскладываются на составляющие (теорема Вариньона).
- **Проверка.** Восемь задач Мещерского (4.7, 4.8, 4.12, 4.13, 4.14, 4.15, 4.19, 4.21 — `TEXTBOOK_INCLINED`),
  1500 случайных рам с наклонными участками и нормальной нагрузкой — независимым расчётом равновесия
  (свои координаты и нормали в `tests/helpers/equilibrium.ts`). Готовые задачи: «Лестница у гладкой стены»,
  «Стропила: ветер перпендикулярно скату». Вкладка «Изгиб» рамы с наклонными участками не принимает — для них вкладка «Рамы: эпюры N, Q, M».

## Проекты и отчёт

- **Сохранить** (Ctrl+S) — файл `<название> <дата>.statika.json`: раздел, конструкция, элементы, «Что найти», название.
- **Открыть** (Ctrl+O) или перетащить файл на страницу. Файл полностью проверяется: ссылки на точки,
  допустимые значения, связность и непересечение участков; ошибки — понятным текстом, схема при ошибке
  не меняется. Открытие отменяется, как любое действие. Файл открывается в своём разделе — вкладка переключается сама.
- **Решение в PDF** (или Ctrl+P) — отчёт на A4: «Дано», чертёж в двух видах, «Найти», пошаговое решение
  (с пояснениями, если они включены), ответ. Файл сохраняется через «Печать → Сохранить как PDF»:
  текст и чертежи остаются векторными, кириллица и формулы — как на экране.

Формат файла — версия 2: общий конверт `src/shared/projectFile.ts` (`format`, `version`, `module`, `title`, `savedAt`)
и данные раздела рядом с ним (для «Балок и рам» — `src/modules/frames/model/project.ts`). Файлы версии 1 (без `module`)
открываются в разделе «Балки и рамы».

## Как проверяется правильность

1. **Эталонные ответы** (`tests/reference.test.ts`): все готовые задачи с точностью 1e-3.
2. **Сверка с прототипом** (`tests/golden.test.ts`, `tests/edit.test.ts`); в случаях, где поведение
   намеренно изменено (см. «Отличия от прототипа»), сверяется всё, кроме затронутого. `scripts/capture-golden.ts` открывает
   копию прототипа в Chromium (в копию добавлена одна строка, открывающая внутренние функции), прогоняет
   готовые задачи и 600 случайных конструкций и сохраняет в `tests/golden/`: HTML решения, статус, значения,
   порядок уравнений, коэффициенты всех уравнений-кандидатов, заголовки карточек, поправки состояния,
   результат «разделить/убрать участок». Порт должен совпасть по всем пунктам: текст — посимвольно,
   числа — с допуском 1e-12 (Chromium и Node по-разному считают `Math.sin` в последнем бите).
3. **Свойства на случайных конструкциях** (`tests/property.test.ts`, fast-check): для каждой определимой системы
   найденные реакции уравновешивают тело. Проверка **независимая**: свои координаты, свои направления опор,
   распределённая нагрузка интегрируется по Симпсону, а не заменяется формулой центра тяжести.
   Правки геометрии не ломают конструкцию. Тест проверен на чувствительность: порча формулы центра тяжести
   трапеции или знака момента ловится сразу.
4. **Чертёж** (`tests/drawing.test.ts`): SVG обоих видов совпадает с прототипом для готовых задач и 600 случайных конструкций.
5. **Интерфейс в браузере** (`scripts/compare-ui.ts`): 84 одинаковых действия в прототипе и в приложении —
   все готовые задачи, правка участков и элементов, перетаскивание, правка размера на чертеже, двойной щелчок,
   отмена и повтор (кнопками и клавишами), мастер. После каждого шага сравниваются чертёж, решение, поля,
   выделение, сообщения, кнопки истории и мастер.
6. **История и состояние** (`tests/store.test.ts`, `tests/history.test.ts`); файл проекта (`tests/project.test.ts`) и браузерная проверка
   сохранения, открытия, перетаскивания, ошибок, вкладок, файлов версии 1 и чужих разделов, PDF (`scripts/e2e-files.ts`).
7. **Известные особенности прототипа** (`tests/known-bugs.test.ts`) — зафиксированы как есть, см. ниже.

## Отличия от прототипа

Исправлены ошибки, влиявшие на расчёт (`tests/fixes.test.ts`):

1. **Определимость — по рангу.** Раньше при n > 3 статус «неопределима» ставился до проверки ранга.
   Теперь: ранг 3 и n > 3 — неопределима, степень n − 3; ранг < 3 — геометрически изменяема
   (например, четыре вертикальных катка).
2. **Знакопеременная распределённая нагрузка** (q₁ и q₂ разных знаков) заменяется двумя силами Q′ и Q″ —
   по одной на каждый треугольник эпюры по обе стороны от нуля. Раньше была одна сила: при q₁ = −q₂
   она равна нулю, и пара сил терялась; в остальных случаях точка приложения уходила за участок.
   На расчётной схеме рисуются обе силы.

Исправлена ошибка этапа 4: при **открытии файла** терялись внутренние шарниры (составная конструкция
считалась как сплошная). Проверяется в `tests/store.test.ts` и в браузере.

Исправлена ошибка редактора: **«Убрать участок»** теперь работает (баг №7: `geomOK` проверялся,
пока удаляемый узел ещё был в списке узлов, и проверка проваливалась всегда).

В режиме пояснений добавлено: проекции каждой наклонной силы через угол с той осью, от которой пользователь
отсчитывал угол (угол больше 90° приводится к острому), и простое объяснение, что значит «по нормали».

## Особенности прототипа, не влияющие на расчёт

Перенесены без изменений (`tests/known-bugs.test.ts`):

3. «Что найти» хранится по имени (`R_E`); после добавления точки имена сдвигаются и отметка теряется
   или переходит на другую реакцию.
4. Проверочное уравнение не может показать «Ошибка»: решение с невязкой отсеивается раньше как «равновесие невозможно».
5. В записи уравнений при α > 90° стоит острый угол с осью (например, `cos 60°` для 120°); числа верные,
   в пояснениях переход показан явно.
6. Соглашение: у опорного стержня «+» направлен от опоры к конструкции, то есть «+» — сжатие.
