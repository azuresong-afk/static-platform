# Покрытие задачника Мещерского конструкторами приложения

Мещерский И. В. Сборник задач по теоретической механике. — М.: Наука, 1975 (файл в `books/`, в репозиторий не входит).

**Вопрос аудита.** Может ли студент сам собрать задачу этого типа в разделе приложения — со своими числами и схемой —
и получить решение с объяснением? Наличие готовой задачи не важно: важно, хватает ли конструктора.

**Как проверяли.** Текст книги разобран на задачи: 1732 задачи в 56 параграфах. Условия прочитаны по параграфам.
Задачи сгруппированы по типам, и каждой группе поставлена оценка:

- **✓ собирается** — все данные задачи вводятся в раздел, раздел отвечает на вопрос задачи и объясняет решение;
- **½ частично** — раздел помогает, но часть работы остаётся студенту. Например, закон движения нужно составить самому,
  вопрос задачи обратный (по ответу найти данное), силу инерции надо добавить вручную или ответ получается численно без формулы;
- **✗ нет конструктора** — тип задачи приложение не решает;
- **— вне формата** — доказательства, геометрические места, вывод приближённых формул.

Оценки поставлены группам задач, а не каждой задаче отдельно, поэтому проценты точны в пределах нескольких единиц.
Задачи «в общем виде» (ответ — формула) считались собираемыми, если раздел решает их с числами: ответ книги можно проверить,
подставив те же числа. Для проверки взяты четыре задачи, которых нет среди готовых: 2.26, 27.5, 30.4 и 47.1 (ускорение и натяжение нити).
Их собрали через модели разделов, и все ответы совпали с книгой.

## Замечания по приложению, найденные по ходу

1. В «Задачнике» и в подписи блоков навигации названия параграфов Мещерского заведены только до §49
   (`MESH_PARAS` в `src/shared/tasks.ts`), а `meshPart` относит всё после §45 к «Аналитической механике».
   Пока задач из §50–56 в приложении нет, на работу это не влияет. Когда они появятся, нужно добавить названия
   и отделы «Динамика космического полёта» (§50–51) и «Устойчивость и колебания» (§52–56).
2. В навигации блок «Кинематика» подписан «Мещерский, §10–23», хотя «Плоский механизм» решает и планетарные передачи §24.
   «Динамика» подписана «§26–42», хотя «Уравнения Лагранжа» дают частоты малых колебаний §53.
   Подписи стоит поправить, когда добавятся новые конструкторы.
