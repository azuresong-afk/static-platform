## В общем виде (§52, 55, 49.12; Д.23)

**Данные.** Как в «Уравнениях Лагранжа»: 1–3 координаты, параметры с числами, T(q, q̇), Π(q), непотенциальные
обобщённые силы Qⱼ(q, q̇). Для каждой координаты — положение q\* формулой от параметров (например,
`arccos(g c/(ω^2 a^2))`) и начальные отклонения δq₀, δq̇₀. Дополнительно: неизвестный параметр (обратная задача),
флажок «безразличное равновесие», параметр, относительно которого решаются условия, и перебор этого параметра.

**Решение.**

- W = Π − T₀ (T₀ — часть T без скоростей), силы покоя Fⱼ = −∂W/∂qⱼ + Qⱼ(q, 0). Если Fⱼ(q\*) ≡ 0 — q\* положение
  равновесия (относительного равновесия, стационарного движения); иначе выводятся уравнения равновесия в буквах.
- Обратная задача: неизвестный X (момент, вес противовеса) входит в Fⱼ линейно — X находится из Fⱼ(q\*) = 0.
  Безразличное равновесие: Fⱼ(q) ≡ 0 при всех q — X = −B/A, и проверяется, что отношение не зависит от q.
- Первое приближение: M·δq̈ + (D + G)·δq̇ + K·δq = 0; M = ∂²T/∂q̇∂q̇, K = −∂F/∂q, D = −∂Q/∂q̇,
  гироскопические Gᵢⱼ = ∂aᵢ/∂qⱼ − ∂aⱼ/∂qᵢ (T₁ = Σaⱼq̇ⱼ).
- Консервативная система (G = D = 0) — критерий Сильвестра для K (теорема Лагранжа — Дирихле): главные миноры в
  буквах. Иначе — det(Mλ² + (D + G)λ + K) = 0 и условия Гурвица; без диссипации — условия вещественности и
  отрицательности корней μ = λ² (гироскопическая стабилизация, 55.9, 49.12).
- Условия решаются относительно выбранного параметра, если он входит в одной степени: ω² < c·g/a². Граница по
  параметру — перебором при заданных числах (корни на плоскости и полоса «устойчиво / нет»).
- Одна координата: k² = K/M в буквах, закон δq = δq₀ cos kt + (δq̇₀/k) sin kt = A sin(kt + ε) и период.
- Канонические переменные (49.12): p = M·δq̇ + N·δq + p\*, N = ∂a/∂q;
  δq̇ = M⁻¹(δp − N·δq), δṗ = NᵀM⁻¹(δp − N·δq) − K·δq.

## Катящийся диск (55.12–55.14)

Тело вращения: масса m, радиус обода a, моменты инерции A (диаметр) и C (ось симметрии) — формулами. Связь
неголономная (качение без скольжения), поэтому уравнения — Ньютона — Эйлера в осях Резаля с исключённой реакцией:
R = m·a_G + m·g·ẑ, dK_G/dt = (−a·j) × R.

- Качение по прямой с угловой скоростью Ω: (A + ma²)θ̈ + [C(C + ma²)Ω²/A − mga]θ = 0, ψ̇ = (C/A)Ωθ;
  устойчиво при C(C + ma²)Ω² > mgaA.
- Вращение вокруг вертикального диаметра с ω: (A + ma²)θ̈ + [(A + ma²)ω² − mga]θ = 0; устойчиво при
  (A + ma²)ω² > mga.
- Численно: якобиан полных нелинейных уравнений в стационарном движении — корни и вывод, перебор параметра,
  интегрирование возмущённого движения (графики θ(t), ψ(t)): медленный обруч падает, быстрый — колеблется.

## Якоби — Гамильтон, струна (49.15–49.22)

- **Якоби — Гамильтон.** По T и Π — H(q, p), уравнение ∂V/∂t + H(q, ∂V/∂q) = 0 и полный интеграл разделением
  переменных: циклическая координата — ∂V/∂qₐ = αₐ; если H распадается на слагаемые Hⱼ(qⱼ, pⱼ), то Hⱼ = βⱼ и
  pⱼ = ∂V/∂qⱼ — корень квадратного уравнения. V = −h·t + Σαₐqₐ + Σ∫pⱼ(qⱼ)dqⱼ (интеграл в конечном виде, если
  pⱼ = √(c + k·qⱼ), иначе остаётся интегралом); первые интегралы ∂V/∂h = β₀, ∂V/∂αₐ = βₐ. Проверка: по численному
  решению уравнений Лагранжа pⱼ = ∂T/∂q̇ⱼ совпадает с pⱼ(qⱼ) из полного интеграла (отклонение < 10⁻⁶).
- **Струна и нить** (принцип Гамильтона — Остроградского). Плотность ρ(x), натяжение T(x), длина l, концы
  закреплённые или свободные: S = ∫∫[ρ(∂y/∂t)² − T(∂y/∂x)²]/2 dx dt, δS = 0 ⇒ ρ∂²y/∂t² = ∂/∂x(T∂y/∂x); свободный
  конец — T∂y/∂x = 0. Частоты и формы — конечными разностями (400 отрезков, бисекция по Штурму).

## Реакции, отрыв, программное движение («Уравнения Лагранжа»; §43, Д.20)

- **Реакция связей на тело.** Масса и координаты центра масс x_C(q), y_C(q) (ось y вверх), по желанию — направление
  e под углом β(q) к оси x. По теореме о движении центра масс R = m·a_C − m·g; проекции R_x, R_y или
  R_e = R_x cos β + R_y sin β, R_n = −R_x sin β + R_y cos β (n повёрнута от e на 90°). Для одной координаты q̈
  подставляется из уравнения движения, q̇² — из интеграла энергии при движении из покоя в q₀: R(q) в буквах.
- **Отрыв.** Выбранная проекция (односторонняя связь) меняет знак — момент уточняется делением шага Рунге — Кутта
  пополам; касание нуля (43.7) — золотым сечением с допуском 10⁻⁶ от масштаба силы. Либо «остановить в положении»:
  q₁ достигает заданного значения. В этот момент — q, q̇, центр масс, его скорость, угловая скорость тела;
  «дальше свободно» — парабола центра масс y_C = a + b·x_C + c·x_C².
- **Программное движение** (обратная задача, Д.20). Законы qⱼ(t) формулами и момент t\*:
  Qⱼ = d/dt(∂T/∂q̇ⱼ) − ∂T/∂qⱼ + ∂Π/∂qⱼ вдоль программы; графики q(t) и Q(t).

## Расхождения с книгой

- **Д.23.** Книга округляет ẏ₀/k = 8/27,1 = 0,295 см до 0,3 и получает амплитуду √(0,2² + 0,3²) = 0,36 см и фазу
  0,597; без промежуточного округления A = 0,357 см, ε = 0,595.
- **43.10.** Ось n в приложении повёрнута от e на +90°, а N книги направлен в другую сторону: R_n = −N
  (модуль совпадает).
- **43.1.** Книга берёт x вниз от B, y — горизонтально; в приложении ось y вверх, поэтому та же парабола записана как
  y_C = −l − x_C²/(3l).

## Ограничения

- 43.3, 43.6, 43.8, 43.9 — частично: несколько этапов (удар, смена связи) или вопрос без конструктора — каждый этап
  собирается отдельно.
- 52.7, 52.13 — частично (общий вид с произвольной функцией, форма направляющей), 55.19 — два волчка: уравнения
  составить самому и задать в режиме «Устойчивость».
- Д.18 Яблонского — частично (T и обобщённые силы составить самому).
- «В общем виде» решает условие относительно параметра, только если он входит в одной степени; иначе условие
  остаётся неравенством для многочлена, а граница ищется перебором.
- Якоби — Гамильтон: разделение только для H, распадающейся на слагаемые по парам (qⱼ, pⱼ) и с циклическими
  координатами; струна — одномерная, малые колебания.
- Катящийся диск — только два стационарных движения (по прямой и вокруг вертикального диаметра).
