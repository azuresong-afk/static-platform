## §41. Метод кинетостатики

К заданным силам добавляются силы инерции: точечные массы — Φ = −m·a, тело в плоском движении — главный вектор
Φ = −m·a_C и главный момент M^Φ = −J_C·ε; затем задача решается как статическая.

| Тип задачи | Задача | Что считается |
|---|---|---|
| Стержень на упоре и угле | 41.5–41.6 | Кинематика: φ̇ = v sin²φ/H, φ̈ = 2v² sin³φ cos φ/H²; ускорение центра a_C; Φ_x = 3(G/g)(v²/H²) l sin⁴φ cos φ, Φ_y = (G/g)(v²/H²) l (1 − 3cos²φ) sin³φ, M^Φ = −(2/3)(G/g) l²(v²/H²) sin³φ cos φ; динамическое давление на угол N_D = (8/3)(v²l²/(H³g)) G sin⁴φ cos φ (сверх статического G l sin φ cos φ/H); таблица значений по углу φ |
| Жидкость в ускоренном сосуде | 41.8 | tg α = w/g, w = v/t |
| Жидкостный акселерометр | 41.9 | g(h₂ − h₁) = w(h₁ ctg α₁ + h₂ ctg α₂) |
| Груз на призме | 41.10 | w = g tg α, N = Q/cos α |
| Испытание на усталость | 41.11 | S = Q + (Q/g) r ω²(cos ωt + (r/l) cos 2ωt); S_max, S_min; «точное» значение — без разложения корня в ряд, график S(ωt) |
| Поворотный кран | 41.12–41.13 | X_A, X_B, Y_A: эффективный вес груза Q(1 + k_v), сила инерции тележки P_т·k_t на высоте опоры B; уравнения ΣM_A, ΣX, ΣY |
| Паром | 41.14 | w = v²/(2s), F = P w/g, T = F/n |
| Полиспаст | 41.16 | w = 4g(4P − Q)/(16P + Q); равномерно при P/Q = 1/4 |
| Клин между пластинами | 41.17 | w = gP ctg α/(P ctg α + 2P₁ tg α), w₁ = w tg α, N = P₁w₁/(g cos α) |

## §46. Принцип возможных перемещений для машин

Входному звену даётся малое перемещение (поворот рукоятки δφ, ход груза δs); перемещение точки приложения искомой
силы выражается через него из геометрии, и Σ δA = 0 (связи идеальные). Для механизмов с углом (ромб, эллипсограф,
кулиса) производная находится от закона положения — см. модель и формулы в каждом шаге решения.

| Тип задачи | Задача | Результат |
|---|---|---|
| Винтовой домкрат | 46.1 | Q = 2πP·OA/h |
| Коленчатый пресс (ромб) | 46.2 | P = πM ctg α/h (по закону положения: δy = tg α·δu, δu = −2h δφ/2π) |
| Клиновой пресс | 46.3 | Q = 2πaP/(h tg α) |
| Машина для испытания на растяжение | 46.4 | X = P x l₁/(e l₂) |
| Система рычагов | 46.5 | P_L = (BC/AC)(ON/OM)(DE/DF) P_K |
| Рычажный пресс | 46.6 | Q = F (a/b)(c/d) |
| Весы | 46.7 | p = (b/a) P; условие независимости от места груза (b + c)/b = l/d — разность показана |
| Эллипсограф | 46.8 | M = 2Pl cos φ |
| Полиспаст | 46.9 | Q/P = 2ⁿ |
| Кулисный механизм | 46.10 | Q = Pl/(R cos²φ) |
| Реечный домкрат | 46.11 | P = Q r₁r₃r₅/(R r₂r₄) |
| Дифференциальный ворот | 46.12 | P = Q(r₂ − r₁)/(2R) |
| Тормоз трамвая | 46.15, 46.16 | N_K = F(a + b)/b, N_L = F(a/b)(b + d)/d; условие равных давлений a/b = (a + b + c)/c, Q = F(a + b)/(2b) |
| Грузы на наклонных плоскостях | 46.17 | P₁ = P/(2 sin α), P₂ = P/(2 sin β) |
| Грузы A, B и блок с грузом K | 46.18 | P = Q/2, f = 1 (независимые перемещения A и B) |

## Дополнение к «Принципу Даламбера» (Яблонский, Д.16)

Рассматриваемое положение при вращении под действием пары можно задать углом поворота φ от начала действия пары,
а не временем: ω² = ω₀² + 2εφ (поле «момент задан» во вкладке «Принцип Даламбера»; в файле — необязательное поле
`drive.angle`, градусы). Знак ω берётся по ω₀, из состояния покоя — по ε; если тело останавливается раньше, чем
повернётся на заданный угол, решение сообщает об этом. Д.19 (натяжения нитей) решалось и раньше — во вкладке
«Кинетическая энергия» (`tensions`); в таблице покрытия он был помечен как не сделанный по ошибке.
