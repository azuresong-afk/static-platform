# Геометрия масс: эллипсоид инерции (пункт 28)

Раздел «Геометрия масс» (`src/modules/inertia/`). Пункт 28 добавил второй экран — кнопка «Эллипсоид инерции →»
(`model/extra.ts`, `extraPresets.ts`).

## Модель и формулы

Тензор инерции относительно точки O по J_x, J_y, J_z и центробежным J_xy = Σmxy, J_yz, J_zx (в матрице — с минусом) или
по однородному тетраэдру OABC с рёбрами по осям (J_x = M(b² + c²)/10, J_xy = Mab/20). Главные моменты и оси —
собственные значения и векторы (метод Якоби); эллипсоид J₁ξ² + J₂η² + J₃ζ² = 1; эллипсоид вращения отмечается.
