# Принцип Даламбера: пластинка, вращающаяся вокруг оси в своей плоскости (пункт 28)

Раздел «Принцип Даламбера» (`src/modules/dalembert/`). Пункт 28 добавил второй экран к режиму вращающегося вала — кнопка
«Пластинка, вращающаяся вокруг оси в своей плоскости →» (`model/extra.ts`, `extraPresets.ts`).

## Модель и формулы

Однородная пластинка-многоугольник (вершины «x : z») в плоскости xz вращается вокруг оси z с ω = const; опоры A и B на
оси. Площадь, x_C и J_xz = (M/S)∫xz dS — по формулам Грина. Кинетостатика:
X_A + X_B + ω²Mx_C = 0, z_A X_A + z_B X_B + ω²J_xz + Mgx_C = 0 (тяжесть вдоль оси — по выбору). Обратная задача —
ω, при которой боковое давление на опору A или B равно нулю.

## Готовые задачи и ответы книги

42.12 (прямоугольник, ось — диагональ: Y_A = −Y_B = Pabω²(a² − b²)/(12g(a² + b²)^{3/2})), 42.13 (треугольник:
ω = 2√(g/a)).

## Ограничения

Ось вращения лежит в плоскости пластинки; пластинка однородная, контур — один многоугольник без отверстий.
