## Модель и формулы

Уравнение прежнее: ẍ + 2nẋ + k²x = h(t), h = F/m, x — от положения статического равновесия.

**Участки.** Сила, не гармоническая, раскладывается на участки по времени `[t₀, t₁)`; на каждом — сумма слагаемых:

- многочлен h = h₀ + s(t − t₀): x_p = A + B(t − t₀), B = s/k², A = (h₀ − 2nB)/k²;
- экспонента h₀e^{−βt}: x_p = h₀e^{−βt}/(β² − 2nβ + k²); если −β совпадает с корнем характеристического уравнения
  (апериодический случай и n = k) — множитель t (простой корень) или t²/2 (двукратный);
- гармоника h sin(pt + δ): как раньше, при n = 0, p = k — резонансная с множителем t.

Решение участка — свободные колебания от состояния в t₀ плюс x_p. В момент смены силы x и ẋ непрерывны, по ним находятся
постоянные следующего участка. Проверка численным интегрированием идёт по участкам (сила разрывна).

| Возмущение | Участки | Формула книги |
|---|---|---|
| `ramp`, F = a·t | один | x = (a/c)(t − sin kt/k) при n = 0, x₀ = ẋ₀ = 0 (32.76) |
| `exp`, F₀e^{−βt} | один | x = h/(k² + β²)·(e^{−βt} − cos kt + (β/k) sin kt) (32.77) |
| `pulse`, F на 0 ≤ t ≤ τ | два: сила, свободные колебания | x_max = F/c·√2 при τ = T/4; 2F/c при τ = T/2; S/√(mc) при τ → 0, Fτ = S (53.47) |
| `ramphold` | два: F₀t/τ, затем F₀ | при t > τ: x = (F₀/c)[1 − (sin kt − sin k(t − τ))/(kτ)] (53.49) |
| `cam`, ξ = a(1 − cos ωt) | два: до 2π/ω, затем свободные | x = c₁a/(m(k² − ω²))·(cos kt − cos ωt) + c₁a/(mk²)·(1 − cos kt) (53.43) |
| `two`, H₁, H₂ | один, два слагаемых | суперпозиция; вторая гармоника в 53.40: H₂ = H₁·r/l на частоте 2ω |

**Основание движется (`support`).** Пружина и демпфер связаны с основанием ξ = a sin(pt + δ); для относительного
смещения z = x − ξ получается z̈ + 2nż + k²z = −ξ̈ = κ·a·p²·sin(pt + δ)/m, где κ — масса, через которую ускорение
основания действует на систему (поле «вес в переносном движении»; 0 — весь груз). Показываются относительная амплитуда
B/a = z²/√((1 − z²)² + 4ζ²z²) и, при κ = m, абсолютная √(k⁴ + 4n²p²)/√((k² − p²)² + 4n²p²) (виброизоляция).
Вращательные системы (виброграф 53.38, маятник 37.40–37.41, торсиограф 53.44, диск 37.38) считаются как поступательные:
J ↔ масса (вес J·g), крутильная жёсткость ↔ c, момент ↔ сила; x = φ·(единица длины). Единицы должны быть согласованы:
в 53.38 J = 0,4 кГ·см·с² даёт «вес» 392,4 кГ, момент веса Qa = 10 кГ·см вводится как «вес в переносном движении» 10.

**Обратные задачи.** Неизвестное — c, l, E, J, A (у стержней и балок единственной ступени), g, b, вес или масса груза,
амплитуда возмущения, частота p, высота падения h; измеряется — T₀, T₁, k, амплитуда B, наибольшая по p амплитуда,
её отношение к H/c, сдвиг фазы ε, частота p*, x_max, K_д. Прямая задача решается `solveOsc`, корень ищется делением
отрезка пополам на логарифмической сетке в пределах 10⁻⁵…10⁵ от текущего значения; возвращаются **все** корни
(амплитуда при заданном J — до и после резонанса, 53.42). Найденное значение подставляется в копию задачи: схема, график
и решение строятся по ней; кнопка «Подставить найденное в задачу» делает это насовсем. Пара корней ближе 0,8 % друг к другу
может не разделиться — тогда уточните значение измеренной величины.
Опыты (замкнутые формулы): J = J_д(T₁/T)², c = J_д(2π/T)² (37.17); J = J_д·T₁²/(T₂² − T₁²) (37.18);
g = 4π²(δ₁ − δ₂)/(T₁² − T₂²), c = (P₁ − P₂)/(δ₁ − δ₂) (32.47); c = Pb²/l, J = Pa²/(3g), T = (2πa/b)√(l/3g) (37.19).

**Рычаги.** Пружина на рычаге — как раньше, c(a/b)². Демпфер на рычаге: b_пр = b(a/b)² (a — плечо демпфера, b — плечо
груза). Балка или стержень на пружине: последовательно, 1/c = 1/c₀ + 1/c_п (поле «пружина последовательно»).

**Резонансная кривая.** η(z) = B/B_ref, B_ref = H/c (постоянная сила, перемещение крепления) или H/(p²m) (ротор,
основание); η = 1/√((1 − z²)² + 4ζ²z²), для ротора и основания — с множителем z². Максимум при z* = √(1 − 2ζ²)
(ротор — 1/√(1 − 2ζ²)), высота 1/(2ζ√(1 − ζ²)), при ζ ≥ 1/√2 максимума нет. «Половинная ширина»: z² = 1 − 2ζ² ±
2ζ√(3 + ζ²), Δ = z₂ − z₁ ≈ 2√3·ζ. Рисунок — под графиком x(t): кривая задачи, для сравнения ζ = 0,05…1, сдвиг фазы,
точка текущей частоты, максимум, Δ.

**53.45 — противовес в желобе коленчатого вала.** В системе, вращающейся с валом (ω), на точку в желобе — дуге радиуса r
с центром B на расстоянии AB = l от оси A — действует центробежная сила mω²ρ, ρ² = l² + r² + 2lr cos φ (φ от линии AB);
сила Кориолиса перпендикулярна желобу, силой тяжести пренебрегают. Вдоль дуги φ̈ + (ω²l/r) sin φ = 0, k = ω√(l/r) —
устойчиво около наиболее удалённого от оси положения. Для амплитуды φ₀ показывается точный период T = 2π/(k·AGM(1,
cos(φ₀/2))) и график точного уравнения против φ₀ cos kt. Угловая скорость — рад/с или об/мин.

**53.48 — маятник с подвесом, движущимся по закону ξ(t).** T = m(ξ̇² + l²φ̇² + 2lξ̇φ̇ cos φ)/2, Π = −mgl cos φ:
lφ̈ + ξ̈ cos φ + g sin φ = 0; при малых φ φ̈ + k²φ = −ξ̈/l, решение
φ = φ₀ cos kt + (φ̇₀/k) sin kt − (1/(lk))∫₀ᵗ ξ̈(τ) sin k(t − τ) dτ (ответ книги). Закон ξ(t) — «ξ = a sin pt» (замкнутая
формула φ_p = a p²(sin pt − (p/k) sin kt)/(l(k² − p²)); при p = k — частное решение −(a k/(2l)) t cos kt) или любая
формула (ξ̈ — аналитической производной, интеграл — по Симпсону). На графике — малые колебания и точное уравнение
(Рунге — Кутта): расхождение видно, когда углы перестают быть малыми.

**53.50 — сила F|sin ωt|.** Функция периодична с периодом T = π/ω, на 0 ≤ t ≤ T равна F sin ωt. Колебания «с частотой
возмущающей силы» — периодическое решение: x = x_ч + C cos kt + D sin kt с x(0) = x(T), ẋ(0) = ẋ(T). Для k ≠ ω
x = F/(m(k² − ω²))·[sin ωt − (ω/k) sin kt − (ω/k) ctg(πk/(2ω)) cos kt], 0 ≤ t ≤ π/ω; далее повторение. Для k = ω
частное решение — −(F/(2mk)) t cos kt. Если k = 2jω (кратно частоте второй гармоники силы), периодического решения нет —
резонанс на 2ω-гармонике, программа отказывает с пояснением. В тесте решение сверено с рядом Фурье
|sin ωt| = 2/π − (4/π)Σ cos(2jωt)/(4j² − 1).

**53.53 — критическая скорость тяжёлого вала.** ω_кр = λ²√(EJ g/(q l⁴)), λ — первый корень частотного уравнения балки
с распределённой массой: шарнир — заделка (53.53) tg λ = th λ, λ = 3,9266, λ² = 15,418 (книга: 15,4); для сравнения
шарнир — шарнир (sin λ = 0, λ² = π²), заделка — заделка (cos λ ch λ = 1, λ² = 22,373), консоль (cos λ ch λ = −1,
λ² = 3,516).

**Д.25 — приведение системы тел к одной координате.** Все скорости и перемещения выражаются через q̇ и q: у тела
v = u·q̇, ω = w·q̇, у пружины деформация λ = s·q, у демпфера v_д = d·q̇, у груза подъём центра тяжести h = y·q² (y < 0 —
центр опускается, как у стержней, поставленных стоймя). Отсюда a = Σ m·u² + Σ J·w², c = Σ c_пр·s² + 2Σ W·y, b = α·d²,
b/a = 2n, k² = c/a. Уравнение a q̈ + b q̇ + c q = Q₀ sin pt, Q₀ = P·f; q = A sin(pt − ε),
A = h/√((k² − p²)² + 4n²p²), h = Q₀/a, tg ε = 2np/(k² − p²) (ε в (0, π)). Декремент η = πn/√(k² − n²) (по половине
условного периода, как у книги) даёт n = k/√(1 + π²/η²), α = 2na/d²; либо α задан и η вычисляется. Максимумы при
изменяющейся частоте: амплитуды координаты — p₁ = √(k² − 2n²), A = h/(2n√(k² − n²)); скорости — p₂ = k, h/(2n);
ускорения — p₃ = k²/√(k² − 2n²). Сообщения об ошибке: a ≤ 0, c ≤ 0 (равновесие неустойчиво), n ≥ k (апериодическое
движение). График — амплитудная кривая A(p) с отметками p и p₁.
