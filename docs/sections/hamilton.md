# Устойчивость и нелинейные колебания

Раздел `hamilton` (вкладка в блоке «Аналитическая механика», код — `src/modules/hamilton/`). Пункт 16 дорожной
карты: Мещерский §49 (интегралы движения, функция Рауса, канонические уравнения Гамильтона), §55 (устойчивость
движения), §56 (нелинейные колебания). Три режима, у каждого свои данные; файл проекта хранит все три.

## Интегралы, Раус, Гамильтон (§49, 55)

**Что решает.** Система задаётся как в «Уравнениях Лагранжа»: 1–3 обобщённые координаты, параметры, T(q, q̇),
Π(q), непотенциальные обобщённые силы Qⱼ. Раздел находит:

- обобщённые импульсы pⱼ = ∂T/∂q̇ⱼ;
- циклические координаты — сам: координата не входит в T и Π и Qₐ = 0; интеграл pₐ = nₐ = const, nₐ — по начальным условиям;
- обобщённый интеграл энергии (Якоби) Σq̇ⱼpⱼ − T + Π = h, если T и Π не зависят от t и непотенциальных сил нет;
- функцию Рауса R = L − Σnₐq̇ₐ (скорости q̇ₐ выражены из циклических интегралов) и уравнения для остальных координат
  d/dt(∂R/∂q̇ᵢ) − ∂R/∂qᵢ = Qᵢ; гироскопические члены gᵢⱼq̇ⱼ, gᵢⱼ = ∂aᵢ/∂qⱼ − ∂aⱼ/∂qᵢ, если R₁ = Σaⱼq̇ⱼ ≠ 0;
- функцию Гамильтона H = ½(p − b)ᵀA⁻¹(p − b) − T₀ + Π при T = ½q̇ᵀAq̇ + bᵀq̇ + T₀ (A⁻¹ — символьно, через
  присоединённую матрицу) и канонические уравнения q̇ⱼ = ∂H/∂pⱼ, ṗⱼ = −∂H/∂qⱼ + Qⱼ;
- проверку: канонические уравнения интегрируются (Рунге — Кутта) и сравниваются с решением уравнений Лагранжа,
  H и циклические импульсы — на графиках;
- стационарное движение (без циклических координат — относительное равновесие): точка, где ∂W/∂q = 0,
  W = −R₀ — приведённая потенциальная энергия (часть R без скоростей с обратным знаком); уточняется методом
  Ньютона от q\* в таблице координат. Устойчивость и частоты — по корням det(Mλ² + Gλ + K) = 0, M — из R₂,
  K = ∂²W/∂q², G — гироскопические коэффициенты.

**Правила знаков.** R = L − Σnₐq̇ₐ (как в книге: в 49.7 R = (m/2)(ṙ² − c²/r²) − Π). Постоянная циклического
интеграла n — сам импульс pₐ; в книге иногда другая нормировка (49.6: n = ψ̇ sin²θ, у нас n = ml²ψ̇ sin²θ). Импульсы
записываются p_q.

## Устойчивость по первому приближению (§55)

**Что решает.** Характеристическое уравнение a₀λⁿ + … + aₙ = 0 задаётся одним из способов:

- коэффициентами (степень 1–6);
- матрицей системы ẋ = A·x (порядок 1–4): det(λI − A) = 0;
- уравнениями M·q̈ + B·q̇ + C·q = 0 (1–3 координаты): det(Mλ² + Bλ + C) = 0.

Элементы — формулы от параметров. Коэффициенты уравнения выводятся в буквах; тождественно нулевые младшие
коэффициенты — нулевые корни (поворот системы как целого). Условия Гурвица (aₖ > 0 и миноры Δ₂ … Δₘ₋₁) — в буквах,
сокращённые на общий множитель, положительный при заданных параметрах, и со значениями. Корни — численно (метод
Аберта). Вывод:

- все Re λ < 0 — асимптотически устойчиво;
- есть Re λ > 0 — неустойчиво;
- корни на мнимой оси простые (или у кратного столько собственных векторов, какова кратность — по рангу A − λI,
  если известна матрица) — линейная система устойчива не асимптотически; для нелинейной — критический случай;
- кратный корень на мнимой оси с недостатком собственных векторов — неустойчиво (вековой член t·e^(λt)).

**Граница по параметру.** Перебор параметра на отрезке (240 точек) с уточнением границ делением пополам;
«устойчиво» — в смысле двух первых пунктов и третьего (недемпфированные системы 55.1, 55.17).

## Нелинейные колебания (§56)

**Что решает.** ẍ = f(x, ẋ) (автономная система, одна координата):

- особые точки ẋ = 0, f(x, 0) = 0 на отрезке ±1,5·max(амплитуды) и их тип по линеаризации (центр, седло, фокус, узел);
- фазовый портрет: основное движение и до шести дополнительных траекторий из x₀ без скорости;
- по основному движению — период, размах и амплитуда первой гармоники на последнем полном колебании, последовательные максимумы;
- метод усреднения (Крылова — Боголюбова) при k² > 0: ẍ + k²x = Φ, Φ = f + k²x (k² задаётся или берётся −∂f/∂x в нуле),
  ȧ = −(1/(2πk))∫Φ(a cos ψ, −ak sin ψ) sin ψ dψ; предельные циклы — нули ȧ(a), устойчив, если ȧ меняет знак с «+» на «−»;
  частота гармонической линеаризации ω²(a) = k² − (1/(πa))∫Φ cos ψ dψ;
- для консервативной системы (f = f(x)) — точный период T(a) по численному интегрированию.

Разрывные характеристики записываются через abs: sign x = x/abs(x). Квадратура по ψ — по серединам отрезков,
поэтому разрыв в ψ = π/2 не мешает.

## Расхождения с книгой

- **55.21.** Ответ книги μ₁ > μ₂, J₂/J₁ > μ₂/μ₁ — только два условия Гурвица из трёх. Характеристическое уравнение
  (после нулевого корня) J₁J₂λ³ + (μ₁J₂ − μ₂J₁)λ² + (c(J₁ + J₂) − μ₁μ₂)λ + c(μ₁ − μ₂) = 0, и нужно ещё
  Δ₂ > 0: c(μ₁J₂² − μ₂J₁²) > μ₁μ₂(μ₁J₂ − μ₂J₁). При J₁ = 1, J₂ = 2, μ₁ = 2, μ₂ = 1 оба условия книги выполнены, но
  при c < 6/7 вращение неустойчиво. Знак момента двигателя: M₁ = M₀ − μ₁(φ̇ − ω₀), как в условии.
- **55.22.** У матрицы, напечатанной в условии, характеристическое уравнение λ⁴ + λ³ + λ² + λ = 0, корни 0, −1, ±i,
  а не −1, −1, 0, 0, как в ответе (видимо, опечатка в условии; исправления одним элементом нет). Вывод «устойчиво» тот
  же: корни на мнимой оси простые.
- **56.7.** Ответ книги — первое приближение метода усреднения; приложение даёт то же (a = 0,199 при v₀ = 0,98),
  а размах, измеренный по движению, больше (0,223) и колебания смещены от нуля из-за члена 3βv₀ξ̇².
- **56.11.** Период в книге — первое приближение по μ; приложение берёт T = 2π/ω, ω² = k² + 3μγα² (отличие порядка μ²).

## Ограничения

- Функция Гамильтона — только при T, квадратичной по скоростям, и невырожденной матрице A; при сложных A
  выражение получается с раскрытыми скобками (49.13: (pψ − pφ cos θ)² не собирается обратно).
- Уравнение Якоби — Гамильтона и принцип Гамильтона — Остроградского (49.15–49.22, струна) не решаются.
- Неголономные системы (катящийся обруч 55.12–55.14) — нет: линеаризованные уравнения нужно вывести самому
  и задать в режиме «Устойчивость».
- Нелинейные колебания — одна степень свободы, автономные; без вынуждающей силы (субгармоники 56.9), без ударов об
  упоры (56.3–56.4) и трения покоя (56.8); точечные преобразования (56.13) не строятся.
