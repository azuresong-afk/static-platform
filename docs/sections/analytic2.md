## «Кинетическая энергия», второй экран

Кнопка «Нить, трос, падение тел, J·dω/dt →», вопросы пункта 29 — в `src/modules/energy/model/extra29.ts`.

**38.8 — бегуны.** Бегуны (тонкие диски весом P, радиус r) на горизонтальной оси, которая вращается вокруг вертикали
с Ω = πn/30; центр бегуна — на расстоянии l от вертикали. Точка касания с дном неподвижна, поэтому собственное
вращение ω₁ = Ωl/r. Абсолютная угловая скорость — сумма Ω и ω₁, обе по главным осям диска:
T₁ = ½m(Ωl)² + ½(mr²/2)ω₁² + ½(mr²/4)Ω², T = k·T₁. Ответ книги 39 кГм, по формуле 39,1.

**38.27 — эпициклический механизм.** Кривошип OA = r₁ + r₂ (стержень весом Q), колесо II (диск весом P) катится по
неподвижному колесу I; механизм в горизонтальной плоскости, момент M постоянный, пуск из покоя.
J_пр = (r₁ + r₂)²(2Q + 9P)/(6g), ½J_пр ω² = Mφ ⇒ ω = 2/(r₁ + r₂)·√(3gMφ/(9P + 2Q)) — ответ книги; график ω(φ).

**38.28 — кулачковый механизм.** Эксцентрик — диск радиуса R весом p, эксцентриситет e; за пол-оборота штанга проходит
2e и сжимает пружину c. J_O = (p/g)(R²/2 + e²), ½J_O ω² = c(2e)²/2. При R = 2e (как в книге) ω = 2√(cg/(3p)) —
не зависит от e.

**Д.18 — тело на колесе с двигателем.** Тело A опирается на ось колеса B и на шероховатую плоскость в точке D; колесо
катится без скольжения; момент двигателя b₁ dM/dt + b₂M = b₃ − αω.

- Координаты от оси O колеса: x — по движению, y — вверх. Центр масс C тела A: x_C (в книге OH = a), y_C (HC = h);
  опора D: x_D (OE = b) и глубина под осью (ED = c). Знаки задаёт пользователь — так собираются варианты, где C или D
  позади оси или C ниже H.
- Корпус двигателя связан с телом A (варианты 1–7, 9, 11–20, 30) или нет (8, 10, 21–29): реактивный момент M′ = M
  входит в уравнение моментов тела A только в первом случае.
- Теорема об изменении кинетической энергии: m_пр ẍ = M/r − f·Y_D, m_пр = m_A + m_B(1 + i²/r²). Принцип Даламбера для
  тела A относительно O: M′ − m_A g·x_C + Y_D(x_D − f·ED) + m_A ẍ·y_C = 0. Исключая Y_D: a₃ẍ = a₁M − a₂,
  d = x_D − f·ED, a₁ = d/r + f (корпус на A) или d/r, a₂ = f·x_C·m_A g, a₃ = m_пр d − f·y_C·m_A.
- До трогания: M(t) = (b₃/b₂)(1 − e^(−b₂t/b₁)), M_н = a₂/a₁, τ = (b₁/b₂)ln(b₃/(b₃ − b₂M_н)).
- Разгон: v̈ + 2nv̇ + k²v = D, n = b₂/(2b₁), k² = αa₁/(r a₃ b₁), D = (a₁b₃ − a₂b₂)/(a₃b₁), v(τ) = v̇(τ) = 0;
  при n > k — форма книги v = A e^(−nt) sh(k*t + β) + D/k²; при n < k и n = k — свои формулы. v* = D/k², M* = a₂/a₁.
- Торможение до qv* (в книге q = 0,9): двигателем (b₁ dM/dt = −αω, M = M* − αx/(r b₁)) — s = v*√(a₃ r b₁(1 − q²)/(αa₁));
  механическим тормозом (M = 0) — l = a₃(1 − q²)v*²/(2a₂). В вариантах 9, 11, 30 при торможении тело опирается в
  другой точке D₁: её координаты задаются отдельно, a₁′, a₂′, a₃′ свои, и путь s находится из квадратного уравнения
  (a₁′M* − a₂′ ≠ 0).
- Проверки: d > 0 (опора прижимается), M_н < b₃/b₂ (система трогается).

## «Уравнения Лагранжа»: параметр по положению равновесия

Флажок «обратная задача» в блоке поиска положений равновесия; модель — `src/modules/lagrange/model/inverse.ts`, текст —
`text/inverse.ts`. Положение q* — столбец «q* (равнов.)» таблицы координат.

- Условие равновесия Fⱼ(q*; p) = 0, Fⱼ = −∂W/∂qⱼ + Qⱼ^н, W = Π − T₀ (как в поиске равновесия).
- Если параметр входит в F только множителем p^k (ω² в центробежном потенциале −T₀), F = A + B·p^k и
  p^k = −A/B — выводится в буквах, затем число; при чётном k берётся положительный корень.
- Иначе — корни на отрезке «от … до» перебором с делением пополам (полюсы отбрасываются).
- Для каждого найденного значения: невязка остальных уравнений (несколько координат), устойчивость по K = −∂F/∂q в q*
  и проверка, не равна ли F нулю при любом q (тогда при этом p равновесие безразличное — 47.19).

Готовые задачи: 47.13 (стержень на трёх катках: T = (Q + 9P/8)ẋ²/(2g), обобщённая сила F; w = 8gF/(8Q + 9P)),
47.16 (угол регулятора при заданной ω, прямая задача), 47.17 (регулятор с пружиной: ω² = g(P₁ + P₂ + 2lc(1 − cos α))
tg α/(P₂(a + l sin α))), 47.18 (пружинный регулятор, n = 187,9 ≈ 188 об/мин; единицы кГ, см, g = 981 см/с²), 47.19
(четыре груза на рычагах: ω = √(2gQa/(Pl²)) при любом φ — Π = −Qa(1 + 2cos 2φ), T₀ = 2(P/g)l²ω²sin²φ).

## «Возможные перемещения», режим «Машины»: замкнутые контуры

Схема «Балок и рам» — дерево участков, поэтому замкнутую раму и фермы на стержнях она не собирает. Общая модель
`src/modules/virtual/model/linkvw.ts`: тела, связи (шарнир между телами или с землёй — две строки, каток или
стержень-опора — одна, стержень между телами — одна) и силы. Отбрасываем искомую связь (каток или стержень): строка
этой связи равна 1, остальные — 0; матрица 3n × 3n. Мгновенный центр тела — (−δy/δφ, δx/δφ). Геометрически
изменяемая или неопределимая система называется.

- **46.24, леса резервуара** (`scaffold`): левая стойка, верхний брус, правая стойка, нижний брус из двух частей (шарнир
  под силой P₁), опоры A (шарнир) и B (каток), стержень CD; подкос под 45°. Возможное перемещение: брус KB — поворот
  вокруг B, правая стойка — поступательно, верхний брус — вокруг шарнира на левой стойке, левая стойка неподвижна
  (поэтому P₂ работы не совершает). S = 12√2·P₁ при любых a, высоте рамы и P₂ (S > 0 — растяжение).
- **46.28, две фермы на стержнях** (`trusses`): фермы I, II с шарниром D, стержни III, IV к шарниру C, каток A
  (реакция вертикальна), каток B на наклонной плоскости (реакция под углом β, «слева направо вниз»). Решение
  показывает мгновенные центры C₁ (на вертикали через A и прямой CE) и C₂ (на прямых CF и C₁D) и формулу книги
  R_B = P·(a/b)·(DC₂/DC₁); сумма работ даёт то же число. Размеры в готовой задаче сняты с чертежа приблизительно.
