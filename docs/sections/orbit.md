## Модель и формулы

**Эллипс.** a, e, μ (числом или μ = gR²); p = a(1 − e²), b = a√(1 − e²), n = √(μ/a³), T = 2π/n,
r_п = a(1 − e), r_а = a(1 + e). Для точки с эксцентрической аномалией E:

- r = a(1 − e cos E) = p/(1 + e cos ν); tg(ν/2) = √((1 + e)/(1 − e))·tg(E/2) (50.30);
- уравнение Кеплера M = E − e sin E = n·t, решается методом Ньютона (E₀ = M при e < 0,8, иначе ±π; число шагов
  показано в решении), от истинной аномалии E = 2·arctg(√((1 − e)/(1 + e))·tg(ν/2));
- v² = μ(2/r − 1/a) = (μ/a)(1 + e cos E)/(1 − e cos E) (50.31); v_r = √(μ/p)·e sin ν, v_φ = √(μ/p)(1 + e cos ν);
  в системе с осью x в перицентр v_x = −√(μ/p) sin ν = −√(μ/a)·sin E/(1 − e cos E), v_y = √(μ/p)(e + cos ν) =
  √(μ/a)√(1 − e²)·cos E/(1 − e cos E) (50.33);
- v = √(v_п·v_а) = √(μ/a) при E = ±90° (50.32); наибольший угол траектории с местным горизонтом — там же, где
  cos ν = −e, и sin γ_max = e (50.34).

Время полёта вперёд по движению Δt = (M₂ − M₁)/n по модулю 2π (остаток периода — обратный путь по той же орбите).
Только эллипс (e < 1): параболу и гиперболу в этом режиме считать нельзя — для них «Орбита в центральном поле».

**Среднее значение r (50.28):** по времени [r] = a(1 + e²/2); для сравнения — по истинной аномалии φ равно b, по
эксцентрической E — a.

**Граница падения (50.24–50.25).** Из точки на расстоянии r₀ (высота H = r₀ − R): sin δ = R/r₀ — полуугол конуса
касательных, граничный угол с горизонтом cos θ_к = R/r₀. Вне конуса (r₀ cos θ₀ > R) траектория не пересечёт
поверхность, если v₀ ≥ v_кр: v_кр² = v₁²·2RH/((R + H)² cos² θ₀ − R²), v₁ = √(μ/r₀) (из условия r_п = R). Внутри
конуса — падение при любой v₀. Если задана v₀, проверка идёт по элементам орбиты (`elementsOf`, признак `hit`): при
движении от планеты и v₀ ≥ параболической точка уходит и поверхности не пересекает, даже если v₀ < v_кр (при очень
крутом подъёме v_кр может превышать параболическую скорость — об этом сообщение).

**Обратные задачи.** 50.15: a = p/(1 − e²), b = p/√(1 − e²), T = 2πab/c, μ = c²/p. 50.17: a = ∛(μT²/(4π²)),
e = H/(2a) = (H/2)·∛(4π²/(μT²)). 50.18: a = R(1 − γ)/(1 − e − γ(1 + e)), γ = H_п/H_а. 50.27:
M₁/M₂ = (a₁/a₂)³(T₂/T₁)² (массами спутников пренебрегаем; год — 365,25 сут).

**Формула Бине (50.12–50.13).** u = 1/r(φ), c = r²φ̇ = const: v² = c²(u² + u′²), a_r = −c²u²(u″ + u), a_φ = 0.
Производные r(φ) берутся символьно (в формуле φ в радианах записывается как `φ`, `phi` или `t`). По таблице
a_r(φ) режим определяет: a_r·r² = const (закон Ньютона, μ = c²/p для конического сечения) или степенной закон
a_r ∝ rⁿ (n выводится и проверяется по всем 12 точкам таблицы), иначе — «закон не степенной».

**Трасса (50.6).** r = R + H, n = √(μ/r³), Ω = 2π/T_вр (по умолчанию T_вр = 86 164 с, звёздные сутки), k = Ω/n.
Подспутниковая точка: sin φ = sin α·sin nt, λ = arctg(cos α·tg nt) − Ωt (счёт от восходящего узла). Угол трассы с
экватором tg β = sin α/(cos α − k); за виток трасса смещается на ΩT к западу; широта до α (или 180° − α).
Синхронная орбита в плоскости экватора (α = 0, k = 1) — точка.

**Два тела (51.1, 51.2, 51.5).** Относительное движение — как в поле неподвижного центра с μ = f(m₁ + m₂);
около центра масс точки движутся по тому же закону с μ₁ = f·m₂³/(m₁ + m₂)², μ₂ = f·m₁³/(m₁ + m₂)², полуоси
a₁ = a·m₂/(m₁ + m₂), a₂ = a·m₁/(m₁ + m₂). Период T = 2π√(a³/μ) короче периода при μ = f·m₁ в √(m₁/(m₁ + m₂)) раз —
это поправка к третьему закону Кеплера в 51.2: T₁²/T₂² = (a₁³/a₂³)(M + m₂)/(M + m₁).

**Маховик (51.9–51.12).** Момент количества движения системы сохраняется: J₀Ω + Jω = const (ω — скорость маховика
относительно корпуса). 51.9: ω = J₀Ω₀/J, A = J₀(J₀ − J)Ω₀²/(2J). 51.10: момент M = M₀ − κω, α = κJ₀/(J(J₀ − J)),
ω = (M₀/κ)(1 − e^(−αt)); корпус остановится, если M₀ > α(J₀ − J)Ω₀; T = (1/α) ln(M₀/(M₀ − α(J₀ − J)Ω₀)).
51.11: ψ = Ω₀/α − [M₀ − α(J₀ − J)Ω₀]/[α²(J₀ − J)]·ln(M₀/(M₀ − α(J₀ − J)Ω₀)). 51.12 (ω̇ + ω/T = ±u₀):
τ = ψJ₀/(JTu₀); t₁ = τ + T ln(1 + √(1 − e^(−τ/T))) — разгон, t₂ = t₁ − τ — торможение маховика.

## Правила знаков

- Углы аномалий отсчитываются от перицентра против движения часовой стрелки по ходу точки, E ∈ (−180°, 180°].
- θ₀ — угол скорости с местным горизонтом (перпендикуляром к радиусу), положительный — от планеты.
- a_r > 0 — от центра, a_r < 0 — к центру (притяжение).
- Наклонение α от 0° до 180°: α < 90° — орбита по вращению тела, α > 90° — против. β отсчитывается от направления
  на восток против часовой стрелки на карте «долгота — широта».

## Расхождения с книгой

- **50.6** — в ответе книги в знаменателе cos α + Ω√((R + H)³/μ). Для орбиты по вращению Земли (α < 90°) вращение
  вычитается из восточной скорости спутника: tg β = sin α/(cos α − Ω√(r³/μ)); формула с «+» верна для α > 90°
  (орбита против вращения, в модуле — для α′ = 180° − α). Раздел считает по «−» при любом α ∈ [0°, 180°]; значение по
  формуле книги с «+» показано в решении. Чисел в ответе книги нет, подгонять нечего.

## Ограничения

- Время полёта и аномалии — только эллипс; для параболы и гиперболы время от перицентра (уравнение Баркера и
  гиперболическое уравнение Кеплера) не считается.
- В «Границе падения» учитывается только сферическая планета без атмосферы.
- Трасса — невозмущённое кеплерово движение вокруг сферы (без сжатия Земли, прецессии узла, атмосферы).
- Задача двух тел — плоское относительное движение; масса и f в системе СИ.
- Формула Бине: r(φ) должна быть положительной и однозначной на участке таблицы (φ₁ ± 60°); неявные траектории
  (r² = a² cos 2φ) вводятся явным r = a√(cos 2φ).
- Вопросы §51 в виде вывода формул (51.1, 51.5 «определить закон движения») показаны на числах.
