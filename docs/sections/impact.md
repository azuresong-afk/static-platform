# Удар: второй экран (пункт 28)

Раздел «Удар» (`src/modules/impact/`): основной экран — соударение двух тел в плоскости (см. README, «Удар»). Пункт 28
добавил второй экран — кнопка «Обратные задачи о шарах, цепочка ударов →» (`model/extra.ts`, `extraPresets.ts`).

## Что решает

- **Остановка второго шара (44.8):** m₂/m₁ = −[(1 + k)(v₁ − v₂) + v₂]/v₂.
- **Три шара (44.9):** масса среднего шара, при которой третий получает наибольшую скорость, m₂ = √(m₁m₃).
- **Косой удар о плоскость (44.13):** tg β = tg α/k, v₁²/v² = sin²α + k² cos²α — углы по отношению скоростей или по
  углу падения.
- **Прицеливание (44.15):** BC₂ = 4R²/a.
- **Цепочка ударов (Яблонский Д.13):** тело (цилиндр, обруч, шар, радиус инерции) движется поступательно (внезапная
  остановка платформы) или катится; препятствия «S:h» — удар о ребро ступеньки (сохраняется кинетический момент
  относительно ребра), подъём на ступеньку; «I:α» — удар о наклонную плоскость (момент относительно точки касания),
  качение вверх на путь s. Находит путь по скорости или скорость по пути (наименьшую — чтобы подняться на все
  ступеньки); ударные импульсы — по теореме об изменении количества движения.

## Готовые задачи и ответы книги

44.8 (два случая), 44.9, 44.13, 44.15, Д.13 (v = 3,68 м/с, S_D = 1208 Н·с, S_F = 704 Н·с: 691 по нормали, 133 вдоль).

## Ограничения

Удары без проскальзывания и отрыва; сопротивление качению не учитывается. Удары стержней, маятников, тел на пружинах —
в основном режиме, по одному удару.
