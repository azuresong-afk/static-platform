# Реакции при плоском движении: второй экран (пункт 28)

Раздел «Реакции при плоском движении» (`src/modules/planebody/`). Пункт 28 добавил второй экран — кнопка
«Кинетический момент, свободное тело, отпущенный стержень, … →» (`model/extra.ts`, `extraPresets.ts`).

## Что решает

- **Кинетический момент тел в плоском движении (37.1–37.3):** таблица тел «m : J_C : x : y : v_x : v_y : ω»,
  L_O = Σ(J_Cω + m(x v_y − y v_x)), L_C — относительно центра масс системы.
- **Свободное движение тела (39.1–39.3):** по начальным условиям — центр масс движется как брошенная точка, вращение
  равномерное; траектория любой точки тела; начальные данные — скорость центра масс и ω или скорости двух точек.
- **Отпущенный стержень (43.3), скольжение по гладкому полу (43.5–43.6):** угловая скорость при падении, условие касания
  пола вертикально.
- **Приведённые массы (43.9):** главные векторы и моменты сил инерции стержня и двух точечных масс; разность моментов
  m(ρ² − ab)ε.

## Готовые задачи и ответы книги

37.1–37.3, 39.1–39.3, 43.3, 43.6, 43.9 (в буквах — числа для примера).

## Расхождения с книгой

- 37.3: в печатном ответе местами r² вместо r₂ — по-видимому, опечатка.
- 39.1: парабола y² = 117,4x (книга 117,5x).

## Ограничения

Тела — плоские, одно твёрдое тело или набор тел в данный момент; связи — только в основном режиме.
