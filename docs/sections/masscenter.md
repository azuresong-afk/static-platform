# Центр масс и плоское движение: работа и мощность, количество движения, давление струи

Раздел `masscenter` (вкладка «Центр масс»). Первые три режима — система точек, сохранение положения центра масс,
плоское движение колеса — описаны в README («Центр масс и плоское движение»). Здесь — три режима пункта 14
дорожной карты: Мещерский §29 и §36. Модель — `src/modules/masscenter/model/dynamics.ts`, текст решения —
`text/dynamics.ts`, чертежи — `draw/dynamics.ts`, тесты — `tests/masscenter.test.ts`.

## Что решает

- **Сохранение количества движения** (§36.8–36.12): тела вдоль одной оси до и после взаимодействия (выстрел,
  разрыв, рывок каната, торможение тележки на платформе). Одна неизвестная скорость; изменение кинетической
  энергии; для двух тел и постоянной силы взаимодействия F — путь одного тела по другому и время торможения.
- **Давление струи** (§36.13–36.18): установившийся поток через неподвижный контур (стена, колено трубы, канал,
  лопатка, патрубок котла). Сила давления жидкости на стенки и, если задан вес сосуда с жидкостью, — реакция опор.
- **Работа и мощность** (§29): равномерное движение под нагрузками; мощность двигателя, время работы или сила
  нагрузки при заданной мощности; КПД; работа за время или за k повторений.

## Модель и формулы

### Сохранение количества движения

Ось x; скорость — проекция со знаком. У каждого тела масса (или вес, m = P/g), скорость до v и после u. Скорость
задаётся абсолютной или относительно другого тела в том же состоянии: абсолютная = относительная + абсолютная
скорость того тела (цепочки допускаются, круг — ошибка). Относительная скорость 0 — тела движутся вместе.
Неизвестная X — одна из скоростей (в том виде, как она задана). Все абсолютные скорости линейны по X, и

  Σm_i·v_i = Σm_i·u_i  (Q_x = const)  →  X.

Кинетическая энергия T₀ и T₁, ΔT = T₁ − T₀. Если тел два, F > 0 и энергия убывает: путь тела 2 по телу 1
s = (T₀ − T₁)/F (работа пары сил трения равна −F·s), время τ = |m₂(u₂ − v₂)|/F (теорема об импульсе для тела 2).

### Давление струи

Сечения — входы и выходы; у каждого площадь A, модуль скорости v и её направление (угол от оси x против часовой
стрелки, ось y — вверх). Секундная масса ṁ = ρ·A·v (по удельному весу ρ = γ/g, силы — в кГ). Одно сечение может
иметь A = 0 — его расход по неразрывности: Σṁ_вх = Σṁ_вых. Сила давления жидкости на стенки

  R = Σ_вх ṁ·v⃗ − Σ_вых ṁ·v⃗

(теорема об изменении количества движения для объёма жидкости; давлением в сечениях и весом жидкости пренебрегаем).
Если задан вес W сосуда с жидкостью: реакция опор N = (−R_x; W − R_y); при N_y < 0 опоры не держат — давление на
опоры равно нулю. Если приток и отток различаются больше чем на 1 %, решение предупреждает.

### Работа и мощность

Нагрузка — сила F вдоль движения или вес P на наклоне α с трением f: F = P(sin α + f cos α) (α = 90° — подъём,
α = 0 — трение fP). Скорость — заданная v, k раз путь s за время t (v = ks/t) или окружная скорость шкива
v = πdn/60 (n — об/мин). Мощность нагрузок N_н = ΣF·v, работа — N_н·t, у путевой нагрузки k·F·s (и без t).

- полезные сопротивления: двигатель развивает N = N_н/η;
- движущие силы (флажок): полезная мощность N = η·N_н.

Ищем: N (и работу), время t (нужна хотя бы одна путевая нагрузка: N_н = P₀ + W/t) или величину F (P) одной
нагрузки. Единицы: технические (кГ, кГм, кГм/с; 1 л. с. = 75 кГм/с, 1 кВт = 1000/g кГм/с) или СИ (Н, Дж, Вт;
1 л. с. = 75g Вт). Мощность двигателя вводится в л. с., кВт или основных единицах.

## Правила знаков

- Количество движения: скорости — проекции на ось x (вправо «+»); ответ со знаком: «−» — против оси.
- Струя: угол скорости — от оси x против часовой стрелки, ось y — вверх; R — сила жидкости на стенки.
- Мощность: F «+» — по движению; КПД 0 < η ≤ 1.

## Ограничения

- Количество движения — только вдоль одной оси и без импульса внешних сил (трение о неподвижную опору не учитывается).
- Путь и время торможения — только для двух тел и постоянной силы взаимодействия.
- Струя: только динамическая составляющая — без давления в сечениях трубы и без веса жидкости в канале.
- Работа и мощность — равномерное движение; разгон, переменные силы — в «Кинетической энергии» и «Динамике точки».
- 29.1, 29.16 и 35.15–35.16 — на втором экране (пункт 28, ниже); 29.14 — в «Ударе и колебаниях» (энергия в общем
  виде).

## Второй экран (пункт 28)

Кнопка «Работа, тележка, призма, торможение, качение →» (модель — `model/extra.ts`, готовые задачи — `extraPresets.ts`).

- **Опрокидывание (29.1):** A = P(√(a² + y_C²) − y_C), a и y_C — положение центра тяжести относительно ребра
  (прямоугольник b × h: a = b/2, y_C = h/2).
- **Маятник двумя способами (29.16):** Π₁ = Py, Π₂ = Px²/(2l), x² = 2ly − y²; разность Py²/(2l).
- **Крановая тележка (35.15–35.16):** R_y = P₁ + P₂; на упругой балке y₁ = −((P₁ + P₂)/c) cos √(cg/(P₁ + P₂)) t (ось y
  вниз от статического равновесия); при φ = φ₀ cos ωt, ω = √(g/l): R_x = −(P₂/g) lφ₀ω² cos ωt, незаторможенная тележка
  x₁ = (P₂lφ₀/(P₁ + P₂))(1 − cos ωt).
- **Тела на призме (Яблонский Д.7):** θ₁, θ₂ — углы положительных направлений относительных перемещений тел 1, 2 с осью
  x, s₂ᵣ = k s₁ᵣ. Гладкая плоскость: s₃ = −(m₁ cos θ₁ + m₂k cos θ₂)s₁ᵣ/m, реакция упора R_x = (m₁ cos θ₁ + m₂k cos θ₂)s̈₁ᵣ.
  Шероховатая: N = G + (m₁ sin θ₁ + m₂k sin θ₂)s̈₁ᵣ; тело 3 сдвигается при s̈₁ᵣ > f_сц G/(|P_x| − f_сц P_y), далее
  s₃ = ∓(fgt²/2 − B s₁ᵣ), B = (|P_x| − f P_y)/m (знак — против P_x).
- **Внутреннее торможение (Яблонский Д.8):** K_x = mẋ + μω₂ cos θ, μ = m₂c₂ + m₃c₃; N = mg − με₂ sin θ;
  ẍ = (με₂ cos θ ∓ f|N|)/m (− βẋ при вязком трении, β = b/m). Тело 1 может остановиться (T*) и пойти обратно, если
  |με₂ cos θ| > f|N|; ответ — точно и приближённо (как в книге: без импульса веса и перемещений за время T).
- **Предельное качение (Яблонский Д.12):** F_сц = [P(Re − i_C² cos β) + i_C² G sin α − RδN]/(R² + i_C²),
  N = G cos α − P sin β; граничные P — из |F_сц| = f_сц N (обе ветви), закон движения x_C = ẍ_C t²/2. Знаки: ось x
  вдоль опоры (α > 0 — вверх по уклону), β > 0 — сила от опоры, e > 0 — момент силы по качению в сторону x.
