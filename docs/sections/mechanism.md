## Что добавлено

- **Формулы книги** (`MechProblem.formulas`, `model/solve.ts`, `text/solution.ts` — шаг «Формулы книги»): величина
  графика (ключ `plotKeys`) сверяется с формулой книги от φ или t на диапазоне графика; допуск `tol` — для приближённых
  формул. Применено в 14.11–14.14 (закон движения ползуна), 15.6 (инверсор Поселье — Липкина), 16.38.
- **ω и ε по ускорениям двух точек** (`model/acc2.ts`, `ui/Acc2View.tsx`, задача `acc2`): ε = d·n/L, ω² = −d·e/L,
  d = a_B − a_A; ускорения других точек a_C = a_A + ε × AC − ω²·AC; мгновенный центр ускорений AQ = −M⁻¹a_A,
  tg μ = |ε|/ω². Знак ω по ускорениям не определяется. Задачи 18.29–18.36.
- **Планетарные и эпициклические передачи** (связь «зацепление» `gear`): 24.13 («Триплекс»), 24.14 (цилиндрический
  дифференциал), 24.15 (картофелекопатель), 24.17 (эпицикл с промежуточным колесом). В 24.16 цепь между равными
  шестерёнками — связь «поступательное движение» (шарнирный параллелограмм).
- **Манипулятор К.9:** захват D по законам X(t), Y(t), звенья находятся обратной задачей (`two` — пересечение двух
  окружностей), угловые скорости и ускорения — из двух проекционных связей на D. Пример (числа не из задания).

## Расхождения с книгой

- **14.14:** формула книги требует смещения x*B = x_max − x*книги — задача решена с этим смещением.
- **15.6:** инвертор строится при l > a, вершина A на расстоянии x_A = (l² − a²)/(2r); ромб — четыре отдельных
  стержня (жёсткое тело из четырёх точек переопределено).
- **16.38:** ответ книги получается для кривошипа, вращающегося по часовой стрелке (ω₀ = −5), что и записано в задаче.
- **К.9:** рисунок задания и числа вариантов не сверялись — готовая задача «(пример)».
