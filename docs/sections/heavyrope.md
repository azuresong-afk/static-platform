# Тяжёлые нити и переменная масса: доработки

Пункт 24 (Мещерский §27, 38, 45). Нового раздела нет: в трёх разделах — «Кинетическая энергия», «Переменная масса» и
«Динамика точки» — добавлен второй экран с набором вопросов («Нить, трос, падение тел, J·dω/dt →», «Общий вид,
обратные задачи, ротор →», «Сила по пути, несколько центров, баллистика →»; в каждом — кнопка «←» обратно).
Один и тот же каркас во всех трёх (`src/shared/extra.ts`, `src/shared/ui/ExtraScreen.tsx`): вопрос выбирается списком
«Вопрос», поля данных зависят от вопроса, справа — решение по шагам, сверху — график или траектория. Состояние —
`ExtraProblem {ask, n, s}` (числа, строки и выбор); файл проекта хранит его рядом с прежней задачей раздела
(поля `extra` и `view`), поэтому файлы, сохранённые до пункта 24, открываются как раньше.

Файлы: `model/extra.ts` (расчёт и текст решения каждого вопроса), `extraPresets.ts` (готовые задачи с ответом книги),
`ui/store.ts` (состояние, отмена, файл проекта). Тесты: `tests/energy-extra.test.ts`, `tests/varmass-extra.test.ts`,
`tests/pointdyn-extra.test.ts`; в «Задачнике» 30 новых задач.

Принятые обозначения: `g = 9,81 м/с²`; во всех задачах с буквенным ответом книги числа взяты для примера и сверены
с формулой книги (в условии даны буквы), численные ответы книги — как напечатано.

## «Кинетическая энергия» (§38)

| Вопрос | Задачи | Что решает |
|---|---|---|
| `pulley` | 38.15 | груз на нити между двумя блоками: наибольшее опускание p₁h = 2p(√(l² + h²) − l) ⇒ h = 4pp₁l/(4p² − p₁²), скорость на глубине h |
| `slide` | 38.16 | груз на гладком стержне на расстоянии a от блока и груз на нити: v² = 2g[P₁h − P(√(a² + h²) − a)]/(P₁ + Ph²/(a² + h²)) |
| `stop2` | 38.17 | две стадии (с нагрузкой и без): коэффициент трения из остановки f = [(P + P₁)s₁ + Ps₂]/[Q(s₁ + s₂)] |
| `table` | 38.18 | весомая нить сходит со стола: x″ = k²(x − x*), k² = (1 + f)g/L, x* = fL/(1 + f); T = arch((L − x*)/(l − x*))/k; f = 0 — книга: T = √(L/g)·ln[(L + √(L² − l²))/l] |
| `peg` | 38.19 | весомая нить на гладком штифте: v² = v₀² + g(a² − d²)/a (d — смещение, d = 0 — книга v = √(ag + v₀²)) |
| `cable` | 38.47 | груз на тросе, навитом на барабан: T = ½[(P + pl)/g + J/R²]v², работа P(x − x₀) + p(x² − x₀²)/2 |
| `cable48` | 38.48 | трос через блок к оси катка с трением качения: T = (P₁ + 2P₂ + Q)v²/(2g), работа веса троса Q/(2L)·h(2l + 2r + h), давление катка линейно убывает с h |
| `ladder` | 38.34 | стремянка на гладком полу: θ̇² = g(h₀ − h)/(l² + ρ²), v_B = 2l sin θ·θ̇ (1) при ударе, 2) на заданной высоте); реакция пола N = P(1 + ÿ_D/g) |
| `rod` | 38.35 | падающий стержень: v_C = (a − h)√(6g(a + h)/(4a² − 3h²)); реакция пола N(h) |
| `track` | 38.4 | кинетическая энергия гусеницы: T = 2γ(l + πr)v₀²/g (верхняя ветвь 2v₀, нижняя 0, дуги — среднее 2v₀²) |
| `jw` | 38.51–38.53 | приведённый момент инерции эпициклического (J = (R + r)²(m/3 + 3M/2)) и гипоциклического (R − r) механизма; J·dω/dt = M₀ − αω − M_тр·R/r, ω(t) = (M_эфф/α)(1 − e^(−αt/J)); торможение трением: τ = Jω₀r/(M_тр R), φ = Jω₀²r/(2M_тр R) |

Правила знаков и допущения: вес троса, навитого на барабан, при расчёте потенциальной энергии не учитывается, но вся
масса троса участвует в кинетической энергии (скорость навитой части равна скорости груза, толщиной троса
пренебрегаем) — как в ответе книги к 38.47 (в знаменателе P + pl). В 38.34 стяжка разорвана, шарнир B движется по
вертикали (горизонтальных внешних сил нет). Момент трения на оси сателлита работает на относительном повороте
сателлита ω_отн = ωR/r, поэтому приводится к кривошипу как M_тр·R/r. Для 38.52 это означает: книга даёт ответ с
буквами, раздел — число; в 38.53 кривошип и сателлит — однородный стержень и диск, массы заданы массами или весами.

Расхождения и ограничения: **38.4** — в книге нужна кинетическая энергия одной гусеницы, раздел считает только её
(без колёс). **38.52–38.53** — готовых чисел в книге нет (ответы буквенные и частично нечитаемы в скане): формулы
выведены заново (приведённый момент инерции проверен суммой кинетических энергий звеньев, ω(t) — интегрированием
уравнения). **38.17** — книга: f = 0,2; формула с данными условия даёт 0,203 (округление в ответе, допуск 2 %).
Не сделаны 38.8 (бегуны — пространственное вращение) и 38.27–38.28 (эпициклический и кулачковый механизмы со своей
геометрией).

|---|---|---|
| `pend` | 45.1 | маятник переменной массы m(t), отделение с нулевой относительной скоростью, сопротивление R = −βφ̇: φ̈ + β/(m(t)l)·φ̇ + (g/l) sin φ = 0 — уравнение и интегрирование |
| `rocket` | 45.2 | подъём ракеты по закону сгорания m = m₀f(t), сопротивление R(x, ẋ) формулой: ẍ = −g − (ḟ/f)v_e − R/(m₀f); ḟ — символическое дифференцирование |
| `aero` | 45.29–45.30 | аэростат поднимает канат со склада: ẍ = −g + Pg/(Q + γx) − (βg + γ)ẋ²/(Q + γx) и скорость по формуле книги |
| `height` | 45.5 (готовая задача уже была), 45.6–45.7 | высота подъёма при m = m₀e^(−αt): H = αv_e(αv_e − g)t₀²/(2g); оптимальное α → ∞, H_max = μ²v_e²/(2g), H = H_max(k − 1)/k |
| `moon` | 45.8 | время сгорания до заданной скорости: t = (v_e ln z − v)/g |
| `work` | 45.19–45.20 | работа силы тяги A = m₁v_e²(z − 1 − ln z); к.п.д. η = ln²z/(z − 1) и его наибольшее значение |
| `soft` | 45.25 | мягкая посадка: α = v₀²/(2v_eH) + gR/(v_e(R + H)); время торможения и m/m₀ — интегрированием |
| `slope` | 45.27 | подъём вдоль наклонной прямой с ускорением w: Φ/m = √(w² + g² + 2gw sin α), cos β = w cos α/(Φ/m), z = exp[(Φ/m)t/v_e], t = √(2H/(w sin α)) |
| `rotor` | 45.36–45.37 | реактивный запуск ротора: J(t)ω̇ = Rqv_e − M (или − bω), J = J_p + (m₀ − qt)r²; ω = (Rqv_e − M)/(r²q)·ln(J₀/J_p) и ω = (Rv_eq/b)[1 − (J_p/J₀)^(b/(r²q))] |
| `center` | 45.35 | притяжение к центру массы M₀/(1 + αt): ξ = x/(1 + αt), τ = t/(1 + αt) сводят движение к кеплерову; тип орбиты, e, a; проверка интегрированием исходных уравнений |

Расхождения с книгой:

- **45.8** — формула v = v_e ln z − gt с данными условия (v_e = 2000 м/с, z = 5, g = 1,62 м/с², v = 3000 м/с) даёт
  t = 135 с (2 мин 15 с); в ответе книги «≈ 2 мин 4 с» (124 с), разница 9 %. Готовая задача проверяется с допуском 10 %.
- **45.19** — книга печатает A = m₁v_e²[ln z − (z − 1)], что отрицательно; работа силы тяги положительна и равна
  m₁v_e²(z − 1 − ln z) (интеграл от v_e·v·dm), сравниваются модули.
- **45.20** — ответ книги: z — корень уравнения ln z = 2(z − 1)/(1 + z). У него нет корня z > 1 (для z > 1 всегда
  ln z > 2(z − 1)/(z + 1)). Принято классическое определение к.п.д.: кинетическая энергия ракеты ½m₁v² к энергии струи
  ½(m₀ − m₁)v_e², тогда η = ln²z/(z − 1), максимум при ln z = 2(z − 1)/z, z = 4,92, η = 0,648, v = 1,59·v_e.
- **45.35** — книга берёт приведённое время τ = 1/(α(1 + αt)); раздел — τ = t/(1 + αt) = 1/α − τ_книги: те же
  уравнения (время входит во второй производной), но отсчёт от начала движения; начальная скорость в новых
  переменных dξ/dτ = ẋ₀ − αx₀. Замена проверена интегрированием обеих систем (расхождение < 10⁻⁷). Учтено: время τ ограничено числом 1/α,
  поэтому за всё время t ∈ [0, ∞) точка проходит в (ξ, η) лишь конечный участок орбиты.

Ограничения: 45.36–45.37 — сопла на ободе радиуса R, шашки на радиусе r (так в ответе книги); в 45.25 принято
g на поверхности и радиус Луны 1,62 м/с² и 1737 км (можно менять); в 45.1 закон массы — формула от t.

| `centers` | 27.59, 27.60, 27.65, 27.66 | притяжение силами kᵢ·m·(rᵢ − r) к 1–3 центрам, центры могут двигаться равномерно, плюс постоянная сила: r(t) = c(t) + (r₀ − c₀)cos ωt + ((v₀ − u)/ω) sin ωt, ω = √Σkᵢ — точная формула; полуоси эллипса, период, моменты пересечения оси Ox, наименьшее расстояние до точки и скорость там |
| `incline` | 27.64 | равномерное движение по шероховатой плоскости под действием тяжести и горизонтальной нити: tg α/f = v₁/v, T = fG cos α·√(1 − (tg α/f)²) |
| `ball` | 27.41 | снаряд при сопротивлении, заданном таблицей «скорость : замедление» (кусочно-линейная интерполяция): высота, дальность, время полёта, их приращения без сопротивления, обе траектории |

Расхождения и ограничения: в **27.41** действительная траектория дана в книге графиком (рисунок), цифр там нет,
поэтому готовой задачи с ответом книги нет: раздел принимает таблицу замедлений, а ответы книги (7,5 и 12 км, 36,5 и
16,7 км) получатся, если ввести значения, снятые с рисунка. Проверяется полёт в пустоте (v₀²sin²α/2g, v₀²sin 2α/g) и
монотонность влияния сопротивления. В **27.60** условие записано как «k·m·MC₁ и k·m·MC₂», центр C₂ — x₂ = 2(a + bt);
ответ книги в тексте скана не читается, поэтому проверялся интегрированием: x = a + bt, y = a cos(√(2k)·t) (при x₀ = y₀ = a,
ẋ₀ = b, ẏ₀ = 0). В **27.66** книга ставит вопрос «каково отношение c₁/c, чтобы траектория проходила через центр»:
ответ c₁/c = 2 и v = v₀ проверен (расстояние до центра обращается в нуль). Не сделаны 27.50–27.51 (геометрические места),
27.67–27.68 (движение по заданной гладкой кривой — в «Динамике точки» есть режим «поверхности и кривые», но заданная
кривая в виде формулы не вводится).

Проверки: все готовые задачи сверяются с ответом книги в тестах; кроме того — интегрирование уравнений движения
независимо от формул (ODE для нити на столе с трением, падающий стержень по Лагранжу, аэростат, ротор, посадка на Луну,
несколько центров, центр переменной массы).
