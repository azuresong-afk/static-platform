## 54.9–54.11 — стержень на нити при малом отношении длин

Нить длины l (безмассовая) и однородный стержень длины L; углы φ₁ (нить) и φ₂ (стержень).
T = (m/2)[l²φ̇₁² + lLφ̇₁φ̇₂ + (L²/3)φ̇₂²], Π = (mg/2)[lφ₁² + (L/2)φ₂²]. Частоты — det(K − k²M) = 0, формы — φ₁/φ₂ (при
l = L/2: k₁ = 0,677√(g/l), k₂ = 2,558√(g/l), 0,847 и −1,180 — как в 54.9).

- **54.10** (нить много длиннее стержня): λ = k²l/g, ε = L/l; (1 − λ)(1/2 − λε/3) = λ²ε/4 ⇒ λ ≈ 1 − ε/2 и
  k₁/√(g/l) ≈ **1 − L/(4l)** — как в книге. Показываются приближённое и точное отношения.
- **54.11** (нить много короче стержня): сравнивается с физическим маятником (стержень на оси в конце, k₀ = √(3g/(2L))):
  λ = k²L/g, ε = l/L; (1 − λε)(1/2 − λ/3) = λ²ε/4 ⇒ λ ≈ 3/2 − 27ε/16 и k₁/k₀ ≈ **1 − 9l/(16L)**.

Ответ 54.11 в скане плохо читается; формула получена разложением и проверена по точному решению (в тесте — разность
порядка ε² при ε = 0,1…0,025) и совпадением метода с 54.10 и 54.9.

## 54.23 — условие равенства главных частот

Ползун P₁ на пружине c (вертикально) и математический маятник l, P₂. Груз маятника движется по вертикали на
x + l cos φ, поэтому в T член связи −m₂lẋφ̇ sin φ — третьего порядка, и линейные уравнения разделяются:
(m₁ + m₂)ẍ + bẋ + cx = 0, lφ̈ + gφ = 0. k₁² = c/(m₁ + m₂), k₂² = g/l, при b = 0 частоты равны при **c = (P₁ + P₂)/l**.
С сопротивлением — x = A₁e^(−ht) sin(√(k₁² − h²)t + ε₁), h = b/(2(m₁ + m₂)); φ — прежняя частота k₂. График x(t), φ(t)
по начальным x₀, φ₀. Либо c задано, и показываются частоты и их отношение.

## 54.24 — положение равновесия, затем частоты

Два стержня R с грузами P на концах и пружина c (длина l₀) между грузами. Углы от вертикали θ₁, θ₂ (в разные стороны),
длина пружины l = 2R sin((θ₁ + θ₂)/2). Равновесие θ₁ = θ₂ = α: **P tg α = c(l₀ − l), sin α = l/(2R)**, то есть
P l/√(4R² − l²) = c(l₀ − l) — единственный корень на (0, 2R), находится делением отрезка. Около него: f″ = cR²cos²α +
c(l₀ − l)R sin α/2, диагональные коэффициенты жёсткости f″ + PR cos α, внедиагональный f″. Корни k² = n² ± μ²,
n² = (f″ + PR cos α)/(mR²), μ² = f″/(mR²), т.е. k⁴ − 2n²k² + n⁴ − μ⁴ = 0 (вид уравнения книги):
противофазные колебания — k_a² = g cos α/R, синфазные — k_s² = g cos α/R + 2f″/(mR²).

## 54.25 — подвес с демпфером на движущейся платформе

Уравнения (ответ книги): m₁ẍ₁ + βẋ₁ − βẋ₂ + (c₁ + c₂)x₁ − c₂x₂ = c₁ξ(t), m₂ẍ₂ − βẋ₁ + βẋ₂ − c₂x₁ + c₂x₂ = 0 (x₁, x₂ —
от положения равновесия вниз). Частоты без сопротивления: m₁m₂k⁴ − [(c₁ + c₂)m₂ + c₂m₁]k² + c₁c₂ = 0. Два режима:
ξ = a sin pt — установившиеся амплитуды |X₁|, |X₂| через (K − p²M + ipB)X = (c₁a, 0)ᵀ и амплитудные кривые по p; любой
ξ(t) — формулой, интегрирование из покоя (Рунге — Кутта). Проверка — интегрированием (амплитуда после затухания
переходного процесса) и p → 0 (X₁ = X₂ = a).

## 54.26 — два маятника на натянутой проволоке

Проволока безмассова, натяжение P; в точках C и D (расстояния a) — маятники m на нитях l, колебания поперёк. Равновесие
точки проволоки: (P/a)(2y₁ − y₂) = mgφ₁ и симметрично; положение груза z = y + lφ. Собственные значения матрицы
(1/3)[[2,1],[1,2]] — 1 (синфазно) и 1/3 (противофазно): **k₁² = g/(l + mga/P), k₂² = g/(l + mga/(3P))**; при малом
μ = mga/(Pl): k₁ ≈ √(g/l)(1 − μ/2), k₂ ≈ √(g/l)(1 − μ/6). В скане ответа нет — результат выведен.

## 54.41 — крутильные колебания с маятниковым гасителем

Массы I, II (J₁, J₂) на валу c₁, ко второй на оси A (OA = l) подвешен маятник (m, AC = a, J_C). Координаты φ₁, φ₂, φ₃
(абсолютные углы), T = ½J₁φ̇₁² + ½(J₂ + ml²)φ̇₂² + ½(J_C + ma²)φ̇₃² + mlaφ̇₂φ̇₃ cos(φ₂ − φ₃), Π = ½c₁(φ₂ − φ₁)². Уравнения
(ответ книги): J₁φ̈₁ + c₁(φ₁ − φ₂) = 0; (J₂ + ml²)φ̈₂ + mlaφ̈₃ cos(φ₂ − φ₃) + mlaφ̇₃² sin(φ₂ − φ₃) + c₁(φ₂ − φ₁) = M₀ sin pt;
(J_C + ma²)φ̈₃ + mlaφ̈₂ cos(φ₂ − φ₃) − mlaφ̇₂² sin(φ₂ − φ₃) = 0. Линеаризация около вращения Ω (φ_j = Ωt + θ_j): K — как у
системы без гасителя плюс центробежная «жёсткость» mlaΩ² у разности θ₂ − θ₃; нулевая частота — вращение системы как
целого. Частота настройки гасителя p² = mlaΩ²/(J_C + ma²) (при J_C = 0 — p = Ω√(l/a)): амплитуда массы II при ней равна
нулю. Показываются нелинейные и линейные уравнения, частоты, амплитуды θ₁, θ₂, θ₃ при заданной p и график |θ₂|(p). Проверка —
сравнение с основным режимом («по T и Π») с T, записанной через Ω + θ̇.
