## Система тел на шарнирах (`src/modules/converging/model/linkage.ts`)

Конструктор для многоузловых шарнирных систем и механизмов в равновесии. Ввод — четыре строки:

- **точки** — «имя x y» через «;» (`A 0 0; B 3,46 2`);
- **тела** — точки тела через «-», тела через пробел (`A-B C-A-E`); тело — жёсткое звено любой формы;
- **опоры** — «A» — шарнирно-неподвижная (X_A, Y_A), «K 90» — ползун или каток: реакция N_K по линии под углом 90°
  к оси x; «K 90 0,1» — ползун с трением в предельном равновесии: линия реакции отклонена от нормали на угол трения
  arctg f («+» — против часовой стрелки, «−» — по часовой; два знака дают две границы, как P_min и P_max в 2.71);
- **силы** — «точка [имя] модуль угол» (угол — от оси x против часовой стрелки), неизвестный модуль — «?»
  (направление известно): так задаётся уравновешивающая сила механизма.

**Модель.** Точка, общая для нескольких тел, или точка опоры стержня — шарнир (палец): у него два уравнения
равновесия, сила, приложенная в такой точке, действует на палец. Тело из двух точек без сил на нём — стержень: одно
неизвестное усилие S вдоль него (растяжение «+»), его собственные уравнения выполняются сами — это метод вырезания
узлов. Остальные тела — три уравнения (ΣX, ΣY, ΣM относительно первой точки тела); силы шарниров на тело — X, Y.
Опора единственного тела (не стержня) действует прямо на тело.

**Решение.** Система линейна; строки нормируются, затем сравниваются ранги матрицы и расширенной матрицы:

- ранги равны и равны числу неизвестных — решение единственно (нормальные уравнения AᵀA x = Aᵀb);
- ранг расширенной больше — «равновесие невозможно»: система — механизм, и заданные силы его не уравновешивают
  (нужна неизвестная сила или связь);
- ранг меньше числа неизвестных — «неизвестные не определяются однозначно» (статическая неопределимость).

Механизм может иметь любое число степеней свободы: важна только совместность уравнений при неизвестных модулях.
Текст решения — схема, число неизвестных и уравнений, все уравнения с числами (до 40), ответ: неизвестные силы
(«−» — против заданного угла), усилия стержней (растянут/сжат), реакции опор, силы шарниров на тела.

**Правила знаков.** S > 0 — стержень растянут (сила стержня на палец направлена от пальца вдоль стержня); реакции
X, Y — по осям; N — по заданной линии; неизвестная сила — по заданному углу.

## Центр тяжести (`src/modules/centroid/`)

- **Усечённая пирамида (конус)** — тело по площадям оснований a, b и высоте h:
  V = h(a + √(ab) + b)/3, центр на оси на расстоянии h(a + 2√(ab) + 3b)/(4(a + √(ab) + b)) от нижнего основания.
- **Режим «поверхность»**: треугольник в пространстве (A = ½|r₁₂ × r₁₃|), плоский четырёхугольник (два треугольника),
  боковая поверхность цилиндра (2πrh, центр посередине высоты), поверхность сферического сегмента
  (2πRh = π(r² + h²), центр пояса — посередине его высоты).
- **Обратные задачи** (`model/extra.ts`): трапеция, подвешенная за вершину (9.13: 2t² + 2at − a² = 0), вырез с вершиной
  в центре тяжести остатка (9.14: y = H(3 − √3)/2), четыре точки опоры пластины (9.15: t = 1/3 для любого треугольника),
  половины цилиндра на нити (9.25: P = 2Q/(3π)). Ответ проверяется разбиением на части.

## Графическая статика: 5.14 (`src/modules/graphstat/model/nodepoly.ts`)

Граф фермы 5.14 не плоский (стержни 3 и 4 перекрещиваются без шарнира), обозначения Боу к нему не применимы. Вместо
общей диаграммы строятся силовые многоугольники узлов по очереди: в узле не больше двух неизвестных; известные силы
откладываются одна за другой, многоугольник замыкают прямые, параллельные неизвестным стержням (пересечение двух
прямых — построение, а не решение системы). Усилия сверяются с «Фермами».

## Расхождения с книгой

- **9.28:** z_C = 3,556 см; книга даёт 3,55 — отбрасывает третий знак, а не округляет.
- **4.62:** указание книги говорит, что затяжка «состоит из двух частей» (против опрокидывания и для трения), но ответ
  2000 кГ = P/f — только вторая часть. Из равновесия кронштейна следуют два условия T ≥ Pa/b и T ≥ P/f, нужно большее;
  при данном b/a > f это P/f — ответ книги. Сумма двух частей дала бы больше 2000.
- Округления книги: 2.38 (163,2 → 163), 2.62 (N = 20,02 → 20), 4.63 (185,6 → 186), 4.71 (0,00574 → 0,0057).

## Ограничения

- Система тел — плоская; распределённых нагрузок и пар нет (пару можно задать двумя силами), тела — жёсткие
  многоугольники точек, контакты без трения — ползуны, с трением — только в предельном равновесии с заданным знаком.
- Поля ввода — строки до 300 знаков: системы примерно до 15 точек.
- Задачи «по формулам» решают свою схему; другая схема — в системе тел на шарнирах или в «Балках и рамах».
