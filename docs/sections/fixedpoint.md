# Тело с неподвижной точкой: режим «по формулам» (пункт 27)

Мещерский §19, 20, 25. Новых разделов нет: во вкладке «Тело с неподвижной точкой» (`src/modules/fixedpoint/`) добавлен
четвёртый режим «задачи по формулам» (`model/calc.ts`, `text/calc.ts`, `draw/calc.ts`); основное описание — в README,
«Тело с неподвижной точкой».

## Виды задач

- **ω и мгновенная ось по скоростям двух точек** (19.13): ω × r₁ = v₁ (три уравнения) и ω × r₂ = k·e₂ (направление
  скорости второй точки, неизвестный множитель k) — система из шести уравнений относительно (ω_x, ω_y, ω_z, k),
  метод Гаусса; несовместные данные — ошибка. Мгновенная ось — через неподвижную точку параллельно ω, уравнения двух
  плоскостей.
- **Земля и трёхгранник Дарбу** (20.9–20.12): φ̇ = v*N/R, λ̇ = v_E/(R cos φ); ω*ξ = −φ̇, ω*η = (U + λ̇) cos φ,
  ω*ζ = (U + λ̇) sin φ; по курсу ψ (tg ψ = v_E/v_N): ω_x = U cos φ cos ψ, ω_y = U cos φ sin ψ + v/R,
  ω_z = U sin φ + v/ρ; по абсолютной скорости V = √((v_E + RU cos φ)² + v_N²): ω_x⁰ = 0, ω_y⁰ = V/R,
  ω_z⁰ = (U + λ̇) sin φ + θ̇ (θ̇ — по производным составляющих скорости, поля «ускорение»).
- **Гироскоп направления** (20.13–20.14): направляющие косинусы оси z (sin α cos β, cos α cos β, sin β) по осям
  восток — север — вверх; ω_x, ω_y, ω_z трёхгранника xyz (при v_E = v_N = 0 — 20.13).
- **Шарнир Кардана — Гука** (25.24): ω₁/ω₂ = (1 − sin²α cos²φ)/cos α; случаи 1/cos α (φ = 90°) и cos α (φ = 0°),
  неравномерность sin α·tg α, график ω₂/ω₁ за оборот.
- **Дифференциал на повороте** (25.14): ω₁,₂ = v(ρ ± l/2)/(ρR), ω_C = (ω₁ + ω₂)/2, ω_r = (R₀/r)(ω₁ − ω₂)/2.

Кроме того, готовые задачи 20.17 (a = −1/2 — неподвижный аксоид есть плоскость Oxy, ω_z = 0) и 25.28 (чистое вращение
при v₁ = v₂ cos α: наименьшая скорость равна нулю, ось на расстоянии v₂ sin α/ω₁).

## Правила знаков

Оси места: ξ — на восток, η — на север, ζ — вверх; широта φ южная со знаком «−»; U = 7,292·10⁻⁵ с⁻¹ (поле в единицах
10⁻⁵ с⁻¹). Курс ψ — от севера к востоку. Ускорения в 20.12 по умолчанию нулевые.

## Расхождения с книгой

- **19.13:** книга даёт ω = 3,2 с⁻¹; точно √10,25 = 3,2016 (допуск 0,1 %). Положение точки M₁(0, 0, 2) восстановлено
  по ответу (плохо читается в скане).

## Ограничения

Свой механизм с несколькими входами в режиме «по формулам» не вводится — это отдельные задачи с полями-числами.
