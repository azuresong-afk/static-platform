## Модель и формулы

### Равновесие при вращении

Точка движется по окружности радиуса R равномерно; по принципу Даламбера к силам добавлена центробежная сила инерции
mω²R = mv²/R от оси, и задача решается как статическая.

- **Вираж.** Наклон без бокового усилия: tg α* = v²/(gR); давление (натяжение подвески) N = m√(g² + v⁴/R²);
  возвышение рельса h = d sin α*. На горизонтальной дороге нужен f ≥ v²/(gR) (велосипедист наклонён на α*). На вираже
  с уклоном α и трением f: v_min² = gR(tg α − f)/(1 + f tg α), v_max² = gR(tg α + f)/(1 − f tg α) (если f tg α ≥ 1 —
  ограничения сверху нет); при заданной v: N = m(g cos α + (v²/R) sin α), F_тр = m((v²/R) cos α − g sin α).
  Радиус по показанию весов k = N/P: R = v²/(g√(k² − 1)).
- **Конический маятник** (нить l, угол θ с вертикалью): ω² = g/(l cos θ), T = mg/cos θ = mω²l; по ω: cos θ = g/(ω²l),
  при ω²l ≤ g нить вертикальна. Сферический маятник по окружности радиуса r: v₀ = r√(g/z₀), z₀ = √(l² − r²),
  период 2π√(z₀/g).
- **Вертикальная окружность** (равномерно): N_низ = m(g + ω²R), N_верх = m(ω²R − g); наименьшая ω разрыва нити —
  по натяжению внизу; ω, при которой исчезает давление вверху, — ω² = g/R (масленка на шатуне: скорость тепловоза ωD/2).
- **Пружина в направляющей:** mω²r = c(r − r_s), r_s — расстояние от оси, при котором пружина не напряжена. Найти r,
  c, ω или c и r_s по двум состояниям (ω₁, r₁), (ω₂, r₂): c = m(ω₂²r₂ − ω₁²r₁)/(r₂ − r₁).
- **Стержни на шарнире вала:** плечи a (угол φ с вертикалью вниз) и b (угол φ − γ), масса распределена по длине.
  (g/2)Σlᵢ² sin θᵢ = (ω²/3)Σlᵢ³ sin θᵢ cos θᵢ. По φ — ω явно; по ω — все корни на (−180°, 180°] с устойчивостью,
  ответ — устойчивое отклонённое положение. Давление на шарнир: вертикально P, горизонтально ρω²Σ(lᵢ²/2) sin θᵢ.
- **Трубка:** dy/dx = ω²x/g ⇒ y = ω²x²/(2g) + c.

### Поверхности и кривые

- **Цилиндр** (ось вертикальна, точка внутри): N = m(v₀ cos α)²/r; φ = (v₀ cos α/r)t, z = v₀t sin α + gt²/2 (ось z
  вниз, α — угол v₀ с горизонтом вниз).
- **Конус** (вершина O внизу, ось вверх, полуугол α, точка на внутренней поверхности): s = OM, r = s sin α;
  r²φ̇ = (a sin α)v₀; s̈ = rφ̇² sin α + (c/m)s − g cos α; N = m(g sin α + rφ̇² cos α). Интегрируется методом
  Рунге — Кутта; без тяжести (g не учитывается) — задача 31.26.
- **Шероховатая окружность:** снаружи от верхней точки N = m(g cos φ − v²/R), изнутри от нижней N = m(v²/R + g cos φ);
  для u = v² уравнение линейно (du/dφ ∓ 2fu = …), решается численно до события: остановка (и удержится ли трением —
  tg φ ≤ f), сход с поверхности (N = 0), верхняя точка. Предельная v₀ — по формулам книги и делением пополам по
  численному решению (совпадают).
- **Проволока:** v² при встрече = 2gl(cos β − cos α); натяжение возрастает на mv²h/(l(l − h)); нить навивается, если
  вверху малой окружности v² ≥ g(l − h) ⇒ cos α_min = (h/l)(3/2 + cos β) − 3/2.
- **Цепная линия** y = a ch(x/a), сила kmy от оси x: v² − ky² = const, ρ = y²/a, N = m(v²a/y² − ka); при v₀² = ky₀²
  давление нуль и ẋ = a√k.
- **Винтовая поверхность** z = aφ + f(r) с трением k: движение по винтовой линии r₀ возможно при
  tg α = k√(1 + f′²(r₀)cos²α), tg α = a/r₀; скорость v = √(g r₀ f′(r₀)). Проверено выводом: проекции на касательную,
  бинормаль и главную нормаль винтовой линии.
- **Маятник на высоте:** Δl/l = 1 − (R/(R + H))².

### Составные задачи

- **Петля с разрывом:** v_D² = gr/cos α (дальность DC = 2r sin α); h = r(1 + cos α + 1/(2cos α)); h_min = r(1 + √2) при
  α = 45°. Заданную h можно проверить: дальность полёта сравнивается с разрывом.
- **Трамплин:** v_C² = 2gh(1 − f ctg α); t = 2(vᵧ + v_C tg β)/g; l = v_C t/cos β.
- **Плита с пружиной:** c = 2P(H + h)/h², k = √(c/m); T = (π/2 + ψ)/k, tg ψ = h/(2√(H(H + h))); S = P(T + √(2H/g)) —
  по теореме об импульсе.
- **Осколок маховика:** наибольшая дальность на том же уровне s = v²/g ⇒ ω = √(gs)/R.
- **Ослабление нити:** положение и скорость — расчётом режима «движение по окружности» (`solveCircle`), затем
  парабола y = x tg θ − gx²/(2v₁²cos²θ) до |OM| = l.

### Теорема об импульсе

- **Прямая:** m(v₁ − v₀) = (F − R)t, R = mg(f cos α + sin α), α > 0 — подъём; путь (v₀ + v₁)t/2; среднее давление F/A.
- **Импульс равнодействующей:** S = m(v₁ − v₀) векторно; средняя сила S/Δt. По окружности: |S| = 2mv sin(ψ/2).
- **Закон площадей:** n₂ = n₁(r₁/r₂)²; нить в отверстии: r = R − at, φ = u₀t/(R − at), T = mu₀²R²/(R − at)³.
- **Два маятника:** √(l₁/l₂) = k/n (несократимая дробь; ищется цепной дробью, знаменатель до 1000), T = nT₁ = kT₂.

## Правила знаков

- Углы — в градусах. Вираж: α — уклон полотна к горизонту, F_тр > 0 — вниз по откосу (к центру).
- Стержни: углы от вертикали вниз; плечо b — под углом φ − γ (при γ = 90° — по другую сторону вала, как на чертеже
  к 41.25), γ = 180° — прямой стержень через шарнир (41.26), b = 0 — один стержень (41.24).
- Пружина в направляющей тянет груз к оси с силой c(r − r_s); r_s меньше рабочего радиуса — предварительный натяг.
- Цилиндр: ось z вниз (как в книге). Конус: ось вверх, вершина внизу.
- Ослабление нити: φ — от нижней точки против часовой стрелки, v₀ «+» — в сторону роста φ (как в «движении по окружности»).
- Импульс: движение в одну сторону, сила тяги — по скорости; уклон α > 0 — подъём, α < 0 — спуск.
- Задан вес: единица силы — кГ (Н), m = P/g.

## Расхождения с книгой

- **26.5:** книга ω = 4,44 с⁻¹; по условию (3 Н, 1 м, 9 Н) ω = √((T/m − g)/l) = √(2g) = 4,43 с⁻¹ и при g = 9,81, и при
  g = 9,8 (4,427). Расхождение 0,2 % — вероятно, округление книги.
- **26.29:** книга v ≥ 11,4 км/ч; по условию v = (D/2)√(g/r) = 0,51·√(9,81/0,25) = 3,195 м/с = 11,50 км/ч (с g = 9,8 —
  11,49). Расхождение 0,9 %; другой разумной модели, дающей 11,4, не нашли (масло выливается в верхнем положении, когда
  ω²r ≥ g; шатун движется поступательно, его точки — по окружностям радиуса кривошипа).
- **26.21, 26.31:** углы книги 18°47′ и 14°20′ — при g = 9,8; с g = 9,81 получается 18°46′ и 14°18′ (14°19′ при 9,8).
- **28.2:** книга T = 5 с; расчёт 4,945 с (с g = 9,8 — 4,948) — в книге округлено.
- **28.13:** в условии — «одновременно вернулись в положение равновесия», а ответ книги T = kT₂ = nT₁ при √(l₁/l₂) = k/n —
  это время одновременного возврата в исходные (крайние) положения. Через положение равновесия маятники проходят в
  моменты (2j + 1)Tᵢ/4, одновременно — только если T₁/T₂ — отношение нечётных чисел. Приложение считает по ответу книги
  и пишет это в решении.
- **31.12:** книга записывает T = (π/2 − α)/k с tg α = −h/(2√(H(H + h))) — тот же угол с обратным знаком; у нас
  T = (π/2 + ψ)/k, ψ > 0.

## Ограничения

- Вираж и конический маятник — равномерное движение; в вираже нет опрокидывания (только скольжение).
- Шероховатая окружность — точка малых размеров на круговом цилиндре, коэффициенты трения покоя и скольжения равны.
- Конус: только отталкивание (притяжение — c < 0) и тяжесть; конус с вершиной вверх не задаётся.
- Стержни — два плеча из одной точки шарнира, однородные, одинаковой погонной массы.
- Импульс на прямой — силы постоянны и движение в одну сторону (без остановки и поворота); сила по графику (Яблонский Д.5)
  не задаётся.
- Не сделано: 26.25 (давление двух грузов на опору — сила пружины из «силы по закону движения» плюс вес B вручную),
  26.28 (вес на Луне и Солнце — арифметика), 26.30 (натяжение при заданном законе φ(t)), 28.10 (метеориты на эллипсе),
  31.14 (обратная задача: жёсткость по нулевому давлению — прямая проверка собирается в «движении по окружности»).
