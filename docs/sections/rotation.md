# Вращение тела: второй экран (пункт 28)

Раздел «Вращение тела» (`src/modules/rotation/`): основной экран — уравнение вращения и сохранение кинетического
момента (см. README, «Вращение тела»). Пункт 28 добавил второй экран — кнопка «Магнит, физический маятник, канат через
блок, муфта и ремень →» (`model/extra.ts`, `model/extraYab.ts`, готовые задачи — `extraPresets.ts`).

## Что решает

- **Магнит в поле (37.25):** J θ̈ = −AHθ, J = m(a² + b²)/3, T = 2π√(J/(AH)).
- **Физический маятник (37.37, 37.39):** цилиндр, стержень или заданные J_C и a; ось может быть наклонена к вертикали на
  угол α; точечная масса на прямой OC: T = 2π√((J_C + ma² + m₁d²)/((ma + m₁d) g sin α)), центр качаний.
- **Человек на канате через блок (37.49–37.50):** кинетический момент относительно оси блока сохраняется (или растёт
  под моментом разности весов): v₀ = m₁u/(m₁ + m₂ + J/R²).
- **Муфта и ремень (43.8, 44.21):** сохранение кинетического момента при соединении дисков; ремень — равные импульсы
  натяжений, J ∝ R⁴ для одинаковых дисков; потеря кинетической энергии.
- **Тело с точкой в желобе (Яблонский Д.9):** 1) (J*z + m₂r_O²)(ω*τ − ω₀) = ∫₀^τ M_z dt; 2) при движении точки по желобу
  L_z = (J_z + m₂r_K²)ω + m₂ṡh_K = const, h_K — плечо направления желоба относительно оси (в проекции на плоскость ⟂ z;
  для пластинки, содержащей ось, h_K = 0). Желоб — прямая из O (угол γ, доля проекции κ) или дуга; пластинка — круг
  (J = m(R²/2 + a²) или m(R²/4 + a²)) или задан J_z.
- **Колёса и груз (Яблонский Д.11):** ω₁ρ₁ = ω₂ρ₂, u = ρ₂/ρ₁; J*пр φ̈₂ = M(t)u − M_c ∓ m₃g r u_L,
  J*пр = J₁u² + J₂ + m₃r²u_L²; при линейном M(t) — φ = at³ + bt² + ω₀t; натяжение T = m₃(g ± a₃), окружное усилие из
  уравнения колеса 2. Движущая сила P(t) — через плечо r_P.

## Правила знаков

Положительное вращение — против часовой стрелки при взгляде с +z (Д.9: ω₀ = −2 рад/с — по часовой); в Д.11 — в сторону
движущего момента, груз поднимается или опускается (выбор).

## Готовые задачи и ответы книги

37.25, 37.37, 37.39, 37.49, 37.50, 43.8, 44.21 (в буквах — числа для примера), Д.9 (J*z = 864 кг·м², ω*τ = 2 рад/с,
ω_T = 2,58 рад/с), Д.11 (φ₂ = 0,672t³ + 0,230t² + 3t, T = 4285 Н, S = 7295 Н).

## Расхождения с книгой

- 37.37: положение оси на чертеже не дано числом; принято l/2 от центра (по ответу).
- Д.11: T = 4284 Н и S = 7294 Н (книга 4285 и 7295 — округление).

## Ограничения

Д.9 — пластинки сложной формы задаются моментом инерции; Д.11 — две передачи (три колеса) приводятся к одной вручную.
