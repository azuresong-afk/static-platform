# Покрытие сборника Яблонского конструкторами приложения

Сборник заданий для курсовых работ по теоретической механике / под ред. А. А. Яблонского (файл
`books/Collection of tasks for term papers on theoretical mechanics.pdf`, в репозиторий приложения не входит).

**Вопрос аудита** тот же, что для Мещерского и Антонова: может ли студент сам собрать своё задание в разделе
приложения и получить решение с объяснением.

**Как проверяли.** Файл — скан без текстового слоя (380 страниц), текст распознан OCR. В сборнике 45 заданий
(статика С.1–С.9, кинематика К.1–К.9, динамика Д.1–Д.27), в каждом обычно 30 вариантов — схемы на рисунках и
данные в таблице. Условия прочитаны целиком. Схемы вариантов просмотрены глазами: OCR чертежи не распознаёт.
Оценка ставится заданию целиком:

- **✓ собирается** — собираются все или почти все варианты (не меньше 25 из 30), раздел отвечает на вопрос задания;
- **½ частично** — часть вариантов не собирается, или часть вопроса остаётся студенту (второй этап, обратная задача,
  величина, которую раздел не выводит);
- **✗ нет конструктора.**

Для проверки собраны два разобранных в книге примера: К.3 (плоский механизм) — моделью «Плоского механизма»,
Д.14 (принцип возможных перемещений для механизма с зубчатой передачей и пружиной) — силами на механизме.
Ответы совпали с книгой; два мелких расхождения от округления перечислены в конце.
