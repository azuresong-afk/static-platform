# Покрытие учебников: сводка

Цель приложения — не набор готовых решений, а конструкторы. Студент сам составляет задачу своего вуза, а приложение
решает её и объясняет ход решения. Аудит проверяет учебники по очереди: хватает ли конструкторов для задач каждой книги.

| Книга | Отчёт | Итог |
|---|---|---|
| Мещерский И. В. Сборник задач по теоретической механике, 1975 | [coverage-meshchersky.md](coverage-meshchersky.md) | 1732 задачи: 53 % собираются, 24 % частично, 22 % нет конструктора |
| Антонов С. И. и др. Прикладная механика, РХТУ | [coverage-antonov.md](coverage-antonov.md) | задачи 1–4 и 6 собираются; не покрыты главы 5 (соединения) и 11 (усталость) |
| Сборник заданий для курсовых работ по теоретической механике под ред. А. А. Яблонского | [coverage-yablonsky.md](coverage-yablonsky.md) | 45 заданий: 18 собираются, 22 частично, 5 нет конструктора |

## Следующие книги

Для сверки нужны тексты книг (PDF). Кандидаты:

- **теоретическая механика.** Общие для многих вузов (Яблонский уже сверен): Тарг,
  Бутенин — Лунц — Меркин, Бать — Джанелидзе — Кельзон. Из списков отдельных вузов: МЭИ — Осадченко и Кирсанов,
  МФТИ — задачник Пятницкого и др. по аналитической механике, МГУ — Голубев и Маркеев. Ещё Кепе — сборник коротких задач;
- **сопротивление материалов.** Распространённые учебники: Беляев, Феодосьев, Александров, задачник Миролюбова и др.
  Этот список составлен по памяти; по спискам вузов он не сверялся.
