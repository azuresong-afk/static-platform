# Итоги пунктов дорожной карты

Пункт, который ведётся параллельно с другими, пишет свои итоги сюда, в `item-<номер>.md`, а не в общие документы
(`docs/coverage*.md`, «Итог», README «Задачник»): так ветки пунктов не конфликтуют при слиянии. В файле — что сделано
и в каких разделах, какие задачи Мещерского и Яблонского стали ✓ и ½ (по параграфам и заданиям), расхождения с книгой,
что осталось. После слияния всех пунктов этапа итоговая сессия запускает `npm run totals` и переносит итоги отсюда в
`docs/coverage*.md` (см. CLAUDE.md, «Параллельные пункты»).
