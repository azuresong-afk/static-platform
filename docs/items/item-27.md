## Расхождения с книгой

- 12.36: знак w_φ в книге противоположен формулам сферической системы (как в 11.17) — документировано, не подгонялось.
- 19.13: книга округляет |ω| = 3,2 с⁻¹ (точно 3,2016).
- 14.14: формула книги верна с смещением x*B = x_max − x*книги; 16.38: ответ книги — для кривошипа по часовой стрелке.
- 21.14: книга даёт относительное движение приближённо (λ = r/l мало), расчёт — точное; в режиме «уравнения» оси
  вращаются по часовой стрелке, палец A в (0; +r).
- Числа во многих «общих» задачах (10.3, 10.12, 10.14, 12.36, 14.x, 20.9–20.14, 22.x, 24.14, К.9) — для примера, в
  названиях стоит «(числа — пример)».
