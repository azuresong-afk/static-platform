# Промты для отдельных сессий

Дорожная карта выполнена, кроме пункта 8 (соединения — ждёт методики). Пункты 14–16 закрывают оставшиеся пробелы
покрытия задачника Мещерского; темы не пересекаются, поэтому их можно вести **параллельно, каждую в своей ветке**.
После всех трёх — сессия слияния. Учебники сессия берёт сама из `books/` ветки `main` (см. `CLAUDE.md`).

## Пункт 14 — теоремы динамики: работа и мощность, количество движения, давление струи

```
Репозиторий azuresong-afk/static-platform. Основа — ветка claude/exciting-gates-xx33r9: начни свою ветку от неё
(git fetch origin && git checkout -b <ветка сессии> origin/claude/exciting-gates-xx33r9) и пушь в свою ветку.
Прочитай CLAUDE.md и следуй ему.
Задача — пункт 14: работа и мощность (Мещерский §29), сохранение количества движения системы и давление струи
(§36). По возможности дополни существующие разделы («Кинетическая энергия», «Центр масс и плоское движение»,
«Динамика точки»), новый раздел — только если иначе нельзя.
Сначала проверь, что это ещё не сделано: roadmap.ts, README, docs/coverage-meshchersky.md (§29, §36), src/modules,
git branch -r. Что уже сделано — не повторяй; если тема закрыта целиком — сообщи и остановись.
Напиши документацию раздела в docs/sections/<id>.md (что решает, формулы, правила знаков, готовые задачи с ответами
книги, расхождения с книгой, ограничения), обнови README (строка со ссылкой), docs/coverage*.md и roadmap.ts.
Публиковать не нужно. В конце — коммит, пуш и короткий отчёт: что сделано, расхождения с книгой, что осталось.
```

## Слияние и публикация (после пунктов 14–16)

```
Репозиторий azuresong-afk/static-platform. Прочитай CLAUDE.md. Влей в ветку claude/exciting-gates-xx33r9 готовые
ветки пунктов 14–16 (найди их через git branch -r), по одной, без переписывания истории; конфликты в счётчиках e2e,
README, roadmap.ts и docs/coverage*.md разреши по смыслу (суммы задач пересчитай). После каждой — npx vitest run;
в конце — npm run build, e2e:files, compare:ui, публикация по CLAUDE.md и короткий отчёт.
```
