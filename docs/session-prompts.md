# Промты для отдельных сессий

Сессии запускать **по очереди**: каждая следующая — после того, как предыдущая запушила свою работу (все они правят
одни и те же файлы: реестр разделов, навигацию, дорожную карту, README, e2e). Учебники в репозитории нет —
прикрепляйте нужные PDF к первому сообщению сессии. Правила и порядок работы сессия берёт из `CLAUDE.md`.

## Сессия 1 — пункт 11: пространственное движение тела

```
Репозиторий azuresong-afk/static-platform. Работай в ветке claude/exciting-gates-xx33r9 (подтяни её, пушь туда же).
Прочитай CLAUDE.md и следуй ему.
Задача — пункт 11 дорожной карты: пространственное движение твёрдого тела — тело с неподвижной точкой, сложение
вращений вокруг пересекающихся осей (конические передачи, дифференциалы, бегуны), углы и кинематические формулы
Эйлера, приближённая теория гироскопов (Мещерский §19, 20, 25, 40; Яблонский К.5, К.6, К.8).
Если в постановке есть развилки — задай вопросы одним сообщением в начале, дальше работай без остановок.
Учебники прикладываю: Мещерский (1975), Яблонский. Публиковать не нужно.
В конце — коммит, пуш и короткий отчёт: что сделано, расхождения с книгой, план.
```
